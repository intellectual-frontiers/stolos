tag-commands

Spec 108-tags: stolos tag add | remove | list, on the controller PC. A change to a machine's tags is a change to the fleet repository, in the machine's own file (decisions.ts of a managed host, machine.ts of an adopted machine), and it is sent the way every change is: one signed commit through stolos apply (--no-apply leaves it for the next apply). Tags are defined by editing fleets/<fleet>/tags.ts in the spec loop, so there is no command that defines one: tag list says where.

Source: src/archon/fleet/tag-commands.ts

TagChangeOptionsinterface
interface TagChangeOptions

What a command is given besides the machine: where the change is sent.

MemberTypeWhat it is
machinestringThe machine.
tagsstring | readonly string[]The tags (env:prod, or a free-form word): a list, or the command line's values joined by newlines or commas.
custom?booleanRead every word as a free-form tag (a word that is also a dimension's or a tag's own name).
noApply?booleanWrite the change, but do not send it (stolos apply sends it later).
message?stringReplaces the commit's message.
