classes

Spec 089: the OCSF 1.9.0 classes Stolos emits, and the names of the OCSF objects, the vocabulary Stolos names its tables and labels from (schema/vocabulary.ts).

The OCSF types themselves are IFC TypeScript's (kernel ocsf, generated there from the pinned OCSF 1.9.0 schema). The kernel types classes 2003, 2002, 5001, 5003 and 5023; the connectors also record nodes as 5020 Software Inventory Info, 5004 Operating System Patch State, 5040 Live Evidence Info and 2008 IAM Analysis Finding, which the kernel does not type yet, so this table names them by their uid, caption and category alone (a commons gap). The object names are those of every object the emitted classes use, as OCSF 1.9.0 names them.

Source: src/archon/ocsf/classes.ts
