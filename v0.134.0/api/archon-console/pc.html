pc

Spec 066: what the Stolos Console shows, gathered on the PC from the fleet repository and this PC's state: every machine (managed servers and workstations, adopted machines, cloud servers), the clouds, the signers, and the repository's changes. Nothing here reaches a server: the last answers are those stolos fleet status and host observe recorded; the pages offer the commands that refresh them.

Source: src/archon/console/pc.ts

PcMachineinterface
interface PcMachine

One machine, whatever its kind.

MemberTypeWhat it is
namestringIts name in the fleet (or the cloud's).
kind"adopted" | "cloud" | "device" | "discovered" | "server" | "workstation"server or workstation (managed), adopted, device (SNMP), discovered (recorded, not yet adopted), or cloud: the ontology's machine kinds (spec 101-ladder FR-006), but the controller, which the console lists as an adopted machine.
os?stringIts operating system, when known.
where?stringWhere it is: an address, a cloud and region.
owner?stringWho it belongs to (adopted machines).
title?stringWhat it is, for people (an adopted machine's title).
serial?stringIts serial number, when the probe could read it.
seen?stringWhen it was last installed (managed) or observed (adopted, cloud).
score?{ pass: number; total: number; }Its checks or policies: how many pass, of how many.
failingstring[]What fails, in words.
attention?Attention[]A managed machine's checks that did not pass at its last verify (failed, warned, or not set up yet), each with its fix, as it reported them (stolos fleet status).
notAsked?booleanA managed machine's results were never asked for from this PC (stolos fleet status).
console?stringIts Archon Console, for a managed server with a web domain.
applied?{ commit: string; subject: string; at: string; }A managed server's applied commit, as it last said (short hash, subject, when).
sync?{ at: string; blocked?: string | undefined; }A managed server's last pull: when, and why it stopped, if it did.
upToDate?booleanWhether its applied commit is the repository's newest (undefined: not known).

PcFactsinterface
interface PcFacts

Everything the Stolos Console shows.

MemberTypeWhat it is
fleet{ id: string; title: string; repo: string; domain?: string | undefined; engine?: string | undefined; }The fleet: id, title, its repository, web domain, and engine pin.
machinesPcMachine[]Every machine.
adopted{ machine: AdoptedDef; observed?: Observed | undefined; results: PolicyResult[]; }[]Adopted machines with their observations and policies.
cloudsPcConnector[]Every cloud provider.
estate?PolicyResult[]Spec 085: the cross-system policies over the estate graph.
controls?PackRun[]Spec 078: the fleet's own control packs (fleets/<fleet>/controls/), with their results.
devices{ device: DeviceDef; observed?: DeviceObserved | undefined; results: PolicyResult[]; }[]Devices read over SNMPv3, with their policies.
signers{ name: string; role: string; added: string; key: string; }[]The signers.
git{ dirty: string[]; unapproved: string[]; log: PcCommit[]; diff?: string | undefined; }The repository: uncommitted files, commits servers would refuse, recent history.
