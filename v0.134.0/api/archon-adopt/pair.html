pair

Spec 098: pairing with a short code. The way a person brings a machine into the fleet without copying a key or a hash by hand, modeled on device login: the controller PC shows one short, fixed command and a code that expires; the person runs the command on the machine and types the code; the PC shows who asked and the person approves there.

This module is the protocol, with no network or terminal of its own: PairSession answers the machine's HTTP requests, and the command (stolos pair, in commands.ts) serves it and asks the person.

RequestWhat it is
GET /the POSIX script: bin/integrate.sh, from this engine, with the pairing filled in
GET /wa Windows loader: saves /w.ps1 and runs it in a child PowerShell (so a stop never closes the person's window)
GET /w.ps1bin/integrate.windows.ps1, from this engine
GET /bin/stolos-probe.sh, /bin/stolos-probe.ps1the probes, from this engine
POST /hellononce=, hostname= and os= (posix or windows) lines, signed with the code: the answer is the machine's name and the fleet's probe key, signed back
POST /checkinthe check-in text (the same as a stolos1: code, unencoded), signed with the code: the answer waits for the person's approval

Every answer is 200 with its first line ok or no <reason>, so the smallest HTTP client (a POSIX shell's curl or wget, PowerShell 5.1) reads it the same way. A signature is HMAC-SHA256 under the code (normalized: uppercase, no separators), in lowercase hex, sent in the X-Stolos-Mac header; the PC's answer to /hello is signed over nonce, key, name and sha256 (the probe's, for the machine's OS), one per line, so the machine knows the key came from the PC that showed the code and installs only the probe that PC means.

The code is 8 characters from an alphabet without look-alikes (about 39 bits), good for one machine, for 10 minutes, and for 5 wrong signatures in all. Plain HTTP is deliberate (the network trust position in the networks guide): on a trusted LAN, or over a zero trust mesh network (Tailscale, NetBird, ZeroTier, Nebula, WireGuard, or similar: see mesh.ts) for anything else, never exposed to the internet.

Source: src/archon/adopt/pair.ts
