archon-boot/firewall.ts

Firewall check for boot serve (spec 004): warn, with the exact command, when this machine's firewall would block servers from reaching TFTP (UDP) or HTTP (TCP). Read-only: it never changes a firewall rule. Windows Defender Firewall, ufw, and firewalld; anything else is not checked.

export interface WinRule {
  /** The rule's display name. */
  name: string;
  /** Allow or Block. */
  action: "Allow" | "Block";
  /** "Any", or a comma list of Domain, Private, Public. */
  profile: string;
  /** "Any", TCP, UDP. */
  protocol: string;
  /** Local ports: "Any", or a list such as ["8080"] or ["1000-2000"]. */
  ports: string[];
  /** Program path for an application rule, else "Any". */
  program: string;
  /** Remote addresses: "Any", "LocalSubnet", or addresses and ranges. */
  remote?: string[];
  /** Limited to a Windows user, service, app package, or interface: not the boot server's. */
  scoped?: boolean;
}
