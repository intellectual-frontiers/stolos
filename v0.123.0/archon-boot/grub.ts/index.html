archon-boot/grub.ts

GRUB configs served to Ubuntu's network GRUB (spec 004). A machine is recognized by its own Boot URI (/boot/<host>/bootx64.efi) or, when the model names one, by its MAC. Anything else gets a menu of armed hosts whose default boots the local disk, so a stray network boot never reinstalls anything.

Exports

functionmainMenu

export function mainMenu(): string

The generic menu: hand the machine to its config by MAC address.

functionhostMenu

export function hostMenu(host: HostDef, base: string, token: string | undefined): string

The GRUB config for a known host: an unattended install entry when the host is armed (token set), otherwise a menu that boots the local disk. base is the boot server's URL, ending in a slash.

functionchooserMenu

export function chooserMenu(armed: Array<{ host: HostDef; token: string }>, base: string): string

A machine the boot server does not recognize: list the armed hosts, but boot the local disk unless someone at the console picks one.
