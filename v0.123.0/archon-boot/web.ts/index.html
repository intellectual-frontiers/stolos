archon-boot/web.ts

The boot machine's side of HTTPS (spec 032):

bun run stolos boot web-setup store the Cloudflare DNS token (once) bun run stolos boot web-push <host> give a running server the token over SSH

The token lives only in this PC's secrets folder and, on each server, root only in /etc/archon/web. It never enters the repository (Article 13).

Exports

functionwebSetup

export async function webSetup(): Promise<number>

bun run stolos boot web-setup: explain the one-time Cloudflare DNS token, read it without echo, check that it can see the fleet's zone, and store it in this PC's secrets. Returns the exit code (1 on a missing web setting or a bad token).

functionwebPush

export async function webPush(name: string | undefined): Promise<number>

bun run stolos boot web-push <host>: give a running server the stored DNS token over SSH (on stdin to archon web credential). Returns ssh's exit code, 2 for an unknown host, or 1 when no token is stored.
