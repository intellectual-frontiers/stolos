archon-boot/boot-log.ts

The boot server's log (spec 004 FR-017): boot serve writes everything its window shows to boot.log in the boot cache (%LOCALAPPDATA%\stolos\boot; Linux: ~/.local/share/stolos/boot), keeping one previous copy (boot.log.1) once it passes 5 MB.

Example

import { openBootLog } from "./boot-log.ts";
const log = await openBootLog();
log.write("2026-11-15T00:00:00.000Z alpha: First boot");
