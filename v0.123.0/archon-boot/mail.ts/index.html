archon-boot/mail.ts

The boot machine's side of outbound mail (specs 025, 027):

bun run stolos boot mail-setup store the Cloudflare API token (once) bun run stolos boot mail-push <host> give a running host the token over SSH bun run stolos boot notify --subject ... email the mailbox from this PC (also: notify test | status)

The token lives only in this PC's secrets folder and, on each server, in Postfix's /etc/postfix/sasl_passwd (root only). It never enters the repository (Article 13).

Exports

functionmailSetup

export async function mailSetup(): Promise<number>

bun run stolos boot mail-setup: explain the one-time Cloudflare setup, read the API token without echo, test it with an SMTP login (nothing is sent), store it in this PC's secrets, then run the doctor's email checks. Returns the exit code (1 on a missing mail setting, a bad token, or a failed check).

functionmailPush

export async function mailPush(name: string | undefined): Promise<number>

bun run stolos boot mail-push <host>: give a running host the stored mail token over SSH (on stdin to archon mail credential). Returns ssh's exit code, 2 for an unknown host, or 1 when no token is stored.

functionbootNotify

export async function bootNotify(args: string[]): Promise<number>

bun run stolos boot notify ... : the same options as archon notify send, or test / status.
