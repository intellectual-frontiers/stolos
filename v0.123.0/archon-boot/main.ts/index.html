archon-boot (spec 004): the boot machine's side of a zero-touch install. Runs with Bun (or Node 26) on Windows or Linux:

bun run stolos boot serve [--port 8080] serve PXE (TFTP, UDP 69), UEFI HTTP Boot, and installs bun run stolos boot reinstall <host> [--confirm-destroy <host>] push its state, arm it, network-boot it once (over SSH); a durable host needs --confirm-destroy (Article 23) bun run stolos boot retire <host> --confirm-destroy <host> [--no-push] a server leaves the fleet, committed and pushed (spec 045) bun run stolos boot arm <host> --claim | --mac-address <mac> [--confirm-destroy <host>] allow one (re)install of a host bun run stolos boot status hosts, Boot URIs, MACs, armed or not bun run stolos boot doctor check this boot machine, with a fix for each problem bun run stolos boot observe recent installs from the boot server's own telemetry bun run stolos vault <sub> back up and restore this PC's secrets (spec 029) bun run stolos boot mail-setup store the mail relay's token (Cloudflare, spec 027) bun run stolos boot mail-push <host> give a running host that token over SSH bun run stolos boot web-setup store the Cloudflare DNS token (HTTPS, spec 032) bun run stolos boot web-push <host> give a running server that token over SSH bun run stolos boot notify --subject ... email the mailbox from this PC (also: notify test | status)
