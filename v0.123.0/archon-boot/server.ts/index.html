archon-boot/server.ts

archon-boot's HTTP server (spec 004): UEFI HTTP Boot files, GRUB menus per host (by Boot URI, or by MAC when the model has one), the verified installer image, and each host's install config with its secrets filled in at request time (Article 13).

flowchart LR
  pxe["PXE / HTTP Boot"] --> menu["GRUB menu<br/>(by MAC, claim, or Boot URI)"]
  menu --> cfg["user-data: autoinstall<br/>(the guard runs first)"]
  cfg --> facts["facts: the guard's answer"]
  facts --> events["events: installer, first boot"]
  events --> done["done: MAC recorded"]
  otlp["/otlp: the fleet's telemetry"] --> files["telemetry files"]

interfaceServeOptions

export interface ServeOptions {
  /** The HTTP port the boot server listens on (GRUB, the installer and the servers reach it). */
  port: number;
  /** Proxy the installer and first boot should use (sites behind one; optional). */
  proxy?: string | undefined;
  /** PEM of a CA that proxy needs trusted (optional). */
  caPem?: string | undefined;
  /** GitHub Enterprise or a releases mirror (optional). */
  githubApi?: string | undefined;
  /** The address to listen on (every IPv4 address by default). */
  hostname?: string | undefined;
  /** Spec 049: every event, structured; the window and boot.log render it. */
  emit: (e: ArchonEvent) => void;
  /**
   * Spec 051, off by default (boot serve --stall-watch): name a machine whose
   * installer took the image and went quiet. It guesses which machine from DHCP
   * leases, which installers change mid-install; it is a hint, not a guarantee.
   */
  stallWatch?: boolean;
}

Options for the boot server (bun run stolos boot serve).
