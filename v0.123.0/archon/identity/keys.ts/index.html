archon/identity/keys.ts

Spec 057: your signing keys, checked and fixed by one command. This module gathers the facts (no prompt, nothing written) and turns them into checks, each with a stable code (archon explain E057-...) and the one command that fixes it. stolos keys, stolos keys setup, boot doctor, archon (where am I), and stolos signers all use the same checks.

Two keys, both OpenSSH ed25519 key pairs (spec 047):

  • the daily key (~/.ssh/fleet-signing) signs your commits; it stays on this PC, locked by a passphrase you type each time, never in an ssh-agent;
  • the recovery key replaces a lost daily key; it is made once and kept apart (never on this PC, never in the backup ZIP).
