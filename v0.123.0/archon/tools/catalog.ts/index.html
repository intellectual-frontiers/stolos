archon/tools/catalog.ts

Tool catalog (spec 010, Article 5): the newest stable release of each tool, from its maintainers' PPA or the vendor's own apt repository when there is one (apt keeps it current), else its official binary release (checksum-verified), else Ubuntu's archive (tmux). Nothing is built from source.
