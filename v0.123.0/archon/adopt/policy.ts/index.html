archon/adopt/policy.ts

Spec 067: the policy pack for adopted machines. Each policy reads an observation and says pass, fail, or unknown, with the fix in plain words for that operating system, and names the Secure Controls Framework (SCF) controls it gives evidence for (specs 068 and 071 reach each framework from those through the SCF Council's own mappings). Spec 078: the pack is written on the control SDK ({@link ADOPTED_CONTROLS}), as a fleet's own controls are.

  /** The policy's id. */
  id: string;
  /** What it requires, for people. */
  title: string;
  /** The SCF controls it gives evidence for. */
  scf: string[];
  /** pass, fail, unknown (cannot tell), warn (not required, but worth doing), or accepted (fails, by a recorded decision). */
  status: "pass" | "fail" | "warn" | "unknown" | "accepted";
  /** What was found. */
  detail: string;
  /** How to make it pass, on this machine's OS. */
  fix?: string;
}
