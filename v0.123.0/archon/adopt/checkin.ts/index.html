archon/adopt/checkin.ts

Spec 069: the check-in code. bin/integrate.sh and integrate.windows.ps1 end by printing one line, stolos1:<base64>, that a person pastes into the Stolos Console or the CLI: the machine's public facts (its account, names, addresses, MAC addresses, public SSH host keys) and what its probe found. It is how a machine reports in with no network path back to the PC, and how the PC pins the machine's host keys without trusting the first connection.

The payload is the probe's own format (@section then key=value lines), with an @checkin and a @hostkeys section in front.
