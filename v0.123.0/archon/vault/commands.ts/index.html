archon/vault/commands.ts

bun run stolos vault <sub> (specs 029 and 056): the boot machine's secrets, and their backup. A backup is one ZIP file (see {@link writeBackupZip}), written into stolos's backup folder; you then move it wherever you keep important things safe. vault restore <zip> (spec 061) puts it back on a freshly cloned PC; without a ZIP it prints the steps (constitution Article 22).

flowchart LR
  status["vault status<br/>what changed since the last backup"] --> backup["vault backup<br/>a ZIP in the backup folder"]
  backup --> move["you move the ZIP<br/>somewhere safe"]
  move -. "after a disaster" .-> restore["vault restore &lt;zip&gt;<br/>on the new PC"]
