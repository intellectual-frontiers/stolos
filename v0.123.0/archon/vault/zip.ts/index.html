archon/vault/zip.ts

Spec 056: the boot machine's backup is one ZIP file. bun run stolos vault backup writes it into the backup folder where archon keeps its data (Windows: %LOCALAPPDATA%\stolos\backup; Linux: ~/.local/share/stolos/backup), reads it back to check every file, and tells you to put it wherever you keep important things safe. It holds everything this PC would need again after a disaster: every fleet's secrets (the admin password's hash, each server's SSH host keys and deploy key, the Cloudflare tokens, carried certificates) and your signing key (both halves; the private half stays locked by its passphrase). On a freshly cloned PC, vault restore <zip> (spec 061) puts it all back; RESTORE.txt in every ZIP says the same, with the steps by hand.

flowchart LR
  secrets["%APPDATA%\stolos\secrets\&lt;fleet&gt;\*"] --> zip["stolos-backup-&lt;pc&gt;-&lt;time&gt;.zip<br/>manifest.json, RESTORE.txt"]
  key["your signing key<br/>(git config user.signingkey)"] --> zip
  zip --> check["read back: every SHA-256"]
  check --> you["you move it somewhere safe<br/>(encrypted: OneDrive Personal Vault, a password manager)"]
