archon/install/host-bootstrap.ts

stolos host bootstrap (spec 005): finish a host whose Ubuntu was installed by hand (from Ubuntu's ISO, a cloud image, anything) instead of by network boot. From the boot machine it copies, over SSH, exactly what the network install would have handed cloud-init (the host name, GitHub's host keys, the first-boot script, and the host's deploy key), then runs the same first boot with sudo. Uses the OpenSSH client that ships with Windows and Linux.
