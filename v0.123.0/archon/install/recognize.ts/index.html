archon/install/recognize.ts

Spec 051: how a machine becomes a host when it network-boots. A person chooses, every time, exactly one of:

--claim the next unknown machine to network-boot (within 30 minutes) becomes the host; its MAC is learned from it; --mac-address <mac> only that network card is the host.

There is no default: a choice made without thinking is how the wrong machine gets erased. The one exception is a host that already installed: the MAC its own machine reported (registration.ts, macSource "installed") is a fact, so boot arm may use it without either option.
