archon/install/first-boot.ts

archon first-boot (spec 005): run once by cloud-init on a freshly installed host, after the first-boot script cloned the repository with this host's deploy key. Converges the host, hands the deploy key to ops, verifies, and pushes the host's first record, which proves the key works.

sequenceDiagram
  participant H as The new host
  participant B as Boot server
  H->>H: clone the fleet repository, verify its signature
  H->>B: event: First boot
  H->>H: packages, accounts, files, units, tools, dotfiles
  H->>H: verify (ok, not set up yet, warnings, failures)
  H->>H: archon.sql: install record, inventory
  H->>B: event: Ready (or Done with problems)
  H->>H: start Ubuntu's daily upgrades

export async function firstBoot(host: HostDef): Promise<number>

Runs first boot on a freshly installed host: converge, hand over the delivered credentials and deploy key, verify, and push the first record. Returns 1 when verification found failures, else 0.

How a first boot ends (specs 005, 009, 025, 026): the final Ready (or Done with problems) line to the boot server's window, then the report URL is removed (spec 005 FR-004); the doctor's email checks and the install's message; last, Ubuntu's daily apt run started in the background, so updates published since the installer image install now (spec 009 FR-004).
