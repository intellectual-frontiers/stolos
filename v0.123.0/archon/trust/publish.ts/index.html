Spec 081: what a Trust Center publishes next to its page, and what a public one leaves out.

ShownPublicGated
the company, the period, the signer, when it was signedyesyes
each framework requirement's status, and its SCF controlsyesyes
each control's status, its counts of checks by result, stale countsyesyes
each control's evidence age (newest, oldest observation)yesyes
the SHA-256 of each full-bundle item behind a control, its kind and timeyesyes
subjects (hostnames, accounts, the repository), check titles, what each check foundnoyes
item names (paths, commit ids), people's names and emails in commitsnoyes
the evidence itself (the full bundle)no: a summary bundle, or on requestyes

A public build publishes a summary bundle it derives: the same format as spec 072's (stolos-evidence/1, each item by its SHA-256, hash-chained), signed by the same fleet signer as the full bundle through a signing callback ({@link Signer}, spec 072's sshSigner). Its items are one JSON document per control and one index, holding only what the public column above says, each bound to the full bundle by its manifest head and its own items' SHA-256. A gated build publishes the full bundle as it is.

flowchart LR
  full["full bundle (verified)"] --> model["Trust Center model"]
  model -- "public" --> red["redact: no subjects, details, names"] --> sum["summary bundle: one item per control, signed"]
  model -- "gated" --> pub["the full bundle, as it is"]
  sum & pub --> site["evidence/ next to index.html: objects/&lt;sha256&gt;"]

interfacePublicControl

export interface PublicControl {
  /** SUMMARY_FORMAT. */
  format: string;
  /** Its SCF id. */
  id: string;
  /** Its SCF name. */
  name: string;
  /** What Stolos looks at for it, in plain words (Stolos's text, the same for every fleet). */
  how: string;
  /** Its status. */
  status: TrustControl["status"];
  /** How many checks it has. */
  checks: number;
  /** How many have each result, and how many are stale. */
  counts: TrustControl["counts"];
  /** When its newest and oldest evidence was observed, and how many checks have no time. */
  observed: { newest?: string; oldest?: string; untimed: number };
  /** The full bundle's items behind it: SHA-256, kind, and time only. */
  backedBy: Array<{ sha256: string; kind: string; at: string }>;
}

What a public Trust Center says about one control (and nothing else: see the table above).

  }>;
}
