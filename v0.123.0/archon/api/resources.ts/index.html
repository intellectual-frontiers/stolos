archon/api/resources.ts

Spec 094: the estate's tables and views as REST resources. Each resource, its columns, and their types come from the declarations in ../estate/schema.ts (spec 090), the same ones the SQL is generated from. A request's filters and paging become a SELECT whose names are only declared ones and whose values are bound parameters: nothing a request sends is ever written into the SQL.

interfaceResource

export interface Resource {
  /** Its name: the path is `/v1/<name>`. */
  name: string;
  /** A table or a view. */
  kind: "table" | "view";
  /** What it holds. */
  doc: string;
  /** Its columns, typed. */
  columns: TypedColumn[];
  /** Its order: a table's key, or a view's columns in order (stable pages). */
  order: string[];
}

One estate table or view, as the API serves it.
