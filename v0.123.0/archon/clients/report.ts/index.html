archon/clients/report.ts

Spec 082: stolos clients report --out <folder>: one report per client, each in its own folder (<folder>/<client>/), each read in that client's scope, plus the cross-client summary at the top (numbers only). A folder inside any client's checkout is refused, so no report lands in a client's repository, and each client's folder holds that client's data only.
