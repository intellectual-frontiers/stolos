archon/notify/notify.ts

archon notify (spec 025): major events, by email, to the fleet's shared mailbox. Reporting never fails or slows the action it reports: a message is queued on disk and sent by archon notify flush (a service started at once and a timer every 5 minutes) through Cloudflare's SMTP relay (spec 027), with backoff when it cannot be reached, duplicates dropped by key within an hour, and one summary after a long outage. Nothing secret is ever sent (IFC TypeScript's one redaction, otel.redactText).

flowchart LR
  ev["an event<br/>(apply, verify, backup, watch, notify send)"] --> enq["enqueue<br/>dedupe by key, compose, redact"]
  enq --> spool["spool<br/>one JSON file per message"]
  enq --> kick["kick<br/>start the flush service"]
  kick --> flush["flush<br/>collapse after an outage"]
  spool --> flush
  flush -->|"SMTP, implicit TLS"| relay["Cloudflare relay"]
  relay --> box["the fleet's mailbox"]
  flush -->|"relay fails"| back["backoff: 1, 5, 15, 60, then 180 min"]
  back --> spool

  relay: string;
  /** Reach the relay over IPv4 only (the network has no IPv6). */
  ipv4: boolean;
  /** The fleet's IANA time zone, for local times in messages. */
  timezone: string;
}
