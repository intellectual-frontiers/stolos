archon/console/stolos-server.ts

Spec 066: the Stolos Console's web server, on this PC only.

  • It listens on 127.0.0.1 and answers only requests whose Host is 127.0.0.1 or localhost on its port (a web page elsewhere cannot reach it through DNS rebinding).
  • Sign-in is a one-time launch link the terminal prints (/launch?t=...): it works once, for two minutes, and becomes a session cookie (HttpOnly, SameSite=Strict). No password and no new key: whoever can read your terminal is you.
  • POSTs come from this page only (Origin, and Datastar's own header).
  • Commands run as bun run stolos ... in the fleet repository, one at a time, with this terminal as their input: a passphrase or token is typed there, never in the browser.
  • Under /v1/, a read-only REST API for the estate (spec 094, ../api/handler.ts): GET and HEAD only, for the same signed-in session.
  • Under /audit/<id>/ and /v1/audit/<id>/, the auditor portal (spec 083, ../audit/portal.ts), behind its own one-time link (/audit/launch): an audit-scoped session sees that engagement's routes only.
