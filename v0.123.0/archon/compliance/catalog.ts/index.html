archon/compliance/catalog.ts

Spec 071: the official catalogs, never Stolos's own. The Secure Controls Framework (SCF) workbook, as the SCF Council publishes it, gives each control's name and its mappings (STRM) to SOC 2, HIPAA, PCI DSS, CMMC, NIST SP 800-53 and 800-171, and FedRAMP. Stolos does not redistribute it: each PC downloads the pinned release from the SCF's own repository, checks its SHA-256, reads the workbook here, and keeps what it needs in its cache. NIST's OSCAL catalogs (SP 800-53 Rev 5, SP 800-171 Rev 3) come the same way from NIST's repository, for control titles in OSCAL exports.

flowchart LR
  scf["SCF Council: the workbook (pinned commit, SHA-256)"] --> read["read here (XLSX)"] --> cache["this PC's cache: catalog JSON"]
  nist["NIST: OSCAL catalogs (pinned commit, SHA-256)"] --> cache
  cache --> view["Compliance: names and framework mappings"] & oscal["OSCAL exports"]
