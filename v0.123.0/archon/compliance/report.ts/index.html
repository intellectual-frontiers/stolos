archon/compliance/report.ts

Spec 068: compliance as evidence. Every result Stolos already has (a managed server's verify, an adopted machine's policies, a cloud account's posture, the repository's signatures) is evidence for one or more SCF controls; each control's status is what its evidence says, and each framework requirement's status is what its controls say, through the SCF Council's own mappings (STRM) from the catalog (catalog.ts). Nothing here is asserted without evidence: a control with none says so; and no mapping is Stolos's own: without the catalog, the frameworks say it is not loaded.

    | "device"
    | "cloud"
    | "estate"

  /** Its result. */

  detail: string;
  /** How to make it pass. */
  fix?: string;
  /** Spec 073: when it was observed (ISO), when its source knows. */

  /** Spec 073: the connector it came from (cloud evidence), for its cadence. */
  connector?: string;
