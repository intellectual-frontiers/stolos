archon/compliance/oscal.ts

Spec 071: the fleet's compliance in OSCAL, NIST's machine-readable format, so an assessor's or an agency's tools read it without retyping. Four documents, all to NIST SP 800-53 Rev 5 (the controls FedRAMP and most federal frameworks use), each control reached through SCF's own mappings:

  • a component definition: Stolos, and each source of evidence, with the controls each reaches;
  • a system security plan (SSP): this fleet, its machines, and how each control is implemented, importing NIST's moderate baseline;
  • assessment results: every observation Stolos made, and a finding per control (satisfied or not);
  • a plan of action and milestones (POA&M): each failing check, open, and each accepted risk, as a deviation approved until its date; and (spec 080) each open risk in the fleet's risk register, with its SP 800-30 likelihood, impact, and level; and (spec 088) each open vulnerability a scanner's connector reported, with its CVE, severity, and asset.

UUIDs are UUIDv5 of what they name, so the same fleet exported twice names the same things the same way, and a diff shows only what changed.

flowchart LR
  ev["Evidence (verify, policies, posture, signatures)"] --> scf["SCF controls"]
  scf -- "SCF STRM" --> n53["NIST SP 800-53 Rev 5"]
  n53 --> cd["component definition"] & ssp["SSP"] & ar["assessment results"] & poam["POA&M"]

interfaceOscalInput

export interface OscalInput {
  /** The compliance view, with the SCF catalog loaded. */
  view: ComplianceView;
  /** The fleet. */
  fleet: { id: string; title: string; repo: string };
  /** Its machines. */
  machines: Array<{ name: string; kind: string; os?: string }>;
  /** SP 800-53 control titles, by OSCAL id (when NIST's catalog is on this PC). */
  titles?: Record<string, string>;
  /** The Stolos version. */
  version: string;
  /** When. */
  now: Date;
  /** Spec 080: the risk register (fleets/<fleet>/risks.ts); its open risks go in the POA&M. */
  register?: readonly Risk[];
  /** Spec 088: the open vulnerabilities the scanners' connectors reported; each is an open POA&M item. */
  vulnerabilities?: readonly OpenVulnerability[];
}
