archon/connect/registry-probe.ts

Spec 088: the registry probe. stolos connector add and connector test run this module in a process of its own, with none of the environment but the few variables the engine reads for its paths (so none of your secrets), and no standard input: it imports the connector, reads its declaration, runs its recorded-fixture tests, and prints one line, STOLOS-PROBE <json>. The engine judges what it says (registry.ts). Bun and Node give the process no permission sandbox: the connector's code is read before it is added, as the engine's is.

sequenceDiagram

  participant P as probe (its own process, no secrets)
  S->>P: the module's path (fetched at its pin)
  P->>P: declare: id, labels, OCSF, SCF, fields; run fixtures (recorded answers)
  P-->>S: STOLOS-PROBE {declaration}
  S->>S: checks: id, labels, SCF ids, engine range, fixtures
