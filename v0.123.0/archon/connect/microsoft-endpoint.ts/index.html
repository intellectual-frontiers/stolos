archon/connect/microsoft-endpoint.ts

Spec 087 (part A): Microsoft's endpoint connectors, read-only, each with one Entra ID app registration's client credentials (a client secret):

  • Microsoft Intune, through Microsoft Graph (GET /v1.0/deviceManagement/managedDevices, application permission DeviceManagementManagedDevices.Read.All): every managed device's name, serial number, operating system, primary user, BitLocker or FileVault, last sync, and compliance state.
  • Microsoft Defender for Endpoint, through its own API (GET https://api.security.microsoft.com/api/machines, application permission Machine.Read.All of WindowsDefenderATP): every machine's name, operating system, last seen, onboarding, and sensor health. Defender reports no serial number, so its machines join the estate by hostname.

The same app registration may hold both permissions; each connector asks for a token for its own API only.
