archon/connect/justworks.ts

Spec 091: Justworks (PEO, payroll, and HR), read-only, the roster only: each member's work email, name, whether they are active, start and termination dates, manager, and employment type. Never pay, birth dates, sex, phones, or addresses: the scopes Stolos asks for exclude them, and anything else in the record is dropped as it is read. Evidence for account management (SCF IAC-08) and provisioning (IAC-04), through the estate graph.

Justworks' API is a partner API: OAuth 2.0 (authorization code, then refresh tokens) for apps Justworks approves (partner-api@justworks.com). There is no self-serve token. Stolos keeps the app's client id and secret and a refresh token (valid 30 days), and asks for a fresh access token on each observation.
