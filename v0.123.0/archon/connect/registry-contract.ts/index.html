archon/connect/registry-contract.ts

Spec 088: the contract a registry connector keeps, and how Stolos reads one without trusting it. A connector module default-exports a {@link defineConnector} result, and names two more things:

  • engine: the range of engine versions it supports (">=0.112.0 <1.0.0");
  • fixtures: its recorded-fixture tests ({@link ConnectorFixture}), which Stolos runs itself, against recorded responses only, before it adds the connector and whenever stolos connector test asks.

{@link declare} reads a loaded module into a {@link Declaration}: its id, labels, OCSF classes, the SCF controls its policies cite, its credential's fields, and its fixtures' results. The registry probe runs it in a process of its own, given none of the environment but the engine's paths, and the engine's checks (registry.ts) judge what it reports.

  /** The credential (made up: never a real one). */
  cred: Record<string, string>;
  /** When it observes (ISO; default 2026-01-01T00:00:00Z), so the results do not drift. */
  now?: string;
  /** Each URL's recorded answer; any other URL is refused. */
  responses: Record<string, { status?: number; body: unknown; link?: string }>;

    account?: string;
    /** How many records (entities included) of each label. */
    records?: Record<string, number>;
    /** How many gaps (parts it could not read). */
    gaps?: number;
    /** Posture facts, each exactly. */
    posture?: Record<string, string | number | boolean>;
    /** Policies' statuses, by id. */
    policies?: Record<string, PolicyResult["status"]>;
  };
}
