archon/connect/tenable.ts

Spec 088: Tenable Vulnerability Management (cloud.tenable.com), read-only, through its workbench API: every asset with vulnerabilities in the last 30 days (GET /workbenches/assets/vulnerabilities), each asset's vulnerabilities by plugin (GET /workbenches/assets/{id}/vulnerabilities), and, for the critical and high ones, the plugin's CVEs and when it was first seen on that asset (GET /workbenches/assets/{id}/vulnerabilities/{plugin}/info). Each is a vulnerability record (OCSF Vulnerability Finding, 2002); open ones go in the OSCAL POA&M. Evidence for SCF VPM-06 and VPM-07.

Credential: the API keys of a user made for Stolos with the Basic role (view only), given Can View on the assets' access groups. Docs: https://developer.tenable.com/reference/workbenches-assets-vulnerabilities and https://developer.tenable.com/docs/authorization.

Limits: medium and low findings carry no CVE (one more call each would); at most 2,000 detail calls per observation; info-level findings are left out.
