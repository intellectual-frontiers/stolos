archon/connect/knowbe4.ts

Spec 088: KnowBe4 security awareness training, read-only, through its Reporting API: every training enrollment (who, which module, its status, and when it was completed). A completed (passed) or failed enrollment is a person_record of kind training, the hook spec 077's people/training control reads beside people/training.ts; the rest are counted (in progress, not started, past due). Evidence for awareness training and its records (SCF SAT-04, SAT-10).

Credential: the Reporting API key (Account Settings > Account Integrations

API > Reporting API), which can only read. One call per 500 enrollments.

Docs: https://developer.knowbe4.com/rest/reporting (base URLs per region: us, eu, ca, uk, de; Authorization: Bearer <key>; page and per_page).
