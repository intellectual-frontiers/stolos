archon/telemetry/signals.ts

Spec 049-telemetry (Article 27): every signal Archon emits, declared once. core/telemetry.ts makes IFC TypeScript's signal registry from these lists. The telemetry module accepts only these names (TypeScript checks every call), man 7 archon-telemetry is rendered from this list, and the tests read it.
