archon/core/net.ts

The boot machine's LAN addresses and the Boot URIs built from them (spec 004), from IFC TypeScript's proc.networkInterfaces.

Example

import { bootUri } from "./net.ts";
bootUri("10.0.0.5", 8080, "alpha"); // "http://10.0.0.5:8080/boot/alpha/bootx64.efi"
