archon/core/announce.ts

Tell a running boot server something happened on this PC (spec 004): an event (spec 049) it records and shows in its window and boot.log. Arming, for example, is only a file the server reads when a machine contacts it, so without this the window stays silent until the host network-boots. Loopback only; best effort: no server running is not an error.

functionannounce

export async function announce(
  event: Pick<ArchonEvent, "name" | "host" | "message" | "attrs">,
  port = Number(proc.env.get("ARCHON_BOOT_PORT")) || 8080,
): Promise<boolean>

POST event to the boot server on loopback (port, default ARCHON_BOOT_PORT or 8080), waiting at most 1.5 seconds. Returns whether the server accepted it; false when none is running.
