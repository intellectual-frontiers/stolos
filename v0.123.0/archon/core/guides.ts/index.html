archon/core/guides.ts

The guides: each is the @module documentation of the module beside the code it explains (so tools/docs.ts renders it, with its Mermaid diagrams, and it changes in the same commit as the code). The build extracts each one into the engine's assets as docs/<name>.md, so the man pages, the welcome page, both consoles, explain, and stolos docs read the same text offline.

flowchart LR
  mod["src/archon/pg/mod.ts<br/>@module JSDoc: the guide"] --> pages["tools/docs.ts: HTML on GitHub Pages"]
  mod --> gen["bun run gen: assets.auto.ts<br/>docs/pg.md"]
  gen --> man["man pages"] & web["welcome page and consoles"] & cli["stolos docs pg"]
  mod --- code["src/archon/pg/*.ts: the code it explains"]
