archon/mcp/server.ts

archon mcp: a Model Context Protocol server over stdio (JSON-RPC 2.0, newline-delimited), implemented natively without an SDK (Article II). Every registry command within the tier limit is a tool; docs, specs, runbooks, and reports are resources. Workstations reach it on a server as ops over SSH, forced to archon mcp --max-tier <tier> (spec 030): the limit is enforced here, on the server, whatever the client is configured to do.

interfaceMcpTool

export interface McpTool {
  /** The tool's name (see mcpToolName). */
  name: string;
  /** A human title: `archon <command>`. */
  title: string;
  /** The summary, the description's first paragraph, the tier and the man page. */
  description: string;
  /** JSON Schema for the arguments: the command's own and `host`, without person-only ones. */
  inputSchema: {
    /** Always "object". */
    type: "object";
    /** One JSON Schema per argument (type, description, default). */
    properties: Record<string, unknown>;
    /** Names of the required arguments. */
    required: string[];
  };
  /** MCP hints for clients. */
  annotations: {
    /** True for read-tier commands. */
    readOnlyHint: boolean;
    /** True for destructive-tier commands (never served). */
    destructiveHint: boolean;
    /** True for read-tier commands and apply. */
    idempotentHint: boolean;
  };
}

An MCP tool definition, as tools/list returns it.
