archon/controls/run.ts

Spec 078: a fleet's control packs, loaded and run. Each pack is a folder, fleets/<fleet>/controls/<pack>/, whose pack.ts exports the pack (as pack, or as its default export) and whose *_test.ts files test it. Risks the owner accepted are in fleets/<fleet>/controls/accepted.ts (exporting accepted), each naming a result as <pack>/<control>.

flowchart LR
  packs["fleets/&lt;fleet&gt;/controls/*&#47;pack.ts"] --> load["loadControlPacks"]
  load --> run["runPack"]
  estate[("estate graph")] --> run
  probe["adopted machines: osquery through the probe"] --> run
  obs["observations: adopted, devices, accounts"] --> run
  run --> results["results: &lt;pack&gt;/&lt;control&gt;, per subject"]
  results --> compliance["stolos compliance, the Compliance tab: source control pack"]

An osquery control asks the machines only when stolos controls run runs; each machine's answer is kept in this PC's state, and the consoles and stolos compliance assert over the answers kept (so a change to the assertion shows at once, and nothing is asked of a machine to draw a page).
