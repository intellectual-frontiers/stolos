archon/backup/backup.ts

Backups (spec 016, Article 14): zstd tar archives of the host's own state and its durable data (spec 044), kept to a retention count, with a restore test. Never restores in place: a restore extracts into a directory for you to inspect.

functionbackupRun

export async function backupRun(host: HostDef): Promise<BackupResult>

Write a zstd tar archive of the host's backup paths (those that exist), prune old archives to the policy's keep, journal it, then export each durable guest (spec 044). Throws when tar fails (exit code above 1).

functionbackupVerify

export async function backupVerify(host: HostDef): Promise<VerifyResult>

Restore-test the newest archive (Article 14): list it, then extract etc/archon/host into a temporary directory and check it names this host. Changes nothing on the live system.
