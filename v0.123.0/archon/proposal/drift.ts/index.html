archon/proposal/drift.ts

Spec 095-proposals: drift is what the host has, minus the plan, minus the birth snapshot (what Ubuntu itself put on the host at install), so Ubuntu's own changes (unattended upgrades, a package's own presets) are never drift (Article 2). Each item carries who changed it and when (from the observations), and the model change that would adopt it.

flowchart LR
  state["what the host has<br/>(packages, units, /etc, ports, accounts, files)"] --> minus1["minus the plan"]
  minus1 --> minus2["minus the birth snapshot"]
  minus2 --> items["drift items"]
  obs["observations<br/>(sudo, apt, etckeeper, osquery, ...)"] -->|who, when| items
  items --> edits["the edit that adopts each:<br/>packages.add, units.enable, ports.open, files.override"]
