archon/proposal/record.ts

Spec 095-proposals: recording mode and reminders. archon record "nginx for the app", then the work, then archon record done: everything observed in between is one intent, with that reason, ready for archon propose --intent <id>. And so nothing waits forever, the daily report and archon doctor count drift not proposed and proposals not decided; after 3 days the daily report mails a reminder (at most every 3 days).

sequenceDiagram
  participant A as a person (sudo)
  participant S as archon
  A->>S: archon record "nginx for the app"
  A->>S: sudo apt install nginx, edit, enable ...
  A->>S: archon record done
  S->>S: collect; everything seen in between is intent r-...
  A->>S: sudo archon propose --intent r-...
