archon/proposal/collect.ts

Spec 095-proposals: the collectors. Each reads one of Ubuntu's own records (journald's sudo entries, apt's history.log and dpkg.log, etckeeper's git log, osquery, systemctl list-unit-files, snapd, podman, dpkg -S on /usr/local and /opt, debsums -c or dpkg --verify) and writes observations (what, who, when, source) into the host's own archon.sql, with the latest state and, once, the birth snapshot. Nothing here changes the host. A modified package binary is a security alert, mailed at once and never proposed.
