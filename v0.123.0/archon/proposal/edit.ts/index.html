archon/proposal/edit.ts

Spec 095-proposals: turning an accepted proposal into a model change. The structured edits become one adopted({...}) in the host's capabilities (bare keys, written by tsLiteral), with its import. Before anything is written, each edit is compared with the model as it is now: what the model already does is left out, and what the model does otherwise (a unit it sets, a file it writes) is a conflict, named with the spec that owns it, never guessed at.

flowchart TD
  p["accepted proposal: structured edits"] --> c{"compared with the model now"}
  c -->|"already so"| skip["left out (named)"]
  c -->|"the model says otherwise"| conflict["a conflict: named, nothing written<br/>(--skip it, or change that capability by hand)"]
  c -->|new| add["adopted({...}) in host.ts<br/>+ a draft spec + the decision"]
  add --> build["stolos build, then you run stolos apply"]
