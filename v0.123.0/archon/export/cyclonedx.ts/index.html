archon/export/cyclonedx.ts

Spec 092: the fleet's compliance as a CycloneDX 1.6 attestation (CDXA): the standard, what the fleet claims for each requirement, the evidence behind each claim, and how far each claim conforms.

  • definitions.standards: the Secure Controls Framework, by release, whose requirements are the SCF controls Stolos gives evidence for (scf.ts), with SCF's description when the catalog is on this PC.
  • declarations.claims: one per control. The target is the fleet; the predicate is what Stolos looks at, in plain words (scf.ts how).
  • declarations.evidence: each check's result (named by its OSCAL observation's UUID, urn:uuid:..., the same as in the assessment results made at the same time) and, when a spec 072 evidence bundle is given, each item in it by its path there (objects/<sha256>). Each claim names the bundle by its SHA-256.
  • declarations.attestations: the fleet (a self-assessor) maps each requirement to its claim, with a conformance score: the share of the control's checks that pass (0 without evidence), and why.
  • declarations.affirmation: the fleet signer who signed the bundle (or the one given), named, with no signature here: the signature is the bundle's (spec 072), which the signatory's external reference points to.
flowchart LR
  std["definitions.standards: SCF (release)"] --> req["requirements: SCF controls"]
  req --> map["attestation map: conformance score"]
  claim["claims: one per control (target: the fleet)"] --> map
  ev["evidence: check results (OSCAL observation UUIDs), bundle items (SHA-256)"] --> claim
  aff["affirmation: the fleet signer (signature: the bundle's)"]

The same input exports the same document: the serial number is a UUIDv5 of the fleet and the time.

interfaceCdxAttestation

export interface CdxAttestation {
  /** CycloneDX. */
  bomFormat: "CycloneDX";
  /** 1.6. */
  specVersion: "1.6";
  /** urn:uuid:<UUIDv5 of the fleet and time>. */
  serialNumber: string;
  /** 1. */
  version: 1;
  /** When, and the tool that made it. */
  metadata: {
    timestamp: string;
    tools: {
      components: Array<{
        type: "application";
        name: string;
        version: string;
        supplier: { name: string };
      }>;
    };
  };
  /** The standard. */
  definitions: {
    standards: Array<{
      "bom-ref": string;
      name: string;
      version: string;
      description: string;
      owner: string;
      requirements: Array<{ "bom-ref": string; identifier: string; title: string; text?: string }>;
      externalReferences: CdxExternalReference[];
    }>;
  };
  /** The claims, their evidence, the attestation, and the affirmation. */
  declarations: {
    assessors: Array<{ "bom-ref": string; thirdParty: false; organization: { name: string } }>;
    attestations: Array<{
      summary: string;
      assessor: string;
      map: Array<{
        requirement: string;
        claims: string[];
        conformance: { score: number; rationale: string };
      }>;
    }>;
    claims: CdxClaim[];
    evidence: CdxEvidence[];
    targets: {
      components: Array<{
        "bom-ref": string;
        type: "platform";
        name: string;
        externalReferences: CdxExternalReference[];
      }>;
    };
    affirmation: {
      statement: string;
      signatories?: Array<{
        name: string;
        role: string;
        organization: { name: string };
        externalReference: CdxExternalReference;
      }>;
    };
  };
}
