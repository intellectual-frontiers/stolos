archon/audit/case.ts

Spec 083: one engagement, read and checked: its file and the commit that vouches for it, its evidence bundle (verified with verifyBundle), the population of each control in scope, the trail with each entry's commit, and each recorded sample redrawn from its seed. The portal reads it from the fleet repository ({@link loadAudit}); stolos audit verify reads the same from an export package, offline, with the same code.

flowchart LR
  repo["the fleet repository (HEAD)"] --> parts["parts: engagement.ts, trail/*.md, raw commits, the bundle"]
  pkg["an export package (ZIP)"] --> parts
  parts --> assemble["assemble: proofs, verifyBundle, populations, samples redrawn"]
  assemble --> portal["the portal"] & verify["stolos audit verify"]
