archon/people/commands.ts

Spec 077: stolos people [status|review|ack], on the controller PC.

  • people status: every people control now (the estate's leavers first), and each leaver account's time to deprovision. Read-only.
  • people review [--quarter 2026-Q4]: one review file per manager, on a branch, signed, pushed, and opened as a pull request with gh.
  • people ack <policy>: your acknowledgement of a policy's current version: a line in policies/acks/<policy>.ts, in a commit signed with your own key that carries Acknowledges: <policy>@<version>.
