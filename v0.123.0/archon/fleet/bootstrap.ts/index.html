archon/fleet/bootstrap.ts

Spec 062: the bootstrap scripts that make a PC a Stolos controller (the pinned Bun, Git, gh, the GitHub sign-in, the fleet cloned into $HOME/fleet, the stolos shortcut). The engine publishes them with every release, bin/bootstrap.sh and bin/bootstrap.windows.ps1 (carried in {@link ASSETS}), which a new PC runs with --repo; a fleet repository gets its own copy as bin/bootstrap.sh and bin/bootstrap.windows.ps1 with its repository filled in, from fleet init and fleet upgrade.

flowchart LR
  tpl["engine: bin/bootstrap.*<br/>(--repo required)"] --> init["fleet init / fleet upgrade"]
  init --> copy["fleet: bin/bootstrap.*<br/>(its owner/name filled in)"]
