archon/pg/connections.ts

043-pg-connections: what this account's libpq would use, and how to reach an instance. Read-only; nothing on the host changes.

archon pg connections every entry of the password file and every section of the service files, matched as libpq matches them archon pg show NAME how to reach an instance, as conninfo, URL, PG* environment, or a service section

A password is never printed, logged, or returned: the password field is dropped the moment a password-file line is split, and a password key in a service file is dropped as it is read. Only whether one is there is kept.

export interface ConnectionsReport {
  /** The password file: where it is, its mode, and whether libpq would use it. */

    path: string;

    mode: string | null;
    usable: boolean;
    problem: string | null;
  };

  /** Each password-file entry, the services it serves, and its problems. */
  entries: Array<{
    line: number;
    host: string;
    port: string;
    database: string;
    user: string;
    services: string[];
    usable: boolean;
    problems: string[];
  }>;
  /** Each service section in effect (a user's section hides a system one of the same name). */
  services: Array<{
    name: string;
    file: string;
    source: ServiceSection["source"];
    host: string;
    port: string;
    database: string;
    user: string;
    sslmode: string | null;
    /** The password-file line libpq would use for it (null: none; peer or a prompt). */
    passwordEntry: number | null;
    problems: string[];
  }>;
}
