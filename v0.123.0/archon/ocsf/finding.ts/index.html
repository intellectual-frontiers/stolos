archon/ocsf/finding.ts

Spec 089: every check's result as an OCSF 1.9.0 Compliance Finding (class 2003), written by IFC TypeScript's kernel (ocsf.complianceFinding) from the evidence's GRC findings (compliance/findings.ts): one per piece of evidence and SCF control. The compliance object names the standard (SCF, by release), the control, and, when the SCF catalog is on this PC, the framework requirements SCF maps it to (<framework>:<requirement>). Typed by the kernel's OCSF types, so a missing required field does not compile.
