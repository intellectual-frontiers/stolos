Spec 072: evidence bundles. One ZIP holds a period's evidence (the observations as Git recorded them, the verify results, the commits with their signatures, and the OSCAL assessment results), each item stored under its own SHA-256 (content-addressed), listed in a manifest in order, each entry chained to the one before (a hash chain), and the manifest signed by a fleet signer's key (ssh-keygen -Y sign, namespace stolos-evidence). An auditor re-checks it offline: every item unchanged, none missing or added, the chain whole, the manifest signed by a signer, and each commit signed as Git signs it.

flowchart LR
  items["items: observations, verify, commits, OSCAL"] --> objects["objects/&lt;sha256&gt;"]
  objects --> manifest["manifest.json: each item's SHA-256, chained"]
  manifest --> sig["manifest.json.sig (a fleet signer)"]
  sig --> verify["stolos evidence verify: offline, with the reason for any failure"]

The ZIP also holds allowed_signers (the fleet's signers when it was made) and a README saying how to check it with sha256sum and ssh-keygen alone. The signers in a bundle vouch for themselves: an auditor who has the fleet's signers from elsewhere passes them with --signers.

Manifest

The manifest: what the signature covers.

  • created: string

    When it was made.

  • fleet: { id: string; title: string; repo: string; }

    The fleet.

  • format: string

    BUNDLE_FORMAT.

  • head: string

    The last entry's chain (the genesis when there are none).

  • items: ManifestItem[]

    The items, in order.

  • omitted: string[]

    Evidence that could not be included, and why.

  • period: { from: string; to: string; }

    The period (ISO dates, both included).

  • signer: string

    Who signed it (their name in signers.ts).

  • stolos: string

    The Stolos version that made it.

I
ManifestItem

One item in the manifest.

  • at: string

    When it was recorded.

  • chain: string

    The chain so far: SHA-256 of the previous entry's chain and this entry.

  • kind: ItemKind

    What it is.

  • name: string

    Its name for people.

  • sha256: string

    Its SHA-256: its object is objects/<sha256>.

  • size: number

    Its size in bytes.

I
VerifyResult

What verify found.

  • commits: Array<{ name: string; signer?: string; }>

    Commits whose Git signature verified, and by whom.

  • manifest: Manifest

    The manifest, when it could be read.

  • ok: boolean

    True when nothing is wrong.

  • problems: string[]

    Each problem, with its reason.

  • signer: string

    Who signed the manifest, when the signature verified.
