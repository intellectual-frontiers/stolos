Spec 095-proposals: the collectors' parsers. Each reads one source's own output, exactly as the tool writes it (journald's JSON, apt's history.log, dpkg.log, etckeeper's git log, osquery's JSON, systemctl list-unit-files, snap changes, dpkg -S, debsums -c or dpkg --verify), and returns observations: what changed, who changed it, when, and where it was seen. Pure functions, so each is tested on fixtures (tests/proposals095_test.ts).

apt's /var/log/apt/history.log: blocks of Start-Date, Commandline, Requested-By (the person behind sudo), Install, Remove, Purge, End-Date. Upgrades are Ubuntu's (unattended-upgrades) and never drift; packages apt pulled in by itself (automatic) are left out.

Interfaces

I
EtcCommit

One etckeeper commit: who, when, its message, and the files it changed.

  • at: string

    When (ISO).

  • author: string

    Its author (etckeeper writes the person behind sudo).

  • files: Array<{ status: string; path: string; }>

    Changed files, as absolute paths, with git's status letter.

  • hash: string

    The commit.

  • subject: string

    Its subject.

I
OsquerySnapshot

What osquery saw at one time: the tables a proposal compares between snapshots.

  • at: string

    When (ISO).

  • modules: string[]

    kernel_modules: names.

  • packages: Record<string, string>

    deb_packages: name to version.

  • ports: string[]

    listening_ports: "tcp/443" (not loopback).

  • sudoers: string[]

    sudoers: "source: header rule_details" lines.

  • users: Record<string, string>

    users: name to "uid shell".

I
SudoEntry

One sudo command from journald.

  • as: string

    As whom it ran (USER=).

  • at: string

    When (ISO).

  • command: string

    The command, as sudo logged it.

  • pwd: string

    Its working directory (PWD=).

  • who: string

    Who ran it.

I
UnitFileState

A unit file's state and its vendor preset (what the package asked for).

  • preset: string

    The preset: enabled, disabled, or empty.

  • state: string

    enabled, disabled, masked, static, ...
