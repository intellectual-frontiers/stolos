providers

The fleet's outside providers as explicit choices (spec 046). Each is a closed set: the engine implements exactly these, so a typo or an unsupported provider fails stolos build (TypeScript), not a host.

Source: src/archon/model/providers.ts

DEFAULT_PROVIDERSconst
const DEFAULT_PROVIDERS: ProvidersDef

The providers a fleet gets when it names none: Cloudflare for DNS and mail, Let's Encrypt for certificates.

providersOffunction
function providersOf(fleet: Pick<FleetDef, "providers">): ProvidersDef

The fleet's providers, with the defaults filled in.

ACME_DIRECTORIESconst
const ACME_DIRECTORIES: Record<"letsencrypt" | "letsencrypt-staging", string>

Each ACME provider's directory (RFC 8555).

isReservedDomainfunction
function isReservedDomain(domain: string): boolean

Names reserved for documentation and tests (RFC 2606, RFC 6761): example.com, example.net, example.org, and the .test, .example, .invalid, .localhost domains. No provider can hold them, so a synthetic fleet uses them and the checks that ask the outside world about a domain skip them.
