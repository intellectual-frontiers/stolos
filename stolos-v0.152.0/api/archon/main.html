main

The command line, for both commands (spec 059): archon on each machine (servers, workstations) and stolos on your PC (src/stolos/main.ts), over one registry where every command says where it runs. See archon(1).

Source: src/archon/main.ts

ensureHomefunction
function ensureHome(): Promise<void>

cloud-init (the first boot) and some service managers start archon without $HOME. Tools assume it (chezmoi refuses to run, so its smoke test failed and it was rolled back on alpha' first boot): take it from the account database.

localHostNamefunction
function localHostName(): Promise<string>

This host's name in the model: /etc/archon/host, else the short hostname.

Surfacetype
type Surface = "pc" | "machine";

Which command this is: stolos on your PC, archon on a machine.

commandNameconst
const commandName: (s: Surface) => string

The command's name for a surface.

mainfunction
function main(argvIn: readonly string[], surface?: Surface): Promise<number>

The CLI: parses global options, finds the command offered here, and runs it. Returns the exit code. The passphrase the command held in memory is wiped when it ends (spec 106-one-passphrase-speed FR-002).

runCommandNestedfunction
function runCommandNested(argv: readonly string[], surface: Surface): Promise<number | undefined>

A registry command run as a phase of the run that is running now, in this process (spec 106-one-passphrase-speed FR-006): what main does between the options and the closing summary, with no header, no summary, no log of its own and no second telemetry run (the parent's). Gives the exit code, or undefined where the command needs a process of its own (sudo, the host lock, a precheck, an unknown command), which the caller then starts.

runfunction
function run(argv?: readonly string[], surface?: Surface): Promise<never>

Run as a program and exit: from this file, or from a fleet repository's own entry file, which imports this one by the package's name (spec 096).
