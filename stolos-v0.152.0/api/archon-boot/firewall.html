firewall

Firewall check for boot serve (spec 004): warn, with the exact command, when this machine's firewall would block servers from reaching TFTP (UDP) or HTTP (TCP). Read-only: it never changes a firewall rule. Windows Defender Firewall, ufw, and firewalld; anything else is not checked.

Source: src/archon-boot/firewall.ts

A port the boot server needs reachable from the network.

MemberTypeWhat it is

portnumberThe port number.

MemberTypeWhat it is

interface FirewallOptions

What a firewall check is given (tests replace the reading and the limit).

MemberTypeWhat it is

What is said where the firewall could not be read in time: a warning, with what to do by hand.

firewallWarningsfunction
function firewallWarnings(needs: Need[], o?: FirewallOptions): Promise<string[]>

Warnings for this machine's firewall; empty when it is fine. Reading it has a hard time limit (FIREWALL_LIMIT_MS, spec 106-one-passphrase-speed FR-008): where it could not be read in time (or at all) the answer is one warning saying so, with what to do by hand, and nothing waits longer. The answer is kept for five minutes in the program's state folder, unless the run is a report, --verbose or --fresh (or the caller asks for fresh), and is not kept where the check could not be completed.
