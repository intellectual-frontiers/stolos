OptInRowinterface
interface OptInRow

One optional service, as the console shows it.

MemberTypeWhat it is
namestringIts switch (pg, s3, smb, otel-ui).
titlestringIts name for people.
onbooleanOn or off.
data?stringdurable, ephemeral, "unchosen", or undefined when it holds no user data.
since?stringWhen it was last switched (ISO time).
by?stringWho switched it.
commands{ on: string; off: string; status: string; }The commands that turn it on and off, and show it.
UnitRowinterface
interface UnitRow

One unit of the host's plan, with its live state.

MemberTypeWhat it is
unitstringThe unit's name.
specstringThe spec that wants it.
activestringsystemd's ActiveState: active, failed, inactive, ...
substringsystemd's SubState: running, exited, dead, ...
enabledstringIts unit file's state: enabled, disabled, masked, static, ...
