network-posture

Spec 111-network-posture: the network as an asset class has posture policies. One pack of nine policies runs over the last observation of the routers' controllers (the official UniFi Network 10.3.58 API, read-only, spec 109), the fleet's network assets (spec 110), its tags (spec 108) and its network.ts, and says for each: pass, fail, warn, not observed yet (spec 117), or accepted (spec 078), with the items it is about, the SCF controls it gives evidence for, an explain code and the fix.

What the data cannot support is not a policy: NETWORK_GAPS lists it with its reason and the field the document lacks. A policy that does not apply (no guest Wi-Fi network, no adopted asset) is listed as not applicable and gives no evidence.

Source: src/archon/connect/network-posture.ts
