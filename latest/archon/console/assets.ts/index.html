• Stolos v0.97.0
    • archon/console/assets.ts

Specs 065 and 066: what both consoles serve besides their pages: one stylesheet (color tokens, light and dark), the Archon and Stolos logos, and Datastar (vendored, pinned by its SHA-256, served from the machine itself: no CDN, no build step).

Datastar's source, as the engine carries it.

f
sha256Hex(data: Uint8Array<ArrayBuffer>): Promise<string>

SHA-256 of some bytes, as lowercase hex.

f
vendored(
file: { path: string; sha256: string; },
cacheDir: string,
base?: string
): Promise<Uint8Array<ArrayBuffer> | undefined>

A large vendored file, from beside this engine (the checkout, or the release on GitHub this engine was imported from), checked against its SHA-256 and kept in cacheDir (fetched once per version). Undefined when it cannot be had or does not match: the page then works without it.
