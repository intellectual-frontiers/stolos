archon/console/pam.ts

Spec 065: checks a username and password with Linux itself (PAM). The console calls it in a worker thread ({@link pamAuthenticator}): pam_unix waits about two seconds after a wrong password, and the web server must not stop answering meanwhile. The service is archon-console (/etc/pam.d/archon-console: common-auth and common-account, as Ubuntu's own services use them); the console's account is in the shadow group, so pam_unix can read the password hashes.

libpam and libc are called through Bun's FFI (bun:ffi, spec 096 FR-010): this is the one file of the engine that names it, and it loads it only on Bun. On Node the password sign-in is refused as not supported ({@link PAM_UNSUPPORTED}). The PAM conversation answers the username prompt and the password prompt, and nothing else.
