archon/web/cloudflare.ts

032-web: the few Cloudflare API calls a server needs to keep its own DNS records (its name and wildcard, both to its private address, not proxied). The token needs Zone: Read and DNS: Edit on the zone (the same token Traefik uses for Let's Encrypt's DNS challenge).
