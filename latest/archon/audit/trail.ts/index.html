archon/audit/trail.ts

Spec 083: the audit trail. Every request the auditor makes, every response the company gives, and every sample drawn is one file in fleets/<fleet>/audits/<id>/trail/, numbered in order (0001-request.md, 0002-response.md, 0003-sample.md), added in a commit of its own signed with a fleet signer's key. The commit names the file and its SHA-256 in a trailer, so the signature covers the entry's exact text and an auditor checks it with the commit alone:

audit soc2-2026: request 3 (CC6.2)

Audit-Entry: fleets/lab/audits/soc2-2026/trail/0003-request.md sha256:<hex>

engagement.ts carries the same trailer in each commit that writes it. An entry is a Markdown file with front matter, each value one line of JSON:

---
seq: 3
kind: "request"
at: "2026-11-02T15:04:05Z"
by: "Dana Example (Example CPA)"
control: "CC6.2"
---

Please show each sampled leaver's accounts on their last day.
sequenceDiagram

  participant C as Company (a fleet signer)
  participant G as Fleet repository
  A->>C: a request (email, the portal's address)
  C->>G: stolos audit request: trail/000n-request.md, a signed commit
  C->>G: stolos audit respond: trail/000m-response.md, a signed commit
  A->>G: the portal or the export: each entry, its commit, its signer
