archon/audit/sample.ts

Spec 083: samples, drawn so the auditor can draw them again. The auditor gives a seed (any text: a number they chose, or a value from a public randomness source they chose, such as a published beacon pulse; Stolos only accepts it) and a sample size (theirs to choose, by their firm's methodology). The method is simple random sampling without replacement by random sort keys, deterministic from the seed:

  1. each unit's key is sha256(seed + "\n" + unit id), in lowercase hex;
  2. the units are ordered by key (then by id, should two keys be equal);
  3. the sample is the first size units (every unit, when the population is smaller).

Every subset of that size is equally likely when SHA-256's output is uniform, and no step depends on Stolos: a shell redraws it.

while read -r id; do
  printf '%s %s\n' "$(printf '%s\n%s' "$SEED" "$id" | sha256sum | cut -d' ' -f1)" "$id"
done < unit-ids.txt | LC_ALL=C sort | head -n "$SIZE" | cut -d' ' -f2-
flowchart LR
  seed["the auditor's seed"] --> key["key = sha256(seed, newline, unit id)"]
  pop["the population's unit ids"] --> key
  key --> sort["order by key"] --> take["the first n: the sample"]
  take --> trail["recorded in the trail: seed, method, size, population hash, units"]
