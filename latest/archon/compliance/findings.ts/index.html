archon/compliance/findings.ts

Specs 068, 089 and 092: Stolos's evidence as IFC TypeScript's GRC findings (kernel grc), the one model every export is written from. A piece of evidence (spec 068: a check's result on a subject, citing SCF controls) becomes one finding per SCF control it cites: the control is the SCF control, implementing the framework requirements the SCF Council maps it to (its STRM, when the catalog is on this PC); the subject is the source and what it is about; the check is the finding's title.

Example

import { evidenceFindings } from "./findings.ts";
import { grc } from "@intellectual-frontiers/ifc-ts/kernel";
const at = grc.instantOf("2026-11-15T12:00:00Z");
if (at !== undefined) {
  evidenceFindings({ scf: ["CRY-07"], subject: "alpha", source: "managed", check: "The disk is encrypted",
    status: "pass", detail: "LUKS" }, { at }).length; // 1
}
