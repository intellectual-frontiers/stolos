archon/model/providers.ts

The fleet's outside providers as explicit choices (spec 046). Each is a closed set: the engine implements exactly these, so a typo or an unsupported provider fails stolos build (TypeScript), not a host.

export function isReservedDomain(domain: string): boolean

Names reserved for documentation and tests (RFC 2606, RFC 6761): example.com, example.net, example.org, and the .test, .example, .invalid, .localhost domains. No provider can hold them, so a synthetic fleet uses them and the checks that ask the outside world about a domain skip them.
