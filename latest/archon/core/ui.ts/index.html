Calm output (Article XXII, spec 018): quiet on success, loud and actionable on problems, full detail always in the log. Native Deno only.

✅ Packages 86 installed (1m12s) ⠸ Files [██████░░░░] 30/47 /etc/ssh/sshd_config.d/50-archon.conf

Terminal: spinner, progress bar, in-place redraw, colors, emoji. Pipe/timer/journald: plain final lines only. NO_COLOR disables color. Non-UTF-8 locale or ARCHON_PLAIN=1: ASCII marks ([ok] [warn] [FAIL]).

defaultLogPath(): string | null

Where this run's log goes: /var/log/archon as root; else the program's folder (Windows: %LOCALAPPDATA%\stolos\log; Linux: ~/.local/state/<program>/log).

f
emojiTerminal(): boolean

Can this terminal show emoji? A UTF-8 locale says so on Linux. Windows sets no locale variables, so its modern terminals are recognized directly: Windows Terminal (WT_SESSION), VS Code and others (TERM_PROGRAM), ConEmu. ARCHON_PLAIN=1 turns them off; ARCHON_EMOJI=1 turns them on.

UiOptions

How a Ui draws: the defaults come from the terminal and the environment.

  • color: boolean

    Use color; default: a terminal without NO_COLOR.

  • emoji: boolean

    Use emoji; default: where the terminal shows them.

  • logPath: string | null

    The run's log file (null: none).

  • now: () => number

    The clock, in milliseconds (tests give their own).

  • quiet: boolean

    Show nothing (the log still records everything).

  • tty: boolean

    Draw for a terminal (spinner, redraws); default: stdout is a terminal.

  • verbose: boolean

    Show every item as it happens, dimmed.

  • write: (s: string) => void

    Where output goes; default: stdout.

Type Aliases

T
Level = "ok" | "warn" | "fail" | "defer" | "skip"

How a phase ended: ok, with warnings, failed, deferred (a disruptive change left for later), or skipped.

T
ProblemLevel = "warn" | "fail" | "pending"

Spec 052: four states, the same everywhere. "fail" and "warn" are problems; "pending" is something not set up yet, expected until someone does it (a token not pushed, a certificate not issued yet): shown with its next step, never a failure, never counted as a warning.
