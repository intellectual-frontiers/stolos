archon/capabilities/adopted.ts

095-proposals: what a host adopted from a proposal. stolos proposal accept adds one adopted({...}) to the host's capabilities per accepted proposal, naming the proposal and the draft spec it wrote, so every item that began as a change made on the server is in the model with its reason. Edit it like any other part of the model.

Overrides of Ubuntu defaults: only what the proposal adopted (a unit enabled, disabled, or masked against its package's preset), each listed in the draft spec.

Example

import { adopted } from "./adopted.ts";

const nginx = adopted({
  proposal: "alpha-20261114-1905-ab12",
  spec: "096-alpha-nginx-for-the-app",
  packages: ["nginx"],
  enable: ["nginx.service"],
  ports: [{ port: 443, protocol: "tcp" }],
});

interfaceAdoptedDef

export interface AdoptedDef {
  /** The proposal it came from. */
  proposal: string;
  /** The draft spec `accept` wrote for it. */
  spec: SpecId;
  /** apt packages to install. */
  packages?: string[];
  /** Snaps to install. */
  snaps?: string[];
  /** Units Ubuntu ships, to enable and start. */
  enable?: string[];
  /** Units to disable. */
  disable?: string[];
  /** Units to mask. */
  mask?: string[];
  /** Ports to open in the firewall. */
  ports?: Array<{ port: number; protocol: "tcp" | "udp" }>;
  /** Files to write (small, non-secret text). */
  files?: Array<{ path: string; content: string; mode: string; owner: string; group?: string }>;
}
