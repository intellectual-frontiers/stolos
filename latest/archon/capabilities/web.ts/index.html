archon/capabilities/web.ts

032-web: every server is HTTPS-ready from its first boot. Traefik (the official release binary, installed by the tools sync) on 80 and 443, open to everyone at the server's firewall, and no network allowlist behind it: who reaches the server is the router's decision (the firewall at the edge, outside the machine). The Archon Console (archon web serve, loopback only, spec 065) answers https://<host>.<domain> and any name or address nothing else claims. Podman (Ubuntu's package) is the container runtime: containers that carry traefik.enable=true get <container>.<host>.<domain>.

Overrides of Ubuntu defaults: Traefik is not Ubuntu's (Ubuntu's nginx and Apache cannot obtain certificates by themselves; Traefik's official binary does Let's Encrypt's DNS challenge with Cloudflare built in, and reads container labels). The Podman socket is group archon-web, mode 0660.
