archon/otelui/otelui.ts

Spec 050-telemetry-ui: OpenObserve as an opt-in on any server. Until it is turned on, the headless Collector does what it always did. Once it is on:

Only telemetry from then on is forwarded: nothing is replayed.

  • its admin credentials are generated here, root only;
  • this server's Collector forwards everything it collects (journald, PCP, OTLP from Archon and apps) to OpenObserve on loopback, adding the credential itself (an environment file systemd reads as root);
  • the Collector also accepts OTLP on 4318 (the router decides from where), so other servers can send here without any secret (they find it by otel.localdomain or telemetry.collector, spec 024);
  • Traefik serves the UI at otel.<host>.<domain>.
