archon apply: converge a host to its plan (Article XI). Idempotent: a run right after a successful run reports zero changes. Never removes anything (Article IX).

functionapply

export async function apply(host: HostDef, opts: ApplyOptions): Promise<ApplyResult>

archon apply: converge the host to its plan. Must run as root unless check or root is set. A real run also records provenance (spec 014), restarts Archon's daemons when the code changed, commits /etc with etckeeper (spec 033), settles the install record after a success (spec 009), and, for a full apply, reports a change of state (spec 025).

functionrestartArchonDaemons

export async function restartArchonDaemons(plan: HostPlan): Promise<string[]>

Restart Archon's own daemons when the checkout's code changed since they started (the checkout's HEAD, remembered in /var/lib/archon/status/daemons-head). A pull alone does not restart a running process, so without this the welcome page kept serving the code it started with.
