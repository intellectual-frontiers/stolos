archon/adopt/integrate.ts

Spec 069: integrate. The PC writes the one line a person runs on the machine (bin/integrate.sh or bin/integrate.windows.ps1, at this engine's release, with the fleet's public data filled in), and reads the check-in code the machine prints back: a discovered machine is recorded in Git; an adopted one is pinned (its host keys come from the code, not from a first connection) and observed.
