archon/adopt/probe.ts

Spec 067: the probe an adopted machine runs for Stolos. It is a POSIX shell script in the account's own ~/.local/bin/stolos-probe (no root, nothing listening), started only by the probe key: its line in authorized_keys forces command="~/.local/bin/stolos-probe", so that key runs this script and nothing else. The script answers a fixed set of read-only probes, named in SSH_ORIGINAL_COMMAND:

  • facts: the OS, hardware, disk, security settings, software, ports;
  • osquery <base64 SQL>: one SELECT through osqueryi, when installed;
  • version: the probe's version.

Its output is @section lines followed by key=value lines, read by {@link parseProbe}. It works on macOS and Linux (Debian, Ubuntu, Arch and Omarchy, Fedora); anything it cannot know it reports as unknown.
