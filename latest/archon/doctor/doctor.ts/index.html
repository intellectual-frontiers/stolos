archon/doctor/doctor.ts

archon doctor (spec 026): a quick, read-only look at whether this machine can reach what it depends on, with what is wrong and where to look. It uses Ubuntu's own network tools (ip, ping, resolvectl, dig, chronyc, ufw, snap, mtr) and curl's timings; the endpoints come from this machine's own configuration (apt sources, the checkout's remote, the tools catalog, the fleet model), never from a list kept here. It changes nothing.

archon doctor: runs each read-only phase (link, Internet, endpoints, email) and prints what it finds. With trace, adds a path trace to unreachable endpoints; with send, mails the email findings. Returns 0: the closing summary counts the problems.
