archon/connect/snyk.ts

Spec 088: Snyk, read-only, through its REST API (/rest, version 2024-10-15): one organization's open issues (vulnerabilities in open source dependencies, containers, and code) with their CVE, severity, the project they are in, and when each was found. Each issue is a vulnerability record (OCSF Vulnerability Finding, 2002); open ones go in the OSCAL POA&M. Evidence for vulnerability remediation and its timeliness (SCF VPM-06, VPM-07).

Credential: a service account's API token on the organization, with a role that only views (on Enterprise plans, a custom organization role with the View Organization, View Project, and View Issues permissions; otherwise the predefined Org Collaborator, which can also start tests: Stolos only reads). Docs: https://docs.snyk.io/snyk-api/reference/issues and https://docs.snyk.io/snyk-api/authentication-for-api.
