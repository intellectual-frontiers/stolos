Spec 087 (part A): Jamf Pro, read-only: every computer's name, serial number, macOS version, assigned user's email, FileVault state of its boot volume, and last contact, from the Jamf Pro API's computer inventory (GET /api/v4/computers-inventory, or /api/v3/... on a server older than Jamf Pro 11.30). Evidence for encryption at rest (SCF CRY-07) and asset inventory (AST-04, MON-02).

Credential: an API client (API Roles and Clients) whose role has only the Read Computers privilege; Stolos exchanges its client id and secret for a short-lived token (OAuth 2.0 client credentials at /api/oauth/token).
