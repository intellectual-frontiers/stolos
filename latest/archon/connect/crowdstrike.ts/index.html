archon/connect/crowdstrike.ts

Spec 087 (part A): CrowdStrike Falcon, read-only: every host with a Falcon sensor, its hostname, serial number, operating system, last seen, and whether the sensor runs in reduced functionality mode (GET /devices/combined/devices/v1). Evidence for anti-malware (SCF END-04), continuous monitoring (MON-02), and asset inventory (AST-04). Falcon does not report disk encryption or the device's owner here; the estate graph takes those from an MDM or Stolos's probe for the same device.

Credential: an API client with the one scope Hosts: Read; Stolos exchanges its id and secret for a short-lived token (OAuth 2.0 client credentials at /oauth2/token).
