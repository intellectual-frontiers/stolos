archon/connect/checkr.ts

Spec 088: Checkr background screening, read through its API with GET only: each candidate's work email and, for each of their reports, only its outcome and date (never what the check found). A completed report is a person_record of kind screening, the hook spec 077's people/screening control reads beside people/screening.ts: clear when Checkr's result is clear (or its assessment eligible), not clear otherwise. Pending reports are counted, not recorded. Evidence for personnel screening (SCF HRS-05).

Credential: a Checkr secret API key, sent as HTTP Basic's user name. Checkr's keys are not scoped: one can make any call. Stolos's guard sends only GET with it; make a key for Stolos alone, so it can be revoked on its own. Docs: https://docs.checkr.com/ (Authentication; Candidates; Reports).
