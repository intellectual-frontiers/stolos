archon/connect/microsoft.ts

Spec 067 (clouds), declared with spec 091's SDK: Microsoft 365 (Entra ID, through Microsoft Graph) and Azure (through Resource Manager), read-only, with one app registration's client credentials: the tenant, its domains, users and licenses, who is a Global Administrator, whether people have MFA, the enterprise applications people sign in to (spec 080: vendors), and Azure's subscriptions and resources.

Spec 088 reads deeper into each subscription, with the same Reader role: Microsoft Defender for Cloud's plans (Microsoft.Security/pricings: a plan on Standard is on) and where the activity log is exported (Microsoft.Insights/diagnosticSettings at the subscription: Azure keeps it 90 days by itself, an export keeps it longer). Each is read only when there is a subscription; its policies are reported only when read.
