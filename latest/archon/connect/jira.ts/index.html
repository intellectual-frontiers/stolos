archon/connect/jira.ts

Spec 087: Jira (Cloud), read-only: the site's people (active, who is in an administrators group), and the last 90 days of tickets: each one's key, type (change, incident, or other, from its issue type and project), status, created and resolved times, and the development work it links (commit and pull request counts from Jira's development panel, and commit or pull request URLs among its remote links). Evidence for change control (SCF CHG-03) and least privilege (IAC-30).

It uses an Atlassian API token with scopes (read:jira-work, read:jira-user), which Atlassian serves only through its API gateway (api.atlassian.com/ex/jira/<cloud id>); the cloud id is read from the site's public /_edge/tenant_info.
