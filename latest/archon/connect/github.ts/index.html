archon/connect/github.ts

Spec 086, declared with spec 091's SDK: GitHub, read-only, for one organization: its members (who are owners, who have no second factor), and its repositories (private or public, whether the default branch is protected by branch protection or a ruleset, how many approving reviews it needs, secret scanning, dependency alerts), and (spec 088) its open Dependabot alerts (GET /orgs/{org}/dependabot/alerts, which the token's read-only Dependabot alerts permission already allows) as vulnerability records, OCSF Vulnerability Findings that feed the OSCAL POA&M. Evidence for change management (SCF CHG-03), MFA (IAC-37), least privilege (IAC-30), scanning (VPM-12), and remediation (VPM-06, VPM-07).

Code scanning alerts need one more permission (Code scanning alerts: Read) that the token Stolos asks for does not have; they are left for later.
