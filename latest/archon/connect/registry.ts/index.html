archon/connect/registry.ts

Spec 088: the connector registry. A fleet adds a connector Stolos does not ship from a TypeScript module at a pinned URL (a tag or a commit). The module is copied, as checked, into the fleet repository (fleets/<fleet>/connectors/<id>.ts) and declared in fleets/<fleet>/connectors.ts with Stolos's lock entry: where it came from, the module's SHA-256, the engine versions it supports, and which engine checked it and its fixtures. The engine loads the added connectors beside its own (CONNECTORS), each only while its copy still hashes as locked.

There is no central server: an index anyone can host is a JSON file ({@link RegistryIndex}) that names connectors and their tags.

flowchart LR
  src["github.com/owner/repo @ tag"] --> url["raw.githubusercontent.com/owner/repo/tag/mod.ts"]
  url --> probe["probe: its own process, fixtures"] --> checks["checks: id, labels, SCF, engine range"]
  checks --> copy["fleets/&lt;fleet&gt;/connectors/&lt;id&gt;.ts (as checked)"]
  checks --> file["fleets/&lt;fleet&gt;/connectors.ts (import + entry, SHA-256)"]
  copy & file --> engine["the engine: CONNECTORS + these"]

  /** Its id (unique among the engine's and the fleet's connectors). */

  /** Its name for people. */
  title: string;
  /** Where it was added from (`https://github.com/<owner>/<repo>[/<path>]`). */

  ref: string;

  /** The module's SHA-256 (hex), as added; its copy in the fleet repository hashes the same. */

  checkedWith: string;
  /** How many fixture tests passed then. */
  fixtures: number;
  /** When it was added or moved to this ref (YYYY-MM-DD). */

functionpinSource

export function pinSource(spec: string): PinnedSource

<source>@<ref> as a pinned module URL. The source is https://github.com/<owner>/<repo>[/<path>] (read from raw.githubusercontent.com, as the engine is), or any http(s)://<host>/<owner>/<repo>[/<path>] laid out the same way; the path defaults to mod.ts. The ref must be a version tag or a full commit SHA: a branch moves, so it is refused.

interfaceRegistryIndex

export interface RegistryIndex {
  /** Always "stolos-connector-index/1". */
  format: "stolos-connector-index/1";
  /** The connectors it lists. */
  connectors: ReadonlyArray<{
    /** The connector's id. */
    id: string;
    /** Its name for people. */
    title: string;
    /** Its repository (`https://github.com/<owner>/<repo>`). */
    source: string;
    /** The module's path in it (default mod.ts). */
    path?: string;
    /** Its released tags. */
    tags: readonly string[];
    /** The engine versions it supports. */
    engine?: string;
    /** Its market categories. */
    markets?: readonly string[];
    /** One line about it. */
    description?: string;
  }>;
}

An index of connectors anyone can host (a JSON file at any URL): Stolos runs no central server. stolos connector add <id>@<tag> --index <url> reads one to find where a connector is.

{
  "format": "stolos-connector-index/1",
  "connectors": [{
    "id": "example-scanner",
    "title": "Example Scanner",
    "source": "https://github.com/example/stolos-connector-example",
    "path": "mod.ts",
    "tags": ["v1.0.0"],
    "engine": ">=0.112.0 <1.0.0",
    "markets": ["vulnerability-assessment"]
  }]
}
