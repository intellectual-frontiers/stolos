archon/connect/aws.ts

Spec 067 (clouds), declared with spec 091's SDK: AWS, read-only, with an access key whose user (or role) has the managed SecurityAudit policy: the account, IAM users, S3 buckets, EC2 instances in every enabled region, and the root account's MFA and keys. Requests are signed with Signature Version 4, in TypeScript (IFC TypeScript's sigv4; no AWS CLI). The query APIs, S3, S3 Control, and GuardDuty read with GET.

Spec 088 reads deeper, each part only where the key may: CloudTrail (every trail, whether it logs, and whether it records every region), GuardDuty (a detector enabled in each region), and AWS Config (a recorder recording in each region). CloudTrail and Config have only a JSON API, read with POST; the guard lets through only their Describe and Get actions (readPost), and SecurityAudit allows nothing else. A part that answers 404 (a service not offered in a region) is left out; its policies are then not reported, so an account read before spec 088 reads the same.

  /** The body. */
  body: string;
  /** The region. */
  region: string;
  /** The service name in the signature (iam, sts, s3, ec2). */
  service: string;
}
