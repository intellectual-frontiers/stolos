archon/api/openapi.ts

Spec 094: the REST API's OpenAPI 3.1 document, generated from the estate schema's declarations (the same ones the SQL views come from), so the document cannot drift from what the API serves. Each table and view is one path; its row schema comes from the declared column types, its column docs become descriptions, and declared values become an enum.

flowchart LR
  decl["ESTATE_SCHEMA (defineTable, defineView, defineLabel)"] --> sql["SQL tables and views"]
  decl --> res["RESOURCES: typed columns"]
  res --> api["GET /v1/&lt;name&gt;"]
  res --> doc["GET /v1/openapi.json"]
