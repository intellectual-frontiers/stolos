archon/controls/core.ts

Spec 078: how a control's answer becomes a result. Each runner here is pure: it is given the rows (or the observation) and returns {@link PolicyResult}s, so the built-in policies (adopted machines, devices, the estate graph) and a fleet's own packs give results the same way, and accepted risks apply to both alike.

flowchart LR
  rows["rows or observation"] --> assert["control.assert"]
  assert -- "undefined" --> none["no result (does not apply)"]
  assert -- "Verdict" --> result["PolicyResult: id, title, scf, status, detail, fix"]
  result --> accept["acceptRisks: a recorded decision makes a failure accepted"]
