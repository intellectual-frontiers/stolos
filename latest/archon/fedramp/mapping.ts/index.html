archon/fedramp/mapping.ts

Spec 076: which Stolos evidence gives evidence for each FedRAMP 20x Key Security Indicator (KSI), and which KSIs Stolos cannot observe, each with its reason in plain words. This is the only mapping here that is Stolos's own: "these checks give evidence for this KSI". The KSIs themselves, their NIST SP 800-53 controls, and which classes they apply to are FedRAMP's (rules.auto.ts); the path from a check's SCF control to SP 800-53 is the SCF Council's (its STRM, in the catalog), and strmLinks shows it where it exists, so a reviewer can see each claim's footing.

flowchart LR
  checks["Stolos checks (Evidence, by SCF control)"] -- "this file: a reason per KSI" --> ksi["FedRAMP KSIs (46)"]
  checks -- "SCF STRM" --> nist["SP 800-53 controls"]
  ksi -- "FedRAMP's own mapping" --> nist
  ksi -.-> no["Not observable: a person's process, a document, a contract"]

Every KSI appears exactly once: the type is a record over FedRAMP's KSI ids, so a KSI FedRAMP adds fails to compile until it is mapped.
