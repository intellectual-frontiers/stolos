Spec 076: the FedRAMP 20x validation package for Class A or Class B, from the evidence Stolos already has. It is a Security Decision Record (SDR) in FedRAMP's own JSON format (SDR-CSX-KSI names the schema fedramp-security-decision-record-schema-2026-06-24.json): for each KSI the class asks for, the measures (Stolos's checks), their cycle, the automated validations with their results and observation times, and for a KSI Stolos cannot observe, why, so the provider writes its own.

flowchart LR
  facts["PcFacts: what this PC last observed"] --> ev["Evidence, with when each was observed"]
  ev --> map["KSI_MAP: checks per KSI"] --> ksi["Each KSI: status, tests, evidence, age"]
  rules["rules.auto.ts: Class A list, cadences (FedRAMP)"] --> ksi
  ksi --> sdr["Security Decision Record (FedRAMP JSON schema)"]

The classes differ as the rules say: Class A addresses the seven KSIs of FRC-CLA-MFR, automation is optional (FRC-CSX-VVK: MAY), machines are validated at least monthly (VDR-TFR-MVX: SHOULD), and the package is kept current every 3 months (CPO-CSX-CPM: SHOULD); Class B addresses every KSI (five marked "Optional" for it), with at least one automated method each (SHOULD), machines validated at least every 7 days (MUST), and the package kept current every month (MUST).

When each piece of evidence was observed comes from Evidence.observedAt when it has one (spec 073 may add it), else from the observation times the Stolos Console already knows (evidenceObservedAt): an adopted machine's or device's last probe, a cloud's last observation, a managed server's last pull or install, the repository's newest commit.

Interfaces

I
ClassCadence

What the rules ask of each class's package, and how often.

  • automation: ClassRule & { minMethods: number; }

    FRC-CSX-VVK: automated validation of each KSI, with the minimum number of methods.

  • documentation: ClassRule

    SDR-CSX-KSI: what the Security Decision Record says for each KSI.

  • machineValidation: ClassRule

    VDR-TFR-MVX: how often machine-based resources are verified and validated.

  • metrics: ClassRule

    SDR-CSX-KMT: historical metrics in the Security Decision Record.

  • packageMaintenance: ClassRule

    CPO-CSX-CPM: how often the certification package is brought up to date.

I
ClassRule

A rule's requirement for one class.

  • every: { unit: string; count: number; }

    How often, when the rule sets a cadence.

  • force: string

    MUST, SHOULD, or MAY.

  • items: readonly string[]

    What it lists, when it lists something.

  • name: string

    Its name.

  • rule: string

    The rule's id (FRC-CSX-VVK).

  • statement: string

    What it says for this class.

I
FedrampPackage

The package: what Stolos found, and the SDR it writes.

  • cadence: ClassCadence

    What the rules ask of this class, and how often.

  • class: FedrampClass

    The class.

  • counts: { ksis: number; covered: number; notObservable: number; withAutomation: number; }

    How many are covered by checks, and how many Stolos cannot observe.

  • generatedAt: string

    When it was made (ISO).

  • ksis: KsiResult[]

    Each KSI the class asks for.

  • rules: { version: string; url: string; sha256: string; schema: string; }

    The FedRAMP rules release.

  • sdr: SecurityDecisionRecord

    The Security Decision Record, valid against FedRAMP's schema.

I
Ksi

One Key Security Indicator, as FedRAMP writes it.

  • classes: Partial<Record<FedrampClass, string>>

    What it asks of each class, when it applies to that class (Markdown, FedRAMP's).

  • controls: readonly string[]

    The NIST SP 800-53 Rev 5 controls FedRAMP maps it to (OSCAL ids: ac-2.1).

  • id: KsiId

    Its id (KSI-THEME-KEY).

  • name: string

    Its name.

  • optionalIn: readonly FedrampClass[]

    The classes for which FedRAMP marks it "Optional".

  • statement: string

    What it asks, in FedRAMP's words (the strictest class's, when it varies).

  • theme: string

    Its theme's short name.

I
KsiResult

One KSI's place in the package.

  • applies: "required" | "optional"

    Whether the class requires it, or FedRAMP marks it optional for the class.

  • evidence: TimedEvidence[]

    The evidence it counts.

  • fresh: boolean

    Whether all its evidence is within the class's machine validation cadence (undefined: no times).

  • ksi: Ksi

    The KSI, as FedRAMP writes it.

  • mapping: KsiMapping

    Stolos's mapping for it.

  • observed: { oldest: string; newest: string; }

    The oldest and newest observation of its evidence.

  • status: Coverage | "not observable"

    Its status from the evidence, or "not observable".

  • strm: Record<string, string[]>

    The SCF STRM links to its SP 800-53 controls (with the catalog).

  • tests: string[]

    The automated tests (distinct checks) behind it.

I
PackageOptions

Everything the package needs besides the facts.

  • catalog: ScfCatalog

    The SCF catalog, for the STRM links to SP 800-53.

  • now: Date

    Now (for observation ages and the record's time).

  • overviewUri: string

    The provider's Certification Package Overview URI.

  • stolosVersion: string

    Stolos's version, for the record's source of update.

I
SdrEvidence

One piece of evidence in an SDR (the schema's $defs/evidence).

  • evidenceDescription: string

    What it is.

  • evidenceLocation: string

    Where it is (a URI).

  • evidenceText: string

    The result, as text.

  • evidenceType:
    "Log"
    | "Report"
    | "Screenshot"
    | "Configuration"
    | "Policy"
    | "Procedure"
    | "Audit Record"

    Log, Report, Screenshot, Configuration, Policy, Procedure, or Audit Record.

  • lastUpdated: string

    When it was last updated (YYYY-MM-DD).

I
SdrKsi

One KSI in an SDR (the schema's keySecurityIndicators item).

  • ksiAssessment: string[]

    The independent assessor's statements (left for the assessor).

  • ksiEvidence: SdrEvidence[]

    Their results.

  • ksiId: string

    The KSI's id.

  • ksiImplementation: string[]

    The measures and their objectives, and their cycle (SDR-CSX-KSI).

  • ksiImplementationStatus: SdrStatus

    Its status (left out when Stolos cannot observe it: the provider states it).

  • ksiTests: string[]

    The automated tests.

  • ksiValidation: string[]

    How the provider validates them (Stolos's automated validations).

I
SdrRequirement

One FedRAMP rule in an SDR (the schema's fedRampRequirements item).

  • frrAssessment: string[]

    The independent assessor's statements.

  • frrID: string

    The rule's id.

  • frrImplementation: string[]

    How it is followed.

  • frrImplementationStatus: SdrStatus

    Its status.

  • frrValidation: string[]

    How that is validated.

I
SecurityDecisionRecord

A Security Decision Record, as FedRAMP's JSON schema defines it (the parts Stolos writes).

  • certificationPackageOverviewUri: string

    The provider's Certification Package Overview (a URI).

  • fedRampRequirements: SdrRequirement[]

    The FedRAMP rules this record speaks to.

  • keySecurityIndicators: SdrKsi[]

    The KSIs.

  • metadata: { version: string; lastUpdated: string; updateSource: string; }

    SDR-CSO-MTD: version, last update, source of update.
