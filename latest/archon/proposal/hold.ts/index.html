archon/proposal/hold.ts

Spec 095-proposals, the owner's decision 1: the reconcile hold. The timer applies every 15 minutes and would undo a hand edit to a managed file (or a managed unit enabled, disabled, or masked by hand) before anyone could propose it. So before each apply, archon reads sudo's journal: an item the plan manages, that differs from the plan, and that a person's sudo command named, is held. Apply leaves it as it is, for up to 7 days, or until its proposal is decided in Git (accepted or rejected), whichever comes first; a revert ends it at once. Then the model in Git wins.

stateDiagram-v2
  [*] --> held: a person changed a managed item under sudo
  held --> proposed: archon propose (adopt)
  held --> ended: 7 days
  held --> ended: archon propose (revert)
  proposed --> ended: proposals.ts says accepted or rejected
  proposed --> ended: 7 days
  ended --> [*]: apply converges it to the model

An ended hold is kept, so the same sudo command never holds the item again; a newer one does.
