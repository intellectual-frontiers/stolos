archon/proposal/propose.ts

Spec 095-proposals: archon propose on a server. Anyone with sudo may propose (the owner's decision 3). It collects again, picks the items (all, by intent, or by key), applies each person's choice (adopt, revert, or keep local until a day), requires a written reason, builds and signs proposal.json with the host key, keeps a copy in /var/lib/archon/proposals/<id>/, records it in archon.sql, and mails it to the fleet's mailbox with a readable summary.

interfaceProposeOptions

export interface ProposeOptions {
  /** Every item not proposed yet. */
  all?: boolean | undefined;
  /** Intents by id (newline-separated when repeated). */
  intent?: string | undefined;
  /** Items by key (newline-separated when repeated). */
  item?: string | undefined;
  /** The action for every chosen item (default adopt). */
  action?: string | undefined;
  /** Items to revert instead (keys, newline-separated). */
  revert?: string | undefined;
  /** Items to keep local instead (keys, newline-separated). */
  local?: string | undefined;
  /** Local: until this day (default 30 days from now). */
  until?: string | undefined;
  /** Why (required, unless a recording gives it). */
  reason?: string | undefined;
  /** Print proposal.json; sign, record, and send nothing. */
  dryRun?: boolean | undefined;
  /** --json. */
  json?: boolean | undefined;
}
