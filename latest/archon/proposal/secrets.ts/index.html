archon/proposal/secrets.ts

Spec 095-proposals, Article 13: no secret ever leaves a server in a proposal. A path in the secret inventory (by its file name), a path that is secret on every host (/etc/shadow, SSH host keys, /var/lib/archon-keys), and content that looks like a key are sent as a SHA-256 hash only. A file's content is sent only when it is small, text, and not secret.
