Spec 095-proposals: the collectors. Each reads one of Ubuntu's own records (journald's sudo entries, apt's history.log and dpkg.log, etckeeper's git log, osquery, systemctl list-unit-files, snapd, podman, dpkg -S on /usr/local and /opt, debsums -c or dpkg --verify) and writes observations (what, who, when, source) into the host's own archon.sql, with the latest state and, once, the birth snapshot. Nothing here changes the host. A modified package binary is a security alert, mailed at once and never proposed.

Interfaces

Collected

What one collection did.

  • birthTakenLate: boolean

    The birth snapshot was taken late, now.

  • failed: Record<string, string>

    Collectors that failed, with why.

  • newAlerts: Alert[]

    Security alerts seen for the first time.

  • observations: number

    Observations written (new or seen again).

I
RawSources

Raw output of every source, read from the host (tests pass fixtures).

  • aptHistory: string

    /var/log/apt/history.log (and its previous rotation).

  • at: string

    When it was read (ISO).

  • containers: string

    podman ps -a --format {{.Names}}.

  • dpkgLog: string

    /var/log/dpkg.log (and its previous rotation).

  • etcLog: string

    etckeeper's log since birth (see parseEtckeeperLog).

  • etcStatus: string

    git -C /etc status --porcelain: changes not committed yet.

  • etcUnowned: string[]

    /etc paths no package owns, among the changed ones (dpkg -S).

  • failed: Record<string, string>

    Collectors that failed, with why.

  • listening: string

    ss -Hlntu.

  • managedFiles: string[]

    Files the plan writes whose content differs now.

  • manual: string

    apt-mark showmanual.

  • modified: string

    debsums -c, or dpkg --verify.

  • osquery: OsquerySnapshot

    osquery's snapshot, when osquery answered.

  • passwd: string

    getent passwd.

  • snapChanges: string

    snap changes.

  • snapList: string

    snap list.

  • sudoJournal: string

    journalctl -o json SYSLOG_IDENTIFIER=sudo.

  • unitFiles: string

    systemctl list-unit-files --no-legend --plain.

  • unowned: string[]

    Files under /usr/local and /opt that no package owns (dpkg -S errors).
