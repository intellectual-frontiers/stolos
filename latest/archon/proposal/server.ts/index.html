archon/proposal/server.ts

Spec 095-proposals: archon drift on a server. It reads what the collectors stored in archon.sql (the daily report, every apply, and archon drift --collect collect), computes drift against the plan and the birth snapshot, and prints each item with who changed it, when, and the model change that would adopt it. Read-only, so it is also an MCP tool.
