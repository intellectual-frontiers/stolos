archon/install/runnable.ts

Spec 063: before a machine is armed, check that what it will run is there. A new server clones the fleet's branch from GitHub at its first boot and runs it only when the tip is signed by one of the fleet's signers (spec 047), and it needs its own model (fleets/<fleet>/hosts/<host>/host.ts) in that commit. Either one missing used to surface only after a full install, as "the repository tip is not signed by a fleet signer: nothing was run". boot arm refuses, and boot serve warns, before anything boots, each with the fix (bun run stolos apply).

flowchart LR
  fetch["git fetch origin &lt;branch&gt;"] --> sig{"tip signed by<br/>a fleet signer?"}
  sig -- no --> fix1["stolos apply<br/>(a signed commit on top)"]
  sig -- yes --> model{"host.ts in<br/>that commit?"}
  model -- no --> fix2["stolos apply -m '004-install: add host'"]
  model -- yes --> ok["arm"]
