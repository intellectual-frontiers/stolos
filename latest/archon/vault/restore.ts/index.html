Spec 061: deno task stolos vault restore <zip> makes a freshly cloned PC the boot machine again from one backup ZIP (spec 056). It reads the ZIP and checks every file against its manifest, puts each file back where stolos keeps it (the secrets, readable by you only; the daily key in .ssh; the recovery key in the key store), records the ZIP as the last backup, then runs keys setup (Git's signing for this checkout, and one test signature: your daily passphrase) and gets VS Code its types.

It never overwrites: a file already there with the same bytes is kept, and a file that differs stops the restore before anything is written (it may be newer than the backup). So it can be run again, and changes nothing the second time.

--destroy-existing restores clean instead: the secrets of every fleet, the key store, and the backup's daily key files in .ssh are removed first, so what is left is exactly the backup. Anything there that the backup does not hold identically is first saved as a backup ZIP of its own (nothing is lost), and only after the ZIP to restore has been read and checked.

flowchart LR
  zip["backup ZIP"] --> check["read it: format, every SHA-256"]
  check --> fleet["the fleet: one of this repository's"]
  fleet --> files["put files back<br/>(never overwrite)"]
  files --> keys["keys setup<br/>(one test signature)"]
  keys --> editor["VS Code's types"]

Interfaces

I
RestoreFile

One file of the ZIP and where it goes.

  • data: Uint8Array<ArrayBuffer>

    Its bytes.

  • name: string

    Its path in the ZIP.

  • secret: boolean

    A private file (owner only); public halves (.pub) are not.

  • state: "new" | "same" | "differs"

    "new": not here yet; "same": already here, identical; "differs": here, with other bytes.

  • to: string

    Where it goes on this PC.

I
RestorePlan

A checked backup ZIP, and what restoring it would do.

  • daily: string

    The daily key's private file name (under signing/), when the ZIP has one.

  • files: RestoreFile[]

    Every file, with where it goes.

  • fleets: string[]

    The fleets it holds secrets for.

  • manifest: ZipManifest

    The ZIP's manifest.

  • recovery: boolean

    Whether it holds a recovery key's private half.

I
RestoreRoots

Where restored files go: the secrets root (holds one folder per fleet), .ssh, and the key store.

  • keys: string

    The key store (the recovery key, and any retired one).

  • secrets: string

    The folder holding <fleet>/... secrets.

  • ssh: string

    The daily key's folder (~/.ssh).
