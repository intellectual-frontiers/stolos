archon/people/git.ts

Spec 077: what Git says about people. A signed commit is an e-signature: an access review is approved, and a policy acknowledged, by a commit signed with the person's own key (people/keys.ts, its principal their work email) or, for a review, by a fleet signer (signers.ts, its principal the signer's name). Git checks each signature with ssh-keygen against an allowed-signers file made from both lists.

Git's history also gives each account's activity: the last observation in which it could sign in, and the first after that in which it could not (or was gone), which measures how long a leaver's account stayed active.

flowchart LR
  keys["people/keys.ts (email)"] & signers["signers.ts (name)"] --> allowed["allowed signers (temporary file)"]
  allowed --> verify["git verify-commit"]
  verify --> reviews["review approved: who, which commit"]
  verify --> acks["Acknowledges: policy@version, by whom"]
  hist["estate/*.ts, each version"] --> act["accountActivity: last active, off by"]
