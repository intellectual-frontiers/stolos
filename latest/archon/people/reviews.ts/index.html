archon/people/reviews.ts

Spec 077: quarterly access reviews, written from the estate graph. Each manager (the people others report to, party_relationship reports_to) gets one Markdown file per quarter, people/reviews/<quarter>/<manager>.md: each report's active accounts (has_account edges) with their admin rights, one line each, unticked. The manager ticks each line they confirm (and removes, in the system itself, any access they do not) and commits it signed: that commit is the approval.

flowchart LR
  estate[("estate graph: reports_to, has_account")] --> files["reviewFiles: one per manager"]
  files --> branch["a branch, a pull request"]
  branch --> tick["the manager ticks each line: a signed commit"]
  tick --> main["merged to main, signatures kept"]
  main --> control["people-access-reviews: approved?"]
