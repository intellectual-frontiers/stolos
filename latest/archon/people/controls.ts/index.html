archon/people/controls.ts

Spec 077: people controls, on the control SDK (spec 078). Each is an estate control: its SQL reads the people and accounts of the estate graph, and its assertion compares them with what the fleet keeps in Git (roles, reviews, policies, acknowledgements, training, screening), which {@link PeopleFacts} carries. A leaver with an active account is the estate's own leavers control, reused, not repeated.

flowchart LR
  estate[("estate graph")] --> sql["each control's SELECT"]
  facts["PeopleFacts: roles, reviews, acks, training, screening, activity"] --> assert["each control's assert"]
  sql --> assert
  assert --> results["people/&lt;control&gt;: pass, warn, fail"]
  results --> compliance["stolos compliance (a control pack)"]
