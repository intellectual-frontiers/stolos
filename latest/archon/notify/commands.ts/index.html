interfaceSendArgs

export interface SendArgs {
  /**
   * The subject. One that starts with `[` or `Lab ` is sent as given, with the
   * body as the whole message; a short one becomes `[Archon] <host>: <subject>`.
   */
  subject: string;
  /** The body text (with a short subject, the subject itself when empty). */
  body?: string;
  /** Read the body from this file instead (it wins over `body`). */
  bodyFile?: string;
  /** Files to attach. */
  attach?: string[];
  /** How serious it is; `"info"` by default. */
  level?: Level;
  /** Deduplication key: the same key within an hour is sent once. */
  key?: string;
}

The options of archon notify send.

functionnotifySend

export async function notifySend(a: SendArgs, o: { wait: boolean }): Promise<number>

archon notify send: queue a message from this machine. With wait, send it now and report whether it went; otherwise start the sender and return. Exit code 0 when queued (or sent, with wait) or a duplicate, else 1.

functionnotifyTest

export async function notifyTest(): Promise<number>

archon notify test: send a test message now and wait for the relay (exit code 0 when sent).

functionnotifyStatus

export async function notifyStatus(o: { check: boolean }): Promise<number>

archon notify status: mailbox, sender, relay, credential, last send and queue. With check (archon verify), one line instead, and exit code 1 when mail is not configured, the last send failed, or a message has waited more than 6 hours.

functionnotifyFlush

export async function notifyFlush(): Promise<number>

archon notify flush (the flush service): send what is due. Prints counts only when something was tried. Always exit code 0.
