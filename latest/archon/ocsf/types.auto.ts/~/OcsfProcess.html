interface OcsfProcess

Process: The Process object describes a running instance of a launched program.

Properties

optional
ai_agent: OcsfAiAgent

AI Agent: The autonomous AI agent that this process is running or hosting, if applicable. Populate when the process serves as the runtime environment for an AI agent (e.g., a Python process executing a LangChain agent or hosting an MCP server). When a process hosts multiple agents and the activity cannot be attributed to one specifically, use hosted_ai_agent_list instead. (optional)

optional
ancestry: OcsfProcessEntity[]

Ancestry: An array of Process Entities describing the extended parentage of this process object. Direct parent information should be expressed through the parent_process attribute. The first array element is the direct parent of this process object. Subsequent list elements go up the process parentage hierarchy. That is, the array is sorted from newest to oldest process. It is recommended to only populate this field for the top-level process object. (optional)

optional
auid: number

Audit User ID: The audit user assigned at login by the audit subsystem. (optional)

optional
cmd_line: string

Command Line: The full command line used to launch an application, service, process, or job. For example: ssh user(at)10.0.0.10. If the command line is unavailable or missing, the empty string '' is to be used. (recommended)

optional
container: OcsfContainer

Container: The information describing an instance of a container. A container is a prepackaged, portable system image that runs isolated on an existing system using a container runtime like containerd. (recommended)

optional
cpid: string

Common Process Identifier: A unique process identifier that can be assigned deterministically by multiple system data producers. (recommended)

optional
created_time: number

Created Time: The time when the process was created/started. (recommended)

optional
created_time_dt: string

Created Time: The time when the process was created/started. (optional)

optional
egid: number

Effective Group ID: The effective group under which this process is running. (optional)

optional
environment_variables: OcsfEnvironmentVariable[]

Environment Variables: Environment variables associated with the process. (optional)

optional
euid: number

Effective User ID: The effective user under which this process is running. (optional)

optional
file: OcsfFile

File: The process file object. (recommended)

optional
group: OcsfGroup

Group: The group under which this process is running. (recommended)

optional
hosted_ai_agent_list: OcsfAiAgent[]

Hosted AI Agent List: The list of autonomous AI agents hosted by this process. Use when a single process hosts multiple agents (e.g., an IDE running several coding agents within the same host process) and the producer cannot attribute a specific activity to a single agent. When attribution is available, populate the singular ai_agent attribute instead. (optional)

optional
hosted_services: Record<string, unknown>[]

Hosted Services: The Windows services that this process is hosting. (optional)

optional
integrity: string

Integrity: The process integrity level, normalized to the caption of the integrity_id value. In the case of 'Other', it is defined by the event source (Windows only). (optional)

optional
integrity_id: 0 | 1 | 2 | 3 | 4 | 5 | 6 | 99

Integrity Level: The normalized identifier of the process integrity level (Windows only). Values: 0 Unknown, 1 Untrusted, 2 Low, 3 Medium, 4 High, 5 System, 6 Protected, 99 Other. (optional)

optional
lineage: string[]

Lineage: The lineage of the process, represented by a list of paths for each ancestor process. For example: ['/usr/sbin/sshd', '/usr/bin/bash', '/usr/bin/whoami']. (optional)

optional
loaded_modules: string[]

Loaded Modules: The list of loaded module names. (optional)

optional
name: string

Name: The friendly name of the process, for example: Notepad++. (recommended)

optional
namespace_pid: number

Namespace PID: If running under a process namespace (such as in a container), the process identifier within that process namespace. (recommended)

optional
parent_process: OcsfProcess

Parent Process: The parent process of this process object. It is recommended to only populate this field for the top-level process object, to prevent deep nesting. Additional ancestry information can be supplied in the ancestry attribute. (recommended)

optional
path: string

Path: The process file path. (optional)

optional
pid: number

Process ID: The process identifier, as reported by the operating system. Process ID (PID) is a number used by the operating system to uniquely identify an active process. (recommended)

optional
ptid: number

Process Thread ID: The identifier of the process thread associated with the event, as returned by the operating system. (optional)

optional
sandbox: string

Sandbox: The name of the containment jail (i.e., sandbox). For example, hardened_ps, high_security_ps, oracle_ps, netsvcs_ps, or default_ps. (optional)

optional
session: OcsfSession

Session: The user session under which this process is running. (optional)

optional
terminated_time: number

Terminated Time: The time when the process was terminated. (optional)

optional
terminated_time_dt: string

Terminated Time: The time when the process was terminated. (optional)

optional
tid: number

Thread ID: The identifier of the thread associated with the event, as returned by the operating system. (optional)

optional
uid: string

Unique ID: A unique identifier for this process assigned by the producer (tool). Facilitates correlation of a process event with other events for that process. (recommended)

optional
uid_numeric: number

Numeric Unique ID: The uid attribute in numeric form where applicable.Note: Producers may populate uid_numeric only in addition to uid and not as an alternative to it. (optional)

optional
user: OcsfUser

User: The user under which this process is running. (recommended)

optional
working_directory: string

Working Directory: The working directory of a process. (optional)

optional
xattributes: OcsfObject

Extended Attributes: An unordered collection of zero or more name/value pairs that represent a process extended attribute.For example: process security context attributes, process resource limits, container-specific attributes, or platform-specific process metadata not covered by standard OCSF attributes. (optional)

Usage

import { type OcsfProcess } from "archon/ocsf/types.auto.ts";
