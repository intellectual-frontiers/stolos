functiondataOnDisk

export async function dataOnDisk(dirs = DATA_DIRS): Promise<string[]>

The opt-ins whose data directory holds data on this host (Article 23's fail-safe: data with no recorded choice counts as durable). PostgreSQL: a cluster directory under /var/lib/postgresql/<version>/. S3: /srv/s3 is private to the container's account, so its link count says whether RustFS made anything in it (an empty directory has two). SMB: anything in the shared folder. A directory that cannot be read counts as holding data.
