Spec 081: what a Trust Center says, read from a verified evidence bundle (spec 072) and nothing else. The bundle's OSCAL assessment results (spec 071) give every check Stolos made and the SCF controls it is evidence for; the bundle's other items (verify results, observations, commits) say when each source was last observed; the SCF Council's mappings (STRM), from the catalog release the bundle names, carry each control to each framework's requirements. Freshness is spec 073's: each source held to its default cadence as of the moment the bundle was signed, and the bundle as a whole held to FedRAMP 20x's longest validation interval (7 days) as of the moment the page is built.

flowchart LR
  zip["evidence bundle (verified)"] --> oscal["assessment-results.json: checks and SCF controls"]
  zip --> items["verify, observation, commit items: when each source was observed"]
  oscal & items --> fresh["spec 073: stale when signed"] --> ctl["each SCF control's status and age"]
  cat["SCF catalog (the release the bundle names)"] --> fw["each framework requirement's status"]
  ctl --> fw

Nothing here reads this PC's live state: a Trust Center built twice from the same bundle (at the same time, with the same catalog) says the same.
