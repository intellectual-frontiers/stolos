archon/clients/registry.ts

Spec 082: the provider's registry of client checkouts. A provider (a managed service provider or a virtual CISO) keeps one file on its own PC, clients.json in its Stolos config folder (P.provider): each client's id, title, the path to that client's checkout, and the fleet within it. The file is the provider's, never in any client's repository; it holds no secret.

One checkout belongs to one client: two clients never share a repository (or one inside the other), so nothing rendered or recorded for one lands in the other's.
