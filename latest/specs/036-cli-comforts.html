Modern command-line comforts

036Implemented

036-cli-comforts

Input

Modern command-line conveniences (eza, bat, zoxide, fzf, and others), from Ubuntu's packages where Ubuntu ships recent ones, else the publisher's binary release (binaries only); default aliases (ls, tree, ...). An archon shell emit command, added to a shell's startup file, decides everything: a shell without that line gets none of the aliases or other shell features. The line is in the fleet's dotfiles for everyone; the prompt is plain on console terminals (physically connected) and colorful everywhere else. VS Code on workstations with a desktop only. A Nerd Font note for workstations; servers say how to choose the plain prompt. AI assistants are not part of this.

#User Scenarios & Testing (mandatory)

  1. Given a user logs in over SSH, When their shell starts, Then ls, ll, la, tree are eza, cat is bat, z jumps, Ctrl+R and Ctrl+T search, and the prompt is Oh My Posh.
  2. Given someone logs in at the server's own screen (or a serial or AMT console), When the shell starts, Then the prompt is plain: no icons, Archon's status in words.
  3. Given a user's own layer drops the archon shell emit line, When their shell starts, Then they get the shell's defaults only (no aliases, keys, or Archon prompt); archon shell status shows the line to add.
  4. Given a script or scp, When bash starts non-interactively, Then nothing of this runs.
  5. Given a workstation with a desktop and a developer, When it converges, Then VS Code is installed from Microsoft's repository; on WSL or a headless machine nothing is.

#Requirements (mandatory)

FR-001

Tools, from Ubuntu 26.04's packages (checked 2026-11-12 at packages.ubuntu.com/resolute): eza 0.23.4, bat 0.25.0, zoxide 0.9.8, fzf 0.67.0, ripgrep 15.1.0, fd-find 10.3.0, git-delta 0.18.2, duf 0.9.1, du-dust 1.2.4, tealdeer 1.8.1. All are recent releases, so Ubuntu's packages are used (Article 2), kept current with security fixes by unattended-upgrades. The upstream comparison could not be fetched when this was written; a tool whose Ubuntu package falls too far behind moves to its publisher's binary release, at the newest version like the other release binaries (Article 5), with the reason here.

FR-002

archon shell emit [bash|zsh|fish] prints the shell code, generated by src/archon/shell/emit.ts: aliases ls, ll, la, tree (eza, with icons where the prompt is the colorful one), bat and cat (bat, which Ubuntu installs as batcat), fd (Ubuntu's fdfind); fzf's key bindings with fd as its file source; zoxide; delta as git's pager; the terminal title; operators' archon abbreviations (fish); and the prompt. Every piece is guarded: nothing in a non-interactive shell, and each only when its tool is installed. Without a shell name it uses the parent process, else $SHELL.

FR-003

The prompt: plain on a console terminal (TERM linux or vt*, or a tty /dev/ttyN, /dev/ttyS*, /dev/ttyUSB*), with the status in words from /var/lib/archon/status/prompt-plain; Oh My Posh with archon.omp.json everywhere else. ARCHON_PROMPT=plain|pretty overrides.

FR-004

archon apply renders the three outputs into /usr/local/share/archon/shell/init.{bash,zsh,fish} and installs the theme there; the archon launcher prints the rendered file for archon shell emit without starting the engine (no Bun or Node).

FR-005

The fleet's dotfiles (home/dot_bashrc.tmpl, home/dot_config/fish/config.fish.tmpl) hold Ubuntu's defaults and the one line, for every persona. Personas no longer carry prompt or completion features.

FR-006

archon shell status shows which startup files carry the line.

FR-007

host.desktop (workstations): set by archon workstation add (false under WSL; true when the default target is graphical). VS Code (code, Microsoft's apt repository, key BC528686B50D79E339D3721CEB3E94ADBE1229CF pinned, followed by unattended-upgrades) only on a workstation with a desktop and a developer.

FR-008

The guide (welcome page, archon guide) explains the comforts, the prompt and its Nerd Font (workstations: how to install it, on Windows for WSL; servers: how to choose the plain prompt), and VS Code (installed, the WSL extension, or Remote - SSH).

#Overrides of Ubuntu defaults

None: Ubuntu's packages; aliases are interactive only and the originals stay reachable (command ls).
