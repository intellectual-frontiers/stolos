archon-boot/guard.ts

Spec 051: the blank-disk guard. Before Ubuntu's installer touches a disk, it reports the machine's own facts (from its firmware tables, /proc, and its disks) to this boot server, which answers "ok" or "stop: why". The install goes on by itself only when every disk is blank, when a person confirmed with --confirm-destroy <host>, or when the machine is this host already (it installed as this host, or boot reinstall reached it over SSH). Anything else stops before a byte is written, and the boot window says what the machine holds and the one command that lets it go on.

  disks -->|no| stop1["stop: no disk to install to"]
  disks -->|yes| blank{"every disk blank?<br/>(wipefs, partitions)"}

  same -->|no| stop2["stop before writing, power off<br/>(E051-DISK-NOT-BLANK)"]
  noanswer["no answer from the boot server"] --> stop3["no install"]
