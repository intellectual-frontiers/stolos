archon-boot/reinstall.ts

bun run stolos boot reinstall <host> (spec 004): one command from the boot machine re-installs a running host, with no one at its console:

A host that cannot be reached is armed anyway, with what to do at its console. Article 23 (spec 044): a durable host (asked over SSH with archon data), or one whose data class cannot be read, is reinstalled only with --confirm-destroy <host>, typed by a person.

  1. the boot server must be running (it serves the install);
  2. (spec 048: the host keeps its own records; nothing is pushed);
  3. the host is armed for one install;
  4. over SSH, archon reboot --netboot boots it from the network once;
  5. this PC trusts the host's SSH host keys, which the install brings back.

bun run stolos boot reinstall <host>: re-install a running host over the network in the steps the module describes. port is the boot server's HTTP port and confirmDestroy is the repeated name a durable host needs. A host that cannot be asked needs it too. Returns the exit code (2 for an unknown host).
