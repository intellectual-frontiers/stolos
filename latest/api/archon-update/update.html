update

archon update (spec 015): bring everything up to date from GitHub in one command. Pull origin/main, then (in the freshly pulled code) validate, converge, refresh tools, re-converge for dotfiles, and verify.

Output follows Article XXII: one phase per step. After a pull that brought new commits, the rest runs in a fresh process that continues the same screen and run log (ARCHON_UI_CONTINUE, ARCHON_LOG, ARCHON_UI_START).

Source: src/archon/update/update.ts

UpdateOptionsinterface
interface UpdateOptions

What archon update does.

MemberTypeWhat it is
checkbooleanOnly report: fetch without pulling, apply and sync tools in check mode, skip verify.
toolsbooleanRefresh tools (archon tools sync) after the apply.
pullbooleanPull origin/main first (false in the process that continues after a pull).
UpdateStepinterface
interface UpdateStep

One step of an update and how it went.

MemberTypeWhat it is
stepstringThe step: "pull", "validate", "apply", "tools", "apply (dotfiles)" or "verify".
okbooleanWhether it succeeded.
detailstringIts one-line result.
updatefunction
function update(host: HostDef, opts: UpdateOptions): Promise<UpdateStep[]>

archon update: pull, validate the model, apply, sync tools (and apply dotfiles again if a tool changed), then verify. After a pull that brought new commits, it runs the rest in the freshly pulled code and exits with that process's code. Stops after an invalid model without applying.
