pages

Spec 100: the pages of remote access.

  • For a device that is not signed in, on an HTTPS name (FR-004, FR-007): sign in with a passkey, or register this device (pick your signer, name it, create the passkey), then the code and the wait for a signer, then sign in. The browser's WebAuthn calls are a few lines of script on the page; nothing else runs in the browser.
  • The Remote Access page (/access, FR-010): the addresses and certificate, who can sign in, every device with its history, the codes waiting, recent sign-ins and refusals, and the flow.

Source: src/archon/access/pages.ts
