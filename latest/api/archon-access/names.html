names

Spec 100 FR-001: the Stolos Console's names on the site's network. With the fleet's web.domain (for example lab.example.net), stolos.lab.example.net names the primary controller and <pc>.stolos.lab.example.net each controller (<pc> is its controllerName()). The label stolos is fleet.stolos.console.name; the primary is fleet.stolos.console.primary (unset: the only controller, this one).

Source: src/archon/access/names.ts

DEFAULT_CONSOLE_NAMEconst
const DEFAULT_CONSOLE_NAME: "stolos"

The console's label under the web domain unless the fleet names another.

HEARTBEAT_LABELconst
const HEARTBEAT_LABEL: "_stolos-console"

The TXT record's first label: _stolos-console.<label>.<domain> holds the live heartbeat.

ConsoleNamesinterface
interface ConsoleNames

Every name the console uses on one controller.

MemberTypeWhat it is
domainstringThe fleet's web domain (lab.example.net): also the WebAuthn relying party's ID.
labelstringThe label (stolos).
basestringThe primary's name: stolos.lab.example.net.
ownstringThis controller's own name: <pc>.stolos.lab.example.net.
pcstringThis controller (its controllerName()).
primarybooleanWhether this controller answers as the base name.
primaryName?stringThe primary controller's name, when the fleet names one.
servedstring[]The names this controller answers on (its own; the base too on the primary).
certNamesstring[]The names its certificate covers: its own, the wildcard, and the base on the primary.
heartbeatstringThe heartbeat's TXT record name.
lanbooleanWhether the fleet says to serve on the LAN (lan: true).
consoleNamesfunction
function consoleNames(fleet: Pick<FleetDef, "stolos" | "web">, pc: string): ConsoleNames | undefined

The console's names on controller pc, or undefined when the fleet has no web domain.
