routes

Spec 100: the console's requests that come before a session, on its HTTPS names (and, for a signer's devices approve on this PC, on 127.0.0.1):

  • GET /access/pending/<code>: a pending registration's public fields, as JSON (FR-005);
  • GET /access/status/<code>: waiting, approved or gone, for the waiting page (FR-006);
  • POST /access/register/options and /finish: a new passkey (FR-004);
  • POST /access/signin/options and /finish: a sign-in (FR-007).

POSTs are JSON from this origin only. Wrong codes count against the address like failed sign-ins.

Source: src/archon/access/routes.ts
