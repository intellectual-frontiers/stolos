launch

Spec 100: what stolos console --lan adds to the console. In order: the names (FR-001), a trusted address (Article 28), the Cloudflare token, the certificate (FR-002), the DNS records, remote access itself (the signed tip read once), then, once the console's handler exists, the HTTPS listener on 443 (FR-003, spec 103-three-ports FR-009: no fallback; another port is an explicit choice) and the timers: the heartbeat every 5 minutes, the signed tip every 30 seconds while a code waits (else 5 minutes), the certificate daily, the digest daily.

Source: src/archon/access/launch.ts
