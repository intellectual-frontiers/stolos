devices

Spec 100: the devices that may sign in to the Stolos Console, and the codes waiting for a signer's approval.

  • fleets/<fleet>/access.ts lists the approved devices (FR-005): public keys only, written by stolos devices approve and stolos devices revoke in one fixed form (a typed literal) and read back without running it (exportedLiteral), so a past version from git show is safe to read.
  • A pending registration (FR-004) lives in the console's memory for 15 minutes under an 8-character code (spec 098's alphabet): nothing is written before a signer approves.
  • The local record (console-access.json in this PC's state, never Git): the tip last honoured, each device's signature counter and last sign-in, the last digest, and the listener.

Source: src/archon/access/devices.ts
