tags

Spec 112-machine-reported-tags FR-007, FR-008, FR-009: a machine's own tags table. The tags a machine says about itself live in its state database (archon.sql, the view archon_tags, so osquery reads them like any other table): one row per tag with its dimension ("" for a free-form tag), value, source (local, set by a person on the machine with archon tag add, or fleet, what the machine worked out from the fleet repository it holds at its last apply), set_by and set_at. None of it changes the machine's configuration.

Source: src/archon/state/tags.ts
