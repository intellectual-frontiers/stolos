verify

archon verify (Article 15, spec 014): run every verification command in the host's plan and report each result. As root, the result is also kept in the host's own archon.sql (opt-in verify) when it changes (stolos fleet status).

Source: src/archon/state/verify.ts

Checkinterface
interface Check

One check's result.

MemberTypeWhat it is
resourcestringWhat it checks (a package, a unit, a check's name).
commandstringThe command run.
okbooleanIt passed.
outputstringThe first line it printed.
level?"fail" | "pending" | "warn""warn": a failure is reported as a warning and does not count as failed. "pending" (spec 052): the check exited 3, "not set up yet": shown with its next step, never a failure or a warning.
fix?stringHow to make it pass, when the check says (the model's fix, or the command to run).
code?stringIts explain code, when it has one (archon explain <code>).
Attentioninterface
interface Attention

One check that needs attention, with what to do about it: the consoles show these (the Archon Console's Overview, the Stolos Console's machine page), so a warning is never a bare number.

MemberTypeWhat it is
resourcestringWhat it checks.
level"fail" | "pending" | "warn"How serious: fail, warn, or pending (not set up yet).
outputstringWhat it found (the check's first line of output).
fixstringHow to make it pass.
code?stringIts explain code (archon explain <code>), when it has one.
attentionOffunction
function attentionOf(checks: Check[]): Attention[]

The checks that did not pass, each with its level and fix.

PENDING_EXITconst
const PENDING_EXIT: 3

Spec 052: a check that exits 3 says "not set up yet" (a token not delivered, ...).

RecordedVerifyinterface
interface RecordedVerify

The latest verify, in this machine's archon.sql (spec 048): read over SSH by fleet status (archon query). `since` is when this result first appeared; the record is rewritten only when the result changes.

MemberTypeWhat it is
passednumberHow many passed.
totalnumberHow many ran (pending ones included).
failedstring[]Failures, by resource.
warnedstring[]Warnings, by resource.
pending?string[]Spec 052: not set up yet (a check that exited 3).
attention?Attention[]Every check that did not pass, with its fix (newer engines).
sincestringWhen this result first appeared.
