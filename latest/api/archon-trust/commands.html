commands

Spec 081: stolos trust build --bundle <zip>: verify an evidence bundle, then write a Trust Center from it: index.html, and under evidence/ the bundle it links to (the full one when gated; a signed public summary when public), unpacked so that each claim's link is the item itself.

Source: src/archon/trust/commands.ts

MARKERconst
const MARKER: ".stolos-trust"

The file a Trust Center's output folder holds, so a rebuild may replace it (and nothing else).

TrustOptionsinterface
interface TrustOptions

How to build a Trust Center.

MemberTypeWhat it is
mode?"gated" | "public"Public (the default: redacted, a summary bundle) or gated (everything, the full bundle).
sign?SignerPublic: sign the summary bundle (as the full bundle's signer). Absent: the evidence is on request.
allowedSigners?stringAn allowed_signers text to verify the bundle with instead of its own.
catalog?ScfCatalogThe SCF catalog (only the release the bundle names is used).
frameworks?("cmmc" | "fedramp" | "hipaa" | "nist800171" | "nist80053" | "pci" | "soc2")[]The frameworks to show (default: every one the mappings reach).
contact?stringThe company's link for questions and access requests (https: or mailto:).
now?DateWhen the page is built.
stolos?stringThe Stolos version building it.
