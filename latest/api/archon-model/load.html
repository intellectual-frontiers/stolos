load

Load the active fleet (fleets/<id>/fleet.ts, written by stolos fleet init) and every host (fleets/<id>/hosts/<name>/host.ts, written by stolos host add). Hosts are discovered from the directory, so there is no index to keep in sync.

Source: src/archon/model/load.ts

mcpTierfunction
function mcpTier(fleet: FleetDef): McpTier

The tier workstations get over MCP (spec 030); never destructive.

mcpAuthorizedKeysfunction
function mcpAuthorizedKeys(fleet: FleetDef): string[]

ops' authorized_keys (spec 030, Article 17): each key may only start archon mcp at the fleet's tier. restrict turns off the shell, port, agent, and X11 forwarding; the client cannot choose another command.

No active fleet: none chosen, or fleets/<id>/fleet.ts is missing. The message says how to make one.

fleetExportfunction
function fleetExport<T>(file: string, name: string, fresh?: boolean): Promise<T | undefined>

A named export of one of the fleet's own TypeScript files (fleet.ts, host.ts, registration.ts, decisions.ts), which the fleet's type check covers; fresh reads it again after a change: a new URL for Node, and the file's entry out of the module cache for Bun, which caches a file by its path whatever its query.

loadFleetfunction
function loadFleet(): Promise<FleetDef>

Import the active fleet's fleet.ts, with its signers (spec 047). Throws NoFleetError when there is none, or when its id does not match its folder.

loadHostsfunction
function loadHosts(): Promise<HostDef[]>

Import every host (servers and workstations) sorted by name, each with what this machine records about it: its registration and MAC (spec 051), its PostgreSQL state (spec 038), and its opt-ins (decisions in Git win, spec 047). Folders starting with _ are skipped.

hostFilefunction
function hostFile(name: string): string

fleets/<id>/hosts/<host>/host.ts (spec 046-engine-instance).

readPgStatefunction
function readPgState(host: string, root?: string): Promise<PgState | undefined>

The PostgreSQL record (the opt-in "pg" and the instances made), when there is one (spec 038).

readOptInsfunction
function readOptIns(host: string, root?: string): Promise<Record<string, OptInRecord>>

Every opt-in decision recorded on this machine for a host (spec 040, kept in archon.sql by spec 048): each record whose `enabled` is a boolean.

isWorkstationconst
const isWorkstation: (h: HostDef) => boolean

True for a workstation (spec 020); the boot server never installs one.

loadServersfunction
function loadServers(): Promise<HostDef[]>

Hosts the boot server installs (workstations are never installed over the network).

usersForfunction
function usersFor(fleet: FleetDef, host: HostDef): UserDef[]

The accounts every host has: the fleet admin, ops (the operator account that converges the host and serves workstations' agents over MCP), then extras. A workstation has one: its existing user (spec 020).

homeOffunction
function homeOf(u: { name: string; }): string

An account's home directory: /root for root, /home/<name> otherwise.
