#What a machine says about itself

A machine can say what it is: a person set DEPLOYMENT=production in its /etc/machine-info (systemd machine-info(5)), its firmware says it is a Dell laptop or an Amazon EC2 instance (DMTF DSP0134 SMBIOS), and a person on it added tags of its own with archon tag add (spec 112-machine-reported-tags). The fleet reads those as claims (stolos:TagClaim): never its own tags, always untrusted input. This module is the pure part: it turns the raw text a machine sent into claims, with the tag grammar of spec 108, a cap on each tag and on each machine, and a count of what it dropped. It never evaluates, never builds a pattern or a path from what it reads, and never throws on a machine's words.

ParsedClaimsinterface

MemberTypeWhat it is

plainfunction
function plain(s: unknown, max?: number): string

A raw string from a machine: no control or direction characters, trimmed, at most max characters.

slugfunction
function slug(text: string): string

A word of the tag grammar made from free text: lowercase letters and digits joined by -, at most 30 characters; "" when nothing is left.

claimTagfunction
function claimTag(raw: unknown): string | undefined

One tag as a machine wrote it, read with the grammar of spec 108: <dimension>:<value>, or a lowercase word; at most 64 characters. Undefined where it is not one (the caller counts it).

parseMachineInfofunction
function parseMachineInfo(text: string): Record<string, string>

Read /etc/machine-info (the format of os-release: KEY=value, # comments, a value in single or double quotes) as data: nothing is run or expanded. Only DEPLOYMENT, LOCATION, CHASSIS and TAGS are kept, each cut to REPORT_LIMITS.rawChars.

sanitizeReportfunction
function sanitizeReport(raw: unknown, at?: string): MachineReport | undefined

A bounded copy of what a machine sent, safe to keep and to read again: unknown keys left out, strings cleaned and cut, at most REPORT_LIMITS.rows rows. undefined where it is not a report at all.

reportFromProbefunction
function reportFromProbe(section: Readonly<Record<string, string>> | undefined, at?: string | undefined): MachineReport | undefined

The probe's @reported section as a report (machine_info_* and smbios_* keys, as the POSIX and PowerShell probes write them).

kindOfChassisTypefunction
function kindOfChassisType(code: string | undefined): string | undefined

The kind a chassis type of DSP0134 means (9 is a laptop), or undefined.

cloudOffunction
function cloudOf(s: Smbios): string | undefined

A cloud provider named by the firmware's maker and model (Amazon EC2, Google Compute Engine), as a word; undefined where none is.

claimsFromfunction
function claimsFrom(report: MachineReport | undefined, map?: MachineInfoMap<string> | undefined, channel?: "announced" | "reported"): ParsedClaims

The claims a report makes (spec 112-machine-reported-tags FR-004 to FR-008): its own tags table, /etc/machine-info (through the fleet's machineInfoMap where it says what a value means), and its firmware. A thing that is not a tag of the grammar, or over the caps, is dropped and counted: what a machine says never makes this fail.
