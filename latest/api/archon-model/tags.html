tags

#Tags

A fleet describes its machines with tags it defines itself (spec 108-tags), in TypeScript, in fleets/<fleet>/tags.ts. A tag belongs to a dimension (env, role, site, owner, criticality, data): a one-of dimension (a machine holds at most one value, an environment) or a many-of one (a machine may hold several, its roles). A tag is written <dimension>:<value> (env:prod) and has a label, a colour (a name of the console's palette) and a description. The tags' ids are a TypeScript union inferred from that file, so a tag the fleet does not define is a type error wherever it is written, and a problem of stolos build where it is read.

A free-form tag is allowed too: a lowercase word with no colon (pilot). It is never defined, and it is always shown as custom, apart from the defined ones. A rule in tags.ts gives a defined tag from what Stolos knows of a machine (os windows gives os:windows); a group (a site network, an address range, named machines) gives its tags to its members. A tag a person gave wins over a rule's, and a rule's over a group's.

Choosing machines by tag uses a small typed parser (env:prod and not role:db), never code.

resolveTagsfunction
function resolveTags(set: Pick<TagSet<Readonly<Record<string, TagDimensionDef>>, string>, "dimensions" | "groups" | "rules"> | undefined, facts: TagFacts, assigned?: TagAssignment, networks?: Readonly<Record<string, string>>, claims?: readonly ReportedClaim[]): ResolvedTags

The tags a machine holds: the ones a person gave, then the rules' (run over facts), then its groups', each with its origin. A one-of dimension holds one value: the strongest origin's (person, then rule, then inherited) is kept and the other is listed as dropped; two values of the same strength are a problem, and the first stays. Free-form tags come last, always as custom.

Spec 112-machine-reported-tags: then the machine's own claims, reported before announced, below everything the fleet says. A claim in a dimension that says fromMachine: "ignore" is dropped and counted; one the fleet does not define is listed and never held; one of a one-of dimension where the fleet holds another value is dropped and is a disagreement (the fleet wins, and says so); the rest are held with the origin reported (or announced), with the trust of their dimension (hint or accept).
