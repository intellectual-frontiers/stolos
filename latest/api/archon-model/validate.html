validate

TypeScript is the validator (Article 10, spec 002). Each rule returns problems with a message and a fix; an invalid model renders, installs, and applies nothing.

Source: src/archon/model/validate.ts

Probleminterface
interface Problem

One thing wrong with the model.

MemberTypeWhat it is
wherestringWhere it is: a fleet path (fleet.admin.user) or a host (hosts/<name>).
messagestringWhat is wrong.
fixstringHow to fix it.
findSecretfunction
function findSecret(text: string): string | undefined

What kind of secret text seems to contain ("a private key", "a GitHub token"), or undefined.

validateFleetfunction
function validateFleet(fleet: FleetDef, hosts: HostDef[]): Problem[]

Check the fleet and its hosts (names, keys, settings, the site, and no secrets in the model). Empty when valid.

validatePlanfunction
function validatePlan(plan: HostPlan, knownSpecs: Set<string>): Problem[]

Check a host's resolved plan: every spec it uses exists in knownSpecs, and its files, ports, units and tools are well formed and carry no secret. Empty when valid.
