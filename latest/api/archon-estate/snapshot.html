snapshot

Spec 090: what the estate graph is built from, read from the fleet repository as it is now or at any commit, without running any of it: the connectors' observations (estate/<id>.ts), the links people made (estate/links.ts), the adopted machines, the SNMP devices, and the managed hosts. Every file Stolos writes is a TypeScript literal, which IFC TypeScript's exportedLiteral reads; the managed hosts are known by their folders. Each source's history (git log) gives first-seen and last-seen times.

Source: src/archon/estate/snapshot.ts
