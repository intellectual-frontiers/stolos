registry-contract

Spec 088: the contract a registry connector keeps, and how Stolos reads one without trusting it. A connector module default-exports a defineConnector result, and names two more things:

  • engine: the range of engine versions it supports (">=0.112.0 <1.0.0");
  • fixtures: its recorded-fixture tests (ConnectorFixture), which Stolos runs itself, against recorded responses only, before it adds the connector and whenever stolos connector test asks.

declare reads a loaded module into a Declaration: its id, labels, OCSF classes, the SCF controls its policies cite, its credential's fields, and its fixtures' results. The registry probe runs it in a process of its own, given none of the environment but the engine's paths, and the engine's checks (registry.ts) judge what it reports.

Source: src/archon/connect/registry-contract.ts

MemberTypeWhat it is
namestringWhat it shows, for people.
