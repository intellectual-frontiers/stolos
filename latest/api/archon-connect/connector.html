connector

Spec 084: connectors. Each reads one outside account (a cloud, an identity provider, a code host, an HR system, ...) with a read-only credential kept in the vault, writes what it found to fleets/<fleet>/estate/<id>.ts (GENERATED, so git log -p is the account's history), and checks posture policies tagged with SCF controls. A connector never changes the account.

Source: src/archon/connect/connector.ts
