linear

Spec 087: Linear, read-only: the workspace (whether sign-in goes through SAML), its people (active, admin, guest, last seen), and the last 90 days of issues: each one's identifier, type (change, incident, or other, from its labels and team), status, created and completed times, and the commits and pull requests attached to it (Linear's GitHub, GitLab, and Bitbucket integrations attach them). Evidence for change control (SCF CHG-03), least privilege (IAC-30), and MFA through the identity provider (IAC-37).

Linear's API is GraphQL only, and GraphQL is sent by POST: the read-only guard lets POST reach the GraphQL endpoint alone, and this connector sends it queries only (a mutation is refused before it leaves). The key itself is made with Linear's Read permission only.

Source: src/archon/connect/linear.ts
