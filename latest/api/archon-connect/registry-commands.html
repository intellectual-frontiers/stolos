registry-commands

Spec 088: stolos connector add | list | remove | test, the connector registry's commands, run in the fleet repository on your PC. Adding one is like moving the engine's pin: checked first, then copied into the fleet repository with its lock entry, then committed and pushed by you (pushing is the approval).

Source: src/archon/connect/registry-commands.ts

RegistryOptionsinterface
interface RegistryOptions

Where the commands work (default: the fleet repository and fleet this PC uses).

MemberTypeWhat it is
repo?stringThe fleet repository.
fleetDir?stringThe fleet's folder (fleets/<fleet>).
version?stringThis engine's version (tests).
runProbefunction
function runProbe(repo: string, module: string): Promise<Declaration>

Run the probe on a module (a file) in its own process, under the runtime running this one: given only the environment variables the engine reads for its paths, and no standard input. The module resolves the engine from the folder it is in (a fleet repository's, or an author's own project's).

Checkedinterface
interface Checked

What connector add and connector test find for one module.

MemberTypeWhat it is
declaration?DeclarationThe declaration, when the module loads.
text?stringThe module's text, as fetched and checked.
sha256?stringThe module's SHA-256.
problemsstring[]What is wrong (none: it may be added).
checkModulefunction
function checkModule(repo: string, fleetDir: string, module: string, others: string[], version: string): Promise<Checked>

Fetch, probe, and check one module against the engine and the fleet's other connectors. A module fetched over HTTP(S) is probed from a file in the fleet's connectors/ folder (so it resolves the engine the fleet installs), removed after; a local module is probed where it is.

connectorAddfunction
function connectorAdd(spec: string, o?: RegistryOptions & { index?: string | undefined; today?: string | undefined; }): Promise<number>

stolos connector add <source>@<ref> [--index <url>].

connectorListfunction
function connectorList(asJson?: boolean, o?: RegistryOptions): Promise<number>

stolos connector list [--json].

connectorRemovefunction
function connectorRemove(id: string, o?: RegistryOptions): Promise<number>

stolos connector remove <id>: the import, the entry and the copy go; its observation stays in Git.

connectorTestfunction
function connectorTest(target?: string | undefined, o?: RegistryOptions): Promise<number>

stolos connector test [id | path]: each added connector (or one) is probed again: its copy and its pinned module still hash as locked, it suits this engine, and its fixtures pass. A path or URL tests a module not added yet (the author's own check).
