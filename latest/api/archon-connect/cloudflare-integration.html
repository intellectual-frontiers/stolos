cloudflare-integration

Spec 109-integrations-api FR-007, FR-008: Cloudflare as an implementation of two kinds of the integration layer, beside its connector (cloudflare.ts, spec 067, which keeps working unchanged).

  • dns: zones and records, the same reads the connector makes (the layer shares them, so no request is sent twice).
  • email: domains (the domains' email DNS records Cloudflare manages: MX, SPF, DKIM, DMARC, and whether Email Routing is on) and routing (the Email Routing rules, without the addresses they forward to). sending is not offered: this release reads inbound routing and the DNS only.

The web front door (spec 032, src/archon/web/cloudflare.ts) uses Cloudflare to write the server's own certificate challenges and records; that code is left as it is (tasks.md, L001).

Source: src/archon/connect/cloudflare-integration.ts
