converge

038-pg, 039-pg-identity: make each instance what the model and the host's record say. Run by every apply (its Databases phase, so the reconcile timer keeps instances) and by archon pg ensure. Archon touches only clusters it created (FR-003).

Source: src/archon/pg/converge.ts

Sinkinterface
interface Sink

Where converge reports (apply's Runner, or a command's phase).

MemberTypeWhat it is
checkbooleanA read-only check: report what would change, change nothing.
change(msg: string) => voidReport a change made (or, in a check, one that would be made).
warn(msg: string, fix?: string | undefined) => voidReport a problem that does not stop converge, with an optional fix to suggest.
fail(msg: string, fix?: string | undefined) => voidReport a failure, with an optional fix to suggest.
unreadable?((path: string) => void)A read-only check could not read this file as the calling user.
clustersfunction
function clusters(): Promise<Cluster[]>

The host's PostgreSQL clusters, from pg_lsclusters (empty when it fails).

secretPathconst
const secretPath: (inst: string, role: string) => string

Where a role's password for an instance is kept, under PG.secrets (as the host names it: read and write it through onHost).

psqlfunction
function psql(v: number, n: string, sql: string, db?: string): Promise<RunResult>

psql as postgres against one cluster (Debian's wrapper picks it by --cluster).

readStatefunction
function readState(host: string, root?: string): Promise<PgState>

Read the host's pg record (the switch and the instances); no instances when there is none.

writeStatefunction
function writeState(host: string, st: PgState, root?: string): Promise<void>

Write the whole record (the switch and the instances), sorted.

writeRecordfunction
function writeRecord(host: string, name: string, rec: PgRecord | undefined, root?: string): Promise<void>

Set one instance's record, or remove it when rec is undefined.

ensureVersionfunction
function ensureVersion(fleet: FleetDef, host: HostDef, v: number, s: Sink): Promise<boolean>

postgresql-<v>: Ubuntu's for 18, PGDG's (Ubuntu's own key) for the others.

wildcardFromfunction
function wildcardFrom(acme: string, fqdn: string): { cert: string; key: string; } | undefined

The server's wildcard certificate from Traefik's store (spec 032), for a published instance: libpq clients verify pg-<name>.<host>.<domain> with sslrootcert=system. Undefined when there is none yet.

convergeInstancefunction
function convergeInstance(fleet: FleetDef, host: HostDef, inst: Instance, s: Sink, by: string): Promise<boolean>

Make one instance right. Returns false on a failure (reported to the sink). by: who asked (recorded when the cluster is created).

accountExistsfunction
function accountExists(name: string): Promise<boolean>

A Linux account's existence (every login role must be one).

groupMembersfunction
function groupMembers(group: string): Promise<string[]>

A Linux group's members: listed members and those whose primary group it is.

convergeIdentitiesfunction
function convergeIdentities(v: number, inst: Instance, s: Sink): Promise<boolean>

An instance's identities (spec 039): every login role it wants (a superuser among them made NOSUPERUSER); a login role that is Archon's but not wanted, or has no Linux account of its name, made NOLOGIN (never dropped); passwords only for services; then each database's roles, members, rights, and extensions. False when a step failed.

writeSystemServicesfunction
function writeSystemServices(host: string, s: Sink): Promise<void>

libpq's system-wide service file (spec 039), written after the instances exist: a new one's port is known only once it is created.
