bundle

Spec 072: evidence bundles. One ZIP holds a period's evidence (the observations as Git recorded them, the verify results, the commits with their signatures, and the OSCAL assessment results), each item stored under its own SHA-256 (content-addressed), listed in a manifest in order, each entry chained to the one before (a hash chain), and the manifest signed by a fleet signer's key (ssh-keygen -Y sign, namespace stolos-evidence). An auditor re-checks it offline: every item unchanged, none missing or added, the chain whole, the manifest signed by a signer, and each commit signed as Git signs it.

The ZIP also holds allowed_signers (the fleet's signers when it was made) and a README saying how to check it with sha256sum and ssh-keygen alone. The signers in a bundle vouch for themselves: an auditor who has the fleet's signers from elsewhere passes them with --signers.

Built on IFC TypeScript: SHA-256 and the ZIP (deflated) are the kernel's, signing is runtime sign.sshSigner and checking a signature runtime sign.sshVerifier, both ssh-keygen -Y in the namespace stolos-evidence.

Source: src/archon/evidence/bundle.ts
