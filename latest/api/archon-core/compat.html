compat

The contract between a PC and its machines (spec 115-compatibility): archon (on each machine) and stolos (on the PC) are one engine, with one version and one release train (spec 114-release-record); what is versioned on its own is the contract between them, in five seams. A seam is one interface with a Semantic Version current and a minimum: the oldest version of that seam the other side may have, that is, the oldest this side still understands. Every number is written here and nowhere else; a golden test (tests/compat115.test.ts, bun run compat:digest) fails when the shape of a seam changes and its version does not.

The rule of change is Semantic Versioning 2.0.0's: a change that breaks a reader raises the major, an addition a reader may ignore raises the minor. A PC judges each machine against its own contract, seam by seam (judgeMachine), and says it in plain words with the fix (describeCompat); the engine's own number takes no part in the judgement, only in the words.

SeamVersioninterface
interface SeamVersion

One seam's version on this side: the version it is at, and the oldest version of the other side it still understands.

MemberTypeWhat it is
currentstringThe Semantic Version this side is at.
minimumstringThe oldest Semantic Version of the other side that this side understands (never above current).
SEAMSconst
const SEAMS: Readonly<Record<Seam, SeamVersion>>

The seams, and each seam's version: the one place they are written (spec 115-compatibility FR-001). Raise current in the change that needs it: the major for a change that breaks a reader, the minor for an addition (FR-002); bun run compat:digest refuses to record a changed shape under an unchanged version.

The seams a machine that runs archon has: the PC reads them from its archon state.

The seams an adopted machine (and the controller) has: its probe's facts.

type ContractKind = "managed" | "adopted";

How a machine is reached, which says which seams it has: a managed server or workstation, or an adopted machine.

SemVertype
type SemVer = readonly [number, number, number];

A Semantic Version as numbers: major, minor, patch.

parseSemVerfunction
function parseSemVer(text: unknown): SemVer | undefined

A version of the form major.minor.patch (each at most five digits), or undefined: a machine's words are never trusted further.

compareSemVerfunction
function compareSemVer(a: SemVer, b: SemVer): number

-1, 0 or 1 by Semantic Versioning's precedence (numbers; no pre-release in a seam's version).

judgeSeamfunction
function judgeSeam(seam: Seam, said: ReportedSeam | undefined): SeamCheck

One seam of one machine against this PC's contract (spec 115-compatibility FR-007): too old where the machine's current is below this PC's minimum; newer where the machine's minimum is above this PC's current or its current is of a higher major; unknown where it did not report (or reported something that is not a version); otherwise compatible.

MachineJudgementinterface
interface MachineJudgement

A machine judged: its status, its engine, and each seam it was judged on.

MemberTypeWhat it is
statusCompatStatusIts status (stolos:CompatStatus).
engine?stringThe engine it reported, when it did.
seamsreadonly SeamCheck[]Each seam of its kind, in the ontology's order.
judgeMachinefunction
function judgeMachine(kind: ContractKind, report: ContractReport | undefined): MachineJudgement

A machine against this PC's contract (spec 115-compatibility FR-007): the seams its kind has, each judged; too-old where any is (the machine cannot be read, or cannot read), else newer where any is, else unknown where any is unknown or nothing was reported, else compatible. The engine's version takes no part in it.

CompatWordsinterface
interface CompatWords

A machine's statement in plain words (spec 115-compatibility FR-008).

MemberTypeWhat it is
statusCompatStatusThe status.
headlinestringThe statement: compatible, too old for this PC: run archon update on alpha, newer than this PC: ..., unknown (not reported yet).
detailstringThe sentence for a list: who runs what, and why it is not compatible.
fix?stringThe command that fixes it, alone (nothing for a compatible machine).
code?"E115-NEWER" | "E115-TOO-OLD" | "P115-UNKNOWN"The code stolos explain knows, for a status that is a problem or a thing to do.
UPDATE_PCconst
const UPDATE_PC: "bun run stolos update"

The command that moves the PC's engine forward (the same for every machine).

describeCompatfunction
function describeCompat(name: string, kind: ContractKind, j: MachineJudgement, pcEngine?: string): CompatWords

A judgement said in plain words, once, for every place that shows it (spec 115-compatibility FR-008): alpha runs engine 0.148.0, compatible with this PC's 0.152.0; too old for this PC: run archon update on alpha (ssh alpha archon update); newer than this PC: run bun run stolos update; unknown (not reported yet). For an adopted machine the fix is the command that installs the current probe.

seamRuleProblemsfunction
function seamRuleProblems(seams?: Readonly<Record<Seam, SeamVersion>>): string[]

The rules of FR-002 that hold for every seam of SEAMS: both versions are Semantic Versions, minimum is not above current and is of the same or an older major. Empty when they hold.
