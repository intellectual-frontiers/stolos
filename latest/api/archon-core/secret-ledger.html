secret-ledger

The secret ledger (spec 029): when each boot-machine secret last changed, by name only. It holds no secret: it is what tells bun run stolos vault status (and the reminders) that something is newer than the last backup. %LOCALAPPDATA%\stolos\vault\ledger.json (Linux: ~/.local/share/stolos/vault).

Source: src/archon/core/secret-ledger.ts

VAULT_LOCALconst
const VAULT_LOCAL: string

The vault's local folder on the boot machine (holds the ledger; no secret).

LEDGERconst
const LEDGER: string

The ledger file: ledger.json in VAULT_LOCAL.

ledgerFilefunction
function ledgerFile(): string

The ledger for this run: LEDGER, or, for a provider's client (spec 082), clients/<id>/ledger.json beside it, so each client's backups are tracked apart.

LedgerBackupinterface
interface LedgerBackup

The record of the last backup (spec 056): its ZIP, where it was written, and what it held.

MemberTypeWhat it is
atstringWhen it was made (ISO 8601).
filestringThe backup's file name (spec 056: a ZIP; spec 029's backups were folders).
dir?stringThe folder it was written to (the backup folder); older records lack it.
namesRecord<string, string>Path inside the secrets folder -> SHA-256 of what was backed up.
Ledgerinterface
interface Ledger

The ledger's contents: secrets' change times and the last backup, by name only.

MemberTypeWhat it is
changesRecord<string, { changedAt: string; removed?: boolean | undefined; }>Path inside the secrets folder (forward slashes) -> when it was written or removed.
lastBackup?LedgerBackupThe last backup recorded; absent before the first one.
remindedAt?stringThe last "N secrets not backed up" email (spec 025).

Write the ledger (as formatted JSON), creating the vault folder first.

const secretName: (file: string) => string

The secret's name: its path inside the secrets folder, with forward slashes.

changedThisRunconst
const changedThisRun: Set<string>

Secrets changed by this process (for the closing panel).

recordChangefunction
function recordChange(file: string, removed?: boolean): Promise<void>

Record that a secret was written (or removed) now, then prepare the closing panel. Never throws: the ledger is advisory.
