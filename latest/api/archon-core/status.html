status

The prompt's Archon segment (spec 009): every archon command ends by writing one short line to /var/lib/archon/status/prompt, and the oh-my-posh theme only reads that file, so the prompt stays instant. The line says how the last run went, how many disruptive changes wait, and whether the checkout has local commits that are not on GitHub.

Source: src/archon/core/status.ts

STATUS_DIRconst
const STATUS_DIR: "/var/lib/archon/status"

Where the status files live: prompt, prompt-plain, last.json and verify.json.

RunStatusinterface
interface RunStatus

How an archon command's run went, as the prompt shows it.

MemberTypeWhat it is
commandstringThe command that ran ("update", "apply").
failuresnumberHow many steps failed.
warningsnumberHow many steps warned.
deferrednumberHow many disruptive changes wait for approval.
pushPendingfunction
function pushPending(repo?: string): Promise<boolean>

Local commits not on GitHub yet (no network: uses the last fetch).

promptLinefunction
function promptLine(s: RunStatus, push: boolean): string

The prompt segment with Nerd Font glyphs: the result, deferred changes, and a push marker.

promptLinePlainfunction
function promptLinePlain(s: RunStatus, push: boolean): string

The same status in words, for the plain prompt (spec 036): "update ok, push".

LastRuninterface
interface LastRun extends RunStatus

The last run, as data (the welcome page reads it; the prompt reads the line).

MemberTypeWhat it is
atstringWhen it was written (ISO 8601).
pushbooleanWhether the checkout had local commits not on GitHub.
commandstringThe command that ran ("update", "apply").
failuresnumberHow many steps failed.
warningsnumberHow many steps warned.
deferrednumberHow many disruptive changes wait for approval.
LastVerifyinterface
interface LastVerify

The last archon verify as root (spec 035): the welcome page's "checks now".

MemberTypeWhat it is
atstringWhen it ran (ISO 8601).
passednumberHow many checks passed.
totalnumberHow many checks ran.
failedstring[]The resources whose checks failed.
attention?{ resource: string; level: "fail" | "pending" | "warn"; output: string; fix: string; code?: string | undefined; }[]Every check that did not pass (failed, warned, or not set up yet), with its fix.
writeVerifyfunction
function writeVerify(v: LastVerify): Promise<void>

Save the last verify for the welcome page (verify.json). Best effort: errors are ignored.

writeStatusfunction
function writeStatus(s: RunStatus): Promise<void>

Write the run's status: last.json, the plain line and the prompt line. Best effort: a host without /var/lib/archon (a workstation) has no segment.
