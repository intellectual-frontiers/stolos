listeners

The three ports the controller PC opens for Stolos (constitution Article 29, spec 103-three-ports): UDP 69 and TCP 8080 for the boot server, TCP 443 for the console over TLS. The numbers are facts of the ontology (stolos:Listener); this module is the one place the code reads them, so every listener that is not loopback-only takes its default from standardPort and marks any other port as an explicit choice (choosePort), with its own firewall rule (firewallRule). tests/ports103.test.ts fails on a socket opened anywhere else.

Source: src/archon/core/listeners.ts
