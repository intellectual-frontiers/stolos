archon core

Tell a running boot server something happened on this PC (spec 004): an event (spec 049) it records and shows in its window and boot.log. Arming, for example, is only a file the server reads when a machine contacts it, so without this the window stays silent until the host network-boots. Loopback only; best effort: no server running is not an error.
