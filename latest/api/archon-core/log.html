log

Logging adapter over the calm-output UI (Article XXII, spec 018), plus journald through logger(1) (util-linux, native; Article XVIII).

step starts a phase; ok/change/skip are counted (shown with --verbose); warn/error are always shown and repeated under "Needs attention"; skips that mention "disruptive" are collected into the single Deferred line.

Source: src/archon/core/log.ts

logconst
const log: { readonly info: (msg: string) => void; readonly step: (msg: string) => Phase; readonly ok: (msg: string) => void; readonly change: (msg: string) => void; readonly skip: (msg: string) => void; readonly warn: (msg: string, fix?: string | undefined) => void; readonly error: (msg: string, fix?: string | undefined) => void; }

The logger the engine uses: step starts a phase, info notes, ok, change and skip are counted, warn and error (with an optional fix) are always shown. A skip that mentions "disruptive" becomes a deferral.

journalfunction
function journal(tag: string, message: string, priority?: string): Promise<void>

Write message to the systemd journal with logger(1), tagged tag at syslog priority.
