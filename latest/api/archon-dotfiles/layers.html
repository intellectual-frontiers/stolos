layers

031-dotfile-layers: every user's chezmoi source is composed from layers, most general first (spec 046: the engine's base travels with the engine; the rest is in the fleet repository, under the fleet's folder):

Source: src/archon/dotfiles/layers.ts

COMPOSED_ROOTconst
const COMPOSED_ROOT: "/var/lib/archon-dotfiles"

Where archon apply writes each user's composed chezmoi source (one directory per user).

LayerKindtype
type LayerKind = "engine" | "fleet" | "host" | "user" | "host-user";

Which layer it is, most general first: engine, fleet, host, user, host-user.

ENGINE_LAYERconst
const ENGINE_LAYER: "@engine/home"

The engine's base layer: read from the engine's own files (assets.auto.ts), not the repository.

interface Layer

One layer of a user's dotfiles.

MemberTypeWhat it is
kindLayerKindWhich layer it is.
dirstringRepository-relative directory (forward slashes).

The five layers for one user on one host in a fleet, most general first.

composedDirfunction
function composedDir(user: string): string

The composed source directory for a user, under COMPOSED_ROOT: a host's path, always /.

targetNamefunction
function targetName(component: string, isFile: boolean): string

The target name of one source path component ("private_dot_ssh" is ".ssh").

targetOffunction
function targetOf(sourceRel: string): string

The target path (relative to the home directory) of a source path.

forbiddenfunction
function forbidden(sourceRel: string): string | undefined

Why a source file may not be in any layer, or undefined. Scripts run code at apply time, encrypted files are secrets (Article 13), externals download without a pinned checksum (Article 12), and a .chezmoiroot would point chezmoi elsewhere.

Compositioninterface
interface Composition

A user's composed dotfiles source, with any problems found on the way.

MemberTypeWhat it is
layersLayer[]Every layer considered, most general first.
presentLayer[]Layers that exist (have at least one file).
filesComposedFile[]The files that won, sorted by source path.
concatenatedMap<string, string>Concatenated special files (.chezmoiignore, .chezmoiremove) and their text.
problemsstring[]Files left out and why (forbidden kinds, two sources for one target in a layer).
