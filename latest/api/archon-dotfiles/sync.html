sync

031-dotfile-layers: write a user's composed chezmoi source from the repository's layers into /var/lib/archon-dotfiles/<user>: owned by root, readable by the user's group, so chezmoi reads it and nothing writes to it but archon. Files no layer provides any more are removed.

Writes a user's composed chezmoi source (under root instead of /var/lib/archon-dotfiles when given), removing files no layer provides, then locks its ownership and modes down. With check, changes nothing and only reports what would change.
