build

stolos validate and stolos build (spec 002): validate the fleet and every host plan (TypeScript, Article 10), then render each host's files into out/hosts/<host>/rootfs/. Deterministic: building twice changes nothing.

Source: src/archon/build.ts

Modelinterface
interface Model

The fleet as loaded, resolved, and validated.

MemberTypeWhat it is
fleetFleetDefThe fleet (fleets/<id>/fleet.ts).
hostsHostDef[]Every host.
plansHostPlan[]Each host's resolved plan (what it should have).
problemsProblem[]Every problem found; empty when the model is valid.
knownSpecsfunction
function knownSpecs(): Promise<Set<string>>

Every spec ID the model may name: the engine's and the fleet repository's own.

loadModelfunction
function loadModel(): Promise<Model>

Load, resolve, and validate everything. Never throws for model problems.

dotfileProblemsfunction
function dotfileProblems(fleet: FleetDef, hosts: HostDef[], repo?: string): Promise<Problem[]>

Spec 031: every dotfile layer names a host and a user in the model, and every user's composition on every host is clean (no forbidden files, no two sources for one target within a layer).

reportfunction
function report(phase: Phase, m: Model): boolean

Report problems through the calm UI; true when the model is valid.

planForfunction
function planFor(host: HostDef): Promise<HostPlan>

One host's resolved plan.

renderHostsfunction
function renderHosts(m: Model): Promise<number>

Render every host's files under out/hosts/<host>/rootfs/. Returns files written.

renderRepoFilesfunction
function renderRepoFiles(m?: Model | undefined): Promise<number>

Files generated from the registry and the model (spec 012): man pages under out/<fleet>/man, and .mcp.json (spec 030), one MCP server per server host.

renderSitefunction
function renderSite(m: Model): Promise<number>

Spec 028: the network reference, from the site model, under out/site/.

stolos build: validate the model, then render every target into out/; true when it is valid.
