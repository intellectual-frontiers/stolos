records

Spec 077: what a fleet keeps about its people, beside the estate graph, and how Stolos reads it. Every file is in fleets/<fleet>/ and is read as a TypeScript literal (never run), so a past version from Git reads the same way:

  • people/roles.ts: which connected systems each role needs (roles);
  • people/keys.ts: each person's own SSH public key, by work email (keys);
  • people/training.ts and people/screening.ts: the records (training, screening), with no more than a control needs;
  • policies/<policy>.md: each policy, with its front matter;
  • policies/acks/<policy>.ts: who acknowledged which version (acks);
  • people/reviews/<quarter>/<manager>.md: the access reviews.

Connectors may supply training and screening records too (none does yet): a record labeled PERSON_RECORD is a node of the estate graph, and the controls read it beside the files.

Source: src/archon/people/records.ts

A policy: its id (file name) and front matter.

MemberTypeWhat it is

One acknowledgement of a policy version, as listed in policies/acks/<policy>.ts.

RoleMaptype
type RoleMap = Record<string, string[]>;

Which connectors each role needs: the key is a role_type from the HR system (employee, contractor, ...), or "*" for everyone; the value lists connector ids (google, github, onepassword, ...).

ScreeningRecordtype
type ScreeningRecord = {
  /** The person's work email. */
  email: string;
  /** The check (for example "background", "right to work"). */
  check: string;
  /** When it was completed (YYYY-MM-DD). */
  date: string;
  /** clear, or not clear (a decision the record does not explain). */
  result: "clear" | "not clear";
};

One screening record: who, which check, when, and its outcome (never the check's details).

TrainingRecordtype
type TrainingRecord = {
  /** The person's work email. */
  email: string;
  /** The course (for example "security awareness"). */
  course: string;
  /** When it was completed (YYYY-MM-DD). */
  date: string;
  /** passed or failed. */
  result: "passed" | "failed";
};

One training record: who, which course, when, and how it went.

PeopleKeystype
type PeopleKeys = Record<string, string>;

Each person's own SSH public key (ssh-ed25519 AAAA...), by work email.

PERSON_RECORDconst
const PERSON_RECORD: LabelView

A connector's training and screening records (none supplies them yet: the hook a learning system's or a screening provider's connector fills). Each record is a node of the estate graph with this label; kind says which.
