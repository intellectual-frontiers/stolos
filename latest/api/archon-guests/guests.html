guests

archon guest sync|list (spec 017): create missing LXD instances from the model and start stopped ones, mailing the ones created (spec 025). Never deletes (Article 11).

MemberTypeWhat it is
namestringThe instance name.
statusstringLXD's status, such as "Running" or "Stopped".

instancesfunction
function instances(): Promise<Instance[]>

The LXD instances on this host (lxc list); throws when lxc fails.

launchArgsfunction
function launchArgs(g: GuestDef): string[]

The lxc launch command line for a guest, with its kind and CPU and memory limits.

guestSyncfunction
function guestSync(host: HostDef): Promise<boolean>

Launches the host's missing guests and starts stopped ones; never deletes. Returns false when any launch or start failed.
