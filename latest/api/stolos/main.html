main

stolos (spec 059): the fleet's command, on your PC, in the fleet repository (bun run stolos ...). Everything about the fleet as a whole: creating it, keys and signers, adding and installing machines (stolos boot ..., the boot server), backups, and keeping this checkout up to date. Each machine has its own command, archon, for itself.

Source: src/stolos/main.ts

stolosMainfunction
function stolosMain(argv: readonly string[]): Promise<number>

The stolos CLI: boot ... is the boot server (its telemetry is IFC TypeScript's, started in this process: spec 096); everything else is a fleet command.

Run as a program and exit: from this file, or from a fleet repository's stolos.ts.
