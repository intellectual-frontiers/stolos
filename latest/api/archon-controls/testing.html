testing

Spec 078: testing a control like code. testControl runs one control over a fixture (rows, an estate made from a few records, or an observation) and returns its results, exactly as Stolos would show them, so a fleet's *.test.ts asserts on them with bun test. Nothing is asked of a machine or an account.

A control tested over rows

Source: src/archon/controls/testing.ts

fixtureEstatefunction
function fixtureEstate(s?: Partial<Snapshot>, now?: Date | undefined): Estate

An estate graph built from a few records (sources, machines, links); the rest is empty.

testControlfunction
function testControl: { <Q extends EstateQuery>(c: EstateControl<Q>, f: EstateFixture<Q>): (PolicyResult & { subjects: string[]; })[]; (c: OsqueryControl, f: OsqueryFixture): (PolicyResult & { machine: string; })[]; <K extends ObservationKind>(c: ObservationControl<K>, f: ObservationFixture<K>): PolicyResult[]; }

Run an estate control over a fixture. Run an osquery control over a fixture: one result per machine. Run an observation control over a fixture. Run a control over a fixture, with accepted risks applied: what Stolos would show (an empty list when the control does not apply).

EstateFixtureinterface
interface EstateFixture<Q extends EstateQuery> extends FixtureCommon

A fixture for an estate control: an estate, or the rows its query answers.

MemberTypeWhat it is
estate?Estate | Partial<Snapshot>An estate graph, or the records to build one from (fixtureEstate).
rows?EstateRows<Q>The rows the query answers, instead of an estate.
accepted?readonly Acceptance[]Accepted risks (by the control's id).
now?DateNow (default: the current time).
OsqueryFixtureinterface
interface OsqueryFixture extends FixtureCommon

A fixture for an osquery control: rows per machine (or one machine's rows).

MemberTypeWhat it is
machines?Record<string, string | Row[]>Each machine's rows; a string is a machine that did not answer, and why.
rows?Row[]One machine's rows (it is called "fixture").
accepted?readonly Acceptance[]Accepted risks (by the control's id).
now?DateNow (default: the current time).

interface ObservationFixture<K extends ObservationKind> extends FixtureCommon
