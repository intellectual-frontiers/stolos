assets

Specs 065 and 066: what both consoles serve besides their pages: one stylesheet (color tokens, light and dark), the Archon and Stolos logos, and Datastar (vendored, pinned by its SHA-256, served from the machine itself: no CDN, no build step), and AG Grid Community for the tables (spec 107).

Source: src/archon/console/assets.ts

TAG_CSSconst
const TAG_CSS: string

Spec 108-tags FR-014: the tag chips. A defined tag is drawn in its colour; a free-form one is always drawn apart (a dashed outline, italics, and the word "custom" in the chip); one written but not defined says so, in the warning colour. Spec 112-machine-reported-tags FR-015: a tag a machine reported is outlined in its colour, not filled (dotted while it is only a hint), with a badge "reported"; one announced is outlined dotted in grey.

A large vendored file, from beside this engine (the checkout, or the release on GitHub this engine was imported from), checked against its SHA-256 and kept in cacheDir (fetched once per version). Undefined when it cannot be had or does not match: the page then works without it.
