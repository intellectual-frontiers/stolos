table

Spec 107-pairing-and-query FR-012, FR-013: the console's one table, a thin wrapper around AG Grid Community (MIT), written so that commons can take it later: nothing here knows what a machine is. AG Grid is vendored, pinned by its SHA-256 and served by the console itself (assets.ts, AG_GRID): the page never loads a script from another site. The grid gives paging, sorting, column filters, a quick filter, resizing, pinning (the column menu), keyboard access, and CSV export.

The table is fed by the page's own server-sent events: the server patches <i hidden class="tbl-item" payload="..."> markers into the table's .tbl-feed element (Datastar's datastar-patch-elements), and the page's script turns each into a change of the grid. A change is { op: "reset" } (clear the rows and the columns), or { op: "add", rows, remove } (rows to add, each with a unique __id, and the __ids of rows to drop). The columns follow the rows: first columns come first (the first pinned left), then the others in the order they appear, then last ones.

Source: src/archon/console/table.ts

TableOptionsinterface
interface TableOptions

What a table is told when it is made.

MemberTypeWhat it is
idstringThe table's id (a lowercase word): the page's elements are <id>-feed and the like.
labelstringWhat the grid is called to a screen reader.
csvNamestringThe CSV's file name, without .csv.
pageSize?numberRows to a page (25 by default).
first?readonly string[]Columns that come first, in order; the first is pinned to the left.
last?readonly string[]Columns that come last, in order.
empty?stringWhat the grid says before any row (default: "No rows yet").

type TableChange =
  | { op: "reset" }
  | {
      op: "add";
      rows: ReadonlyArray<Record<string, unknown> & { __id: string }>;
      remove: readonly string[];
    };

One change to a table's rows.
