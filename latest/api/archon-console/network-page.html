network-page

Spec 110-network-assets FR-002, FR-008, FR-009: the Network page of the Stolos Console, shown only where a router-kind integration is connected: the topology (SVG drawn on the server from the uplink edges), the console's one table (AG Grid, table.ts) of devices, clients, VLANs and Wi-Fi networks, one device's page with its facts and an Open in UniFi link, and the class and way-of-joining badges the machines table uses. The page holds no logic: it draws NetworkView (connect/network-view.ts).

Source: src/archon/console/network-page.ts

postureCardfunction
function postureCard(f: Pick<PcFacts, "networkPosture">, o?: { full?: boolean | undefined; }): Html

Spec 111-network-posture FR-015: the Network posture card. Compact (the Overview): the counts and each failing policy with its first items and its fix. Full (the Network page): every policy with its status, SCF controls, items, fix and explain code, what does not apply, and the gaps with their reasons. It draws the pack's results (f.networkPosture) and holds no logic.
