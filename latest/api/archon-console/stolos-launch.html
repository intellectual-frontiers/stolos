stolos-launch

Spec 066: stolos console: the Stolos Console on this PC. It checks that your GitHub account (gh) may push to the fleet repository, listens on 127.0.0.1, prints a one-time launch link (and opens it), and runs until Ctrl+C. Commands run in the fleet repository with this terminal as their input, so passphrases and tokens are typed here, never in the browser.

Source: src/archon/console/stolos-launch.ts
