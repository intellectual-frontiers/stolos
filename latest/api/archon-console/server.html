server

Spec 065: the Archon Console's web server, as one request handler built from its dependencies (PAM, accounts, the runner, the data), so tests drive it with fakes and a server with the real ones.

  • /signin (form, PAM) and /signout; everything else needs a session (a cookie). Wrong passwords are throttled by address and by account.
  • POSTs come from this site only: the Origin must match the Host, and a run must carry Datastar's own header (another site's form cannot set it).
  • /actions/run streams the command's output as server-sent events (Datastar patches the page as lines arrive).

Source: src/archon/console/server.ts

clientAddressfunction
function clientAddress(req: Request, info?: ServeInfo | undefined): string

The address a request came from. The console listens on 127.0.0.1 behind Traefik, which replaces any X-Forwarded-For a client sends with its own (it trusts no forwarded headers): so the header counts only on a loopback connection, and its last entry is the one Traefik added.
