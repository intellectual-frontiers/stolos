function hostAdopt(o: { name: string; ssh?: string | undefined; checkIn?: string | undefined; title?: string | undefined; owner?: string | undefined; until?: string | undefined; }): Promise<number>

stolos host adopt <name> --ssh user@address: pin, install the probe, observe.

reportfunction
function report(name: string, rs: PolicyResult[]): void

Print one subject's policy results.

hostObservefunction
function hostObserve(name?: string | undefined): Promise<number>

stolos host observe [name]: observe one adopted machine, or all.

hostCheckfunction
function hostCheck(name?: string | undefined, json?: boolean): Promise<number>

stolos host check [name]: the policies, per adopted machine.

hostReleasefunction
function hostRelease(name: string): Promise<number>

stolos host release <name>: remove the probe and its key's line, then the model and the key.

queryAdoptedfunction
function queryAdopted(sql: string, adopted: readonly { machine: AdoptedDef; }[]): Promise<QueryAnswer[]>

One osquery SELECT on each adopted machine, through its probe (the caller checks the SQL first, with queryRefusal). Spec 078's osquery controls ask through this too.

fleetQueryfunction
function fleetQuery(sql: string, json?: boolean): Promise<number>

stolos fleet query "<sql>": one osquery SELECT on every machine; one table.

discoverfunction
function discover(json?: boolean): Promise<number>

stolos discover: machines seen on this PC's network or in the clouds, not yet in the fleet.

hostAcceptfunction
function hostAccept(name: string, policy: string, reason: string, until: string): Promise<number>

stolos host accept <name> <policy> --reason ... --until YYYY-MM-DD: record an accepted risk in machine.ts.

adoptCheckInfunction
function adoptCheckIn(ci: CheckIn, o: { name: string; ssh?: string | undefined; title?: string | undefined; owner?: string | undefined; until?: string | undefined; spec?: string | undefined; }, c?: Phase): Promise<number>

Adopt a machine from its check-in (a stolos1: code, or a paired machine's signed check-in): its host keys are pinned from the check-in, then it is observed over SSH with its probe key.

hostIntegratefunction
function hostIntegrate(o: { name: string; as: string; github?: string | undefined; repo?: string | undefined; }): Promise<number>

stolos host integrate <name> --as discover|adopt|osquery|server|workstation: the line to run on the machine.

discoverImportfunction
function discoverImport(code: string, name?: string | undefined, owner?: string | undefined): Promise<number>

stolos discover --import <code>: record a machine that checked in, to adopt or manage later.
