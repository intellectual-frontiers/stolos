query

Spec 107-pairing-and-query: ask every machine one question, all at once. fleet query and the Stolos Console's "Ask every machine" page share this: every machine (the managed servers, over their MCP servers, and the adopted machines, through their probes, the controller PC's among them) is asked at the same time, at most QUERY_CAP at a time, each with a time limit of its own (QUERY_TIMEOUT_S seconds unless --timeout says another). Each answer is handed on the moment it arrives, so a page can draw one merged table that fills in; a machine that fails or does not answer in time still gets an answer, with its reason, so no machine is missing from the table, and the count says "N of M answered".

Source: src/archon/adopt/query.ts

QUERY_CAPconst
const QUERY_CAP: 8

How many machines are asked at the same time.

QUERY_TIMEOUT_Sconst
const QUERY_TIMEOUT_S: 15

How long each machine has to answer, in seconds, unless --timeout says another.

QueryAnswerinterface
interface QueryAnswer

One machine's answer to a question to every machine.

MemberTypeWhat it is
machinestringThe machine.
kind"adopted" | "managed"managed or adopted (the controller is an adopted machine).
stateAnswerStateWhere it is (stolos:AnswerState): answered, failed, or timed out (asking, before its answer comes).
rows?Record<string, unknown>[]Its rows, when it answered.
error?stringWhy it did not answer (failed, timed out).
ms?numberHow long it took, in milliseconds.
AskTargetinterface
interface AskTarget

A machine to ask, and how: ask gives its rows, throws with its reason, and should stop when signal aborts.

MemberTypeWhat it is
machinestringThe machine.
kind"adopted" | "managed"managed or adopted.
ask(signal: AbortSignal, limitMs: number) => Promise<Record<string, unknown>[]>Ask it: its rows, or a thrown error whose message is the reason. limitMs is the time it has.
AskOptionsinterface
interface AskOptions

How a question to every machine goes.

MemberTypeWhat it is
cap?numberHow many are asked at the same time (8 by default).
timeoutMs?numberThe time limit of each machine, in milliseconds (15 s by default).
onStart?((machines: readonly Pick<AskTarget, "kind" | "machine">[]) => void)Called with all the machines before any is asked.
onAnswer?((a: QueryAnswer) => void)Called with each answer as it arrives (any order).
askAllfunction
function askAll(targets: readonly AskTarget[], o?: AskOptions): Promise<QueryAnswer[]>

Ask every target at once (at most cap at a time), each within its own limit, handing each answer on as it arrives. Resolves with every answer, by machine name, once the last has come: one answer per target, whatever happened to it.

answeredLinefunction
function answeredLine(answers: readonly QueryAnswer[], total?: number): string

"N of M answered": the count a table's line says (a machine that failed or timed out has not answered).

tableRowsfunction
function tableRows(answers: readonly QueryAnswer[]): Record<string, unknown>[]

The rows of a table for answers: a row for each result row, and one for each machine without rows (its state and reason).
