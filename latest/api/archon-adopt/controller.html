controller

Spec 097: the controller PC as a fleet machine. The PC that runs stolos holds every secret, the signing keys and the backups, so an auditor asks about it first. It is recorded as an adopted machine with the role controller (fleets/<fleet>/adopted/<name>/machine.ts, the name from its hostname), and observed locally: the same probe scripts adopted machines run (bin/stolos-probe.sh, bin/stolos-probe.ps1), started by Stolos itself. No SSH server, no probe key, no listening port: adopting the controller adds no way in.

On top of the probe's facts, the controller's own (observed.controller): whether the daily signing key is locked by a passphrase and kept out of an ssh-agent, whether the latest vault backup holds every secret as it is now, and whether the recovery key is in the vault and was checked recently. The policy pack (policy.ts) reads them, with the usual ones (the disk is encrypted, the firewall is on, ...), and adds one: no SSH server listening on the controller.

A fleet may have several controllers (each signer's PC); each observes only itself.

Source: src/archon/adopt/controller.ts

interface ControllerFacts

What only a controller's observation holds.

MemberTypeWhat it is
signingKey"locked" | "missing" | "unlocked"The daily signing key: locked by a passphrase, unlocked (none), or missing.
inAgent?booleanThe daily key is held by an ssh-agent (unlocked for anyone on this PC's session).
backup"behind" | "current" | "never"The secrets against the latest recorded backup: current, behind (something unbacked), or never.
backupAt?stringWhen the latest backup was recorded (ISO).
unbackednumberHow many secrets the latest backup does not hold as they are now.
recoveryInVaultbooleanA listed recovery key's private file is in the vault, so every backup holds it.
recoveryCheckedAt?stringWhen the recovery key was last proven to work on this PC (ISO).
remoteAccess?{ certificate?: string | undefined; devices: number; unused: number; }Spec 100: remote access to the Stolos Console, when the fleet sets it up: the certificate's expiry and the devices with no sign-in for 90 days.

recordControllerfunction
function recordController(): Promise<void>

Record this PC as the controller (when it is not yet) and observe it now, quietly: run by fleet init, keys setup and pair (spec 097). It never fails the command that runs it; it says what it did, and what to keep, in the next steps.
