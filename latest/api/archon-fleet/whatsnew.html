whatsnew

What's new after an engine upgrade (spec 105-calm-output FR-016): up to five bullets from the engine repository's commit subjects between the old and the new tag, from GitHub's public compare API (unauthenticated; ARCHON_GITHUB_API names a mirror), and every commit-body line that begins Operator action: as something for the person to do. A lookup that fails says nothing.

Source: src/archon/fleet/whatsnew.ts
