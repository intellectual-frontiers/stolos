config

032-web: the server's HTTPS front door, as data. Traefik (an official release binary, spec 010) listens on 80 and 443; 80 only redirects. No route is limited by network: who reaches the server is the router's decision (the firewall at the edge, outside the machine; Article 21 and spec 064). Certificates come from Let's Encrypt through Cloudflare's DNS challenge when fleet.web is set; until then (and without it) Traefik's self-signed certificate answers.

Everything here is pure: the capability renders it, tests read it.

Source: src/archon/web/config.ts
