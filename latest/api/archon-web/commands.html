commands

032-web on a server: archon web credential | dns | status.

Source: src/archon/web/commands.ts

serverAddressfunction
function serverAddress(_host?: HostDef | undefined): Promise<string | undefined>

The address this server's records point at: the one it reaches the network from now (the source of its default route), never a reserved or modeled one, so a new DHCP lease is followed (spec 032). Its other IPv4 addresses (container bridges, LXD) are only a fallback without a default route.

DNS_STATEconst
const DNS_STATE: "/var/lib/archon/web-dns.json"

What archon web dns last published: the address, and when (root only).

dnsDuefunction
function dnsDue(address: string, last: { address?: string | undefined; at?: string | undefined; } | undefined, now?: Date): "changed" | "daily" | undefined

Whether Cloudflare must hear from this server: a new address, or a day since the last check.

webDnsCheckfunction
function webDnsCheck(hostName: string): Promise<number>

archon web dns-check (the timer, every 5 minutes and at boot): quiet unless the address changed (or a day passed), then archon web dns. No run log for the checks that change nothing.

installWebCredentialfunction
function installWebCredential(json: string): Promise<void>

Store the Cloudflare token (root only) for archon web dns and for Traefik.

webCredentialfunction
function webCredential(hostName: string): Promise<number>

archon web credential: the token from stdin (bun run stolos boot web-push), then the records.

webDnsfunction
function webDns(hostName: string): Promise<number>

archon web dns: this server's name and wildcard in Cloudflare, to its address.

certificateOffunction
function certificateOf(name: string): Promise<{ issuer: string; notAfter: string; } | undefined>

The certificate Traefik presents for a name: issuer and expiry (openssl).

webStatusfunction
function webStatus(hostName: string): Promise<number>

archon web status: the proxy, the certificate, DNS, and every route.
