observe

archon observe (spec 021): what this machine records about itself, where, and within which limits; observe tui opens otel-tui on it; observe prune keeps PCP's metric archives within their size and free-space limits (journald and the Collector's files limit themselves).

Source: src/archon/observe/observe.ts

parseSizefunction
function parseSize(s: string): number

"2G" -> bytes (K, M, G, T are powers of 1024, as journald reads them).

fmtBytesfunction
function fmtBytes(n: number): string

A byte count for people: "512 B", "3.4 MB", "12 GB" (powers of 1024).

Archiveinterface
interface Archive

One PCP archive: its files share a base name such as 20261111.00.10 or 20261110.

MemberTypeWhat it is
dirstringThe folder that holds it.
basestringThe shared base name, for example 20261111.00.10.
filesstring[]Its files' names (index, meta, and numbered volumes, possibly compressed).
bytesnumberTheir total size, in bytes.
pcpArchivesfunction
function pcpArchives(root?: string): Promise<Archive[]>

Every PCP archive under root, grouped by base name.

freePercentfunction
function freePercent(path: string): Promise<number | undefined>

Free space of the filesystem holding a path, in percent.

pruneChoicefunction
function pruneChoice(archives: Archive[], limitBytes: number, freePct: number | undefined, minFreePct: number, diskBytes: number): Archive[]

Which archives to delete: oldest first while the total is over the limit or the disk is below its free-space floor. The newest archive (being written) is never deleted.

prunefunction
function prune(host: HostDef, check?: boolean): Promise<number>

archon observe prune: delete the oldest metric archives while over the size limit or the disk's free-space floor (check: only report).

observefunction

archon observe: what this host records about itself (metrics, logs, traces), where, and how much.

observeTuifunction
function observeTui(): Promise<number>

otel-tui on this machine's telemetry: PCP's core metrics live, Archon's recent OTLP.
