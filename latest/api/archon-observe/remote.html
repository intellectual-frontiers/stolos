remote

Spec 048-observe-by-query: ask a server through its MCP server, over SSH as ops (spec 030, Article 17), the same way an agent does. The server limits what it answers; nothing it says is pushed anywhere.

Source: src/archon/observe/remote.ts

RemoteResultinterface
interface RemoteResult

A server's answer to one MCP tool call.

MemberTypeWhat it is
okbooleanTrue when the tool ran and did not report an error.
textstringThe tool's text output, or why the call failed (ssh's error, "no answer").
sshArgsfunction
function sshArgs(target: string, timeoutS?: number, knownHosts?: string | undefined): string[]

ssh arguments for a server's MCP endpoint. With knownHosts (known_hosts.auto, generated from the hosts' registrations in Git, spec 047), the server's key is checked against Git first, then the user's own known_hosts.

Call one tool of a server's MCP server (newline-delimited JSON-RPC over ssh's stdio).
