events

Spec 049-telemetry (Article 27): events are structured at their source. Each event has a declared name (below), a severity, the host and address it is about, attributes, and a message; it is recorded as an OpenTelemetry log record. Anything a person reads (the boot server's window, boot.log) is a rendering of these records, never the source: the window's icons, colors, and de-duplication come from the event's name and attributes, not from parsing its text.

Source: src/archon/telemetry/events.ts

OtlpAnyValuetype
type OtlpAnyValue =
  | { stringValue: string }
  | { intValue: string }
  | { boolValue: boolean }
  | { doubleValue: number }
  | { arrayValue: { values: OtlpAnyValue[] } }
  | { kvlistValue: { values: OtlpKeyValue[] } }
  | Record<never, never>;

An OTLP AnyValue in the OTLP/HTTP JSON encoding: a 64-bit integer is a decimal string, a map is a list of key-values, and an empty object is a null (spec 092 adds arrays and maps, for structured log bodies).
