where

Spec 053: "where am I". bun run stolos with no arguments shows, for the fleet of this repository, every step from a new repository to running hosts, each done or not as the real state says (Git, this machine's secret store, the boot server's tokens, what hosts reported), and the one command to run next. Nothing is stored about progress: it is computed every time.

Source: src/archon/guide/where.ts

WhereFactsinterface
interface WhereFacts

What stolos (no arguments) found about where you are: the facts its next step is chosen from.

MemberTypeWhat it is
fleetsstring[]The fleets of this repository.
fleetId?stringThe active fleet, when one is chosen and exists.
pinned?stringpackage.json's engine tag, when pinned.
lockedbooleanbun.lock exists.
signers{ daily: number; recovery: number; }How many signers of each role signers.ts lists.
signingProblems{ what: string; fix?: string | undefined; }[]This machine's signing problems (spec 057's checks, failures first): what is wrong, with its fix.
adminHashbooleanThe admin password's hash is in this machine's secret store.

web?{ token: boolean; }The fleet has HTTPS names: is the Cloudflare token on this machine?
hosts{ name: string; workstation: boolean; installed: boolean; armed: boolean; claim: boolean; }[]Each host: a workstation or a server, installed, armed, armed by claim.
dirtybooleanUncommitted changes in the fleet repository, and commits not pushed.
unpushednumberCommits not pushed.
