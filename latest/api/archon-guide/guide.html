guide

035-welcome-guide: what is on this server and how to use it, in plain words, computed from the server's own plan (Article 4: one source). The welcome page, archon guide, and the login banner's pointer all read this; an item appears only when the plan really has what it describes.

Source: src/archon/guide/guide.ts

type Category = "shell" | "web" | "watch" | "safety" | "email" | "work";

A guide section.

CATEGORIESconst
const CATEGORIES: Record<Category, { emoji: string; title: string; intro: string; }>

Each section's emoji, title, and introduction.

GuideIteminterface
interface GuideItem

One item of the guide: what is on this machine and how to use it.

MemberTypeWhat it is
idstringIts id.
categoryCategoryIts section.
titlestringIts title.
whatstringOne or two plain sentences: what it is and why you'd care.
use?{ cmd: string; why: string; }[]Commands to try, each with what it does.
links?{ label: string; href: string; }[]Live places to open (Cockpit pages, dashboards, the repository).
guide?stringA longer guide in the Archon Console (/guide/<name>) and in the repository.
guideForfunction
function guideFor(plan: HostPlan): GuideItem[]

The guide's items for a host's plan.

AgentSetupinterface
interface AgentSetup

How to reach this server from an AI agent (MCP over SSH), and the Git loop.

MemberTypeWhat it is
serverstringThe MCP server's name, as the repository's .mcp.json calls it.
targetstringssh's target: ops@<this server>.
argsstring[]ssh's arguments for any MCP client (stdio).
tierstringThe tier the server serves (it refuses the rest; destructive never).
cloneUrlstringThe URL to clone the fleet repository.
repoUrlstringThe fleet repository's page.
slugstringowner/name.
