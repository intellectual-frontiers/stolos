commands

Spec 092: stolos export <kind> [--out <file>] gathers what the kind needs from this PC (the estate graph from the fleet repository, the compliance view, an evidence bundle) and writes one document, by default to this PC's state directory, export/. Without a kind (or with rdf) it is the RDF export it always was (specs 002 and 014).

Source: src/archon/export/commands.ts
