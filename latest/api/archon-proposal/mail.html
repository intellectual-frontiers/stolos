mail

Spec 095-proposals: reading a saved message (.eml, RFC 5322 with MIME) for its attachments, so stolos proposal import takes the mail as it was saved, with no mailbox access and no credential (the owner's decision 2). Multipart parts nest; attachments are base64, quoted-printable, or plain; a gzipped attachment (proposal.json.gz, what notify sends when it is large) is unpacked.

Source: src/archon/proposal/mail.ts
