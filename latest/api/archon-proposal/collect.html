collect

Spec 095-proposals: the collectors. Each reads one of Ubuntu's own records (journald's sudo entries, apt's history.log and dpkg.log, etckeeper's git log, osquery, systemctl list-unit-files, snapd, podman, dpkg -S on /usr/local and /opt, debsums -c or dpkg --verify) and writes observations (what, who, when, source) into the host's own archon.sql, with the latest state and, once, the birth snapshot. Nothing here changes the host. A modified package binary is a security alert, mailed at once and never proposed.

Source: src/archon/proposal/collect.ts

stateFromfunction
function stateFrom(raw: RawSources, plan: PlanView): HostState

The host's state from its raw sources, against the plan and the birth snapshot: /etc files a person changed since birth (a package's own unchanged file is not drift; a modified one is), units, packages, ports, accounts.

readSourcesfunction
function readSources(plan: HostPlan, view: PlanView, birth: Birth, since: string): Promise<RawSources>

Read every source from this host (root: journald, /etc's history, and root-only files).

birthFromfunction
function birthFrom(raw: Pick<RawSources, "at" | "listening" | "manual" | "passwd" | "snapList" | "unitFiles">, etcCommit: string, late?: Observation[] | undefined): Promise<Birth>

The birth snapshot from this host now. At install it is what Ubuntu (and the first apply) put there. Taken later (late), packages a person installed with apt and units a person enabled under sudo, as the logs show, are left out of it, so they still count as drift.

recordBirthfunction
function recordBirth(hostName: string, dir?: string): Promise<Birth>

Take the birth snapshot at install (first boot), once: what Ubuntu put on the host. Never replaced.

collectfunction
function collect(host: HostDef, dir?: string): Promise<Collected>

Collect on this host (as root): read every source, store what it saw, take the birth snapshot if it is missing (late, on a host installed before spec 095), and mail a SECURITY ALERT for a newly modified package file.
