pc

Spec 095-proposals: stolos proposal ... on your PC, in the fleet repository. import reads a saved message (.eml) or the attachments, checks that the host is in the fleet and that the signature is its own host key from registration.ts, and keeps the proposal in your state folder (outside Git). list and show say what each would change; accept edits the host's TypeScript, writes a draft spec, records the decision in Git, and builds; reject records the rejection. You review and run stolos apply, and the server converges.

Source: src/archon/proposal/pc.ts
