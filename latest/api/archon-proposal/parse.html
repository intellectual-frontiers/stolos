parse

Spec 095-proposals: the collectors' parsers. Each reads one source's own output, exactly as the tool writes it (journald's JSON, apt's history.log, dpkg.log, etckeeper's git log, osquery's JSON, systemctl list-unit-files, snap changes, dpkg -S, debsums -c or dpkg --verify), and returns observations: what changed, who changed it, when, and where it was seen. Pure functions, so each is tested on fixtures (tests/proposals095_test.ts).

Source: src/archon/proposal/parse.ts

function obsId(...parts: string[]): Promise<string>

A short stable id for an observation: the same evidence collected twice is one record.

A local "YYYY-MM-DD HH:MM:SS" (apt, dpkg) as ISO time, read in this machine's time zone.

An Archon run under sudo (archon's own commands are not hand changes).

SudoEntryinterface
interface SudoEntry

One sudo command from journald.

MemberTypeWhat it is
whostringWho ran it.
atstringWhen (ISO).
commandstringThe command, as sudo logged it.
asstringAs whom it ran (USER=).
pwdstringIts working directory (PWD=).
parseSudoJournalfunction
function parseSudoJournal(text: string): SudoEntry[]

sudo's journal entries (journalctl -o json SYSLOG_IDENTIFIER=sudo): one JSON object per line, MESSAGE alice : TTY=pts/0 ; PWD=/home/alice ; USER=root ; COMMAND=/usr/bin/apt install nginx. Refused attempts and PAM's session lines are not commands that ran; archon's own runs are left out.

commandTargetsfunction
function commandTargets(command: string): { kind: SubjectKind; name: string; }[]

What a sudo command touches that a drift item can be matched with: packages, units, paths.

sudoObservationsfunction
function sudoObservations(entries: SudoEntry[]): Promise<Observation[]>

sudo entries as observations (command subjects: who, when, and exactly what was typed).

parseAptHistoryfunction
function parseAptHistory(text: string): Promise<Observation[]>

apt's /var/log/apt/history.log: blocks of Start-Date, Commandline, Requested-By (the person behind sudo), Install, Remove, Purge, End-Date. Upgrades are Ubuntu's (unattended-upgrades) and never drift; packages apt pulled in by itself (automatic) are left out.

parseDpkgLogfunction
function parseDpkgLog(text: string, apt?: Observation[]): Promise<Observation[]>

/var/log/dpkg.log lines (2026-11-14 10:02:13 install nginx:amd64 <none> 1.26.0): installs and removals. Only those apt's history does not explain are kept (a dpkg -i of a downloaded .deb); aptAt is apt's install times.

etckeeper's history (git -C /etc log --format=%x1e%H%x1f%an%x1f%aI%x1f%s --name-status). Archon's own commits (archon apply: ...) are left out.

isUbuntuCommitfunction
function isUbuntuCommit(c: EtcCommit): boolean

Commits made for Ubuntu (unattended upgrades, apt run by root on its own), not by a person.

etckeeper commits as file observations (who is the commit's author unless it is root).
