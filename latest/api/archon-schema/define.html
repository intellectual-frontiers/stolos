define

Spec 089: the schema language. A table, a view, or a label is declared once, in typed TypeScript, and everything else is generated from it: the canonical SQL (tables, indexes, views), the upsert statement and its parameters, the row type, the OCSF view, and the documentation with its Mermaid diagram. Names follow the vocabularies in vocabulary.ts: singular lower_snake_case, never an SQL keyword, and each part a cited standard's term.

Source: src/archon/schema/define.ts

ColumnTypetype
type ColumnType = "text" | "integer" | "real" | "boolean" | "json";

A column's SQL type; booleans are stored as 0 and 1, JSON as text.

ValueOftype
type ValueOf<C extends Column> = C["type"] extends "integer" | "real"
  ? number
  : C["type"] extends "boolean"
    ? boolean
    : C["type"] extends "json"
      ? unknown
      : C["values"] extends readonly string[]
        ? C["values"][number]
        : string;

The TypeScript type of a column's value.

RequiredKeystype
type RequiredKeys<C extends Record<string, Column>> = {
  [K in keyof C]: C[K]["required"] extends true ? K : never;
}[keyof C];

The columns of a table that are required (NOT NULL).

RowOftype
type RowOf<C extends Record<string, Column>> = { [K in RequiredKeys<C>]: ValueOf<C[K]> } & {
  [K in Exclude<keyof C, RequiredKeys<C>>]?: ValueOf<C[K]> | null;
};

A row of a table: required columns required, the rest optional.
