commands

bun run stolos vault <sub> (specs 029 and 056): the boot machine's secrets, and their backup. A backup is one ZIP file (see writeBackupZip), written into stolos's backup folder; you then move it wherever you keep important things safe. vault restore <zip> (spec 061) puts it back on a freshly cloned PC; without a ZIP it prints the steps (constitution Article 22).

Source: src/archon/vault/commands.ts

vaultStatusfunction
function vaultStatus(o: { lost?: boolean | undefined; hook?: boolean | undefined; }): Promise<number>

vault status: every secret, when it changed, and whether the last backup holds it.

afterBackupfunction
function afterBackup(path: string, signingKey?: string | undefined, recovery?: boolean): string[]

What to tell the person once the ZIP is written: where it is, and where to put it.

vaultBackupfunction
function vaultBackup(): Promise<number>

vault backup: one ZIP with every secret and both signing keys, read back and recorded.

vaultRestorefunction
function vaultRestore(): Promise<number>

vault restore without a ZIP: the steps (the command, and by hand); it changes nothing.

vaultListfunction
function vaultList(): Promise<number>

vault list: the backup ZIPs still in the backup folder (moved ones are wherever you put them).

recoverHostKeysfunction
function recoverHostKeys(host: string): Promise<number>

Pull a running host's identities back over SSH (a boot machine lost without a backup): its SSH host keys and ops' deploy key, so the rebuilt boot machine holds the same ones (nothing changes on GitHub, and clients see the same host).
