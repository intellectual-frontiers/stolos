state

The vault's view of the boot machine's secrets (spec 029): what is there, what the inventory says each one is, and whether the last backup holds it as it is now. Names, sizes, and SHA-256 only; never a value.

Source: src/archon/vault/state.ts

LiveSecretinterface
interface LiveSecret

One secret file as it is now on the boot machine (no value: only its name, size and digest).

MemberTypeWhat it is
namestringPath inside the secrets folder, forward slashes.
pathstringIts full path on this machine.
ref?SecretRefIts inventory entry, when the inventory knows the path.
sha256stringSHA-256 of its contents, hex.
sizenumberIts size in bytes.
changedAtstringWhen it last changed (ISO 8601): the ledger's record, else the file's mtime.
liveSecretsfunction
function liveSecrets(dir?: string, ledger?: Ledger | undefined): Promise<LiveSecret[]>

Every file in the secrets folder, with its inventory entry.

BackupCheckinterface
interface BackupCheck

The recorded last backup (spec 056). A backup is a ZIP you move wherever you keep important things, so archon cannot look for it there: the record counts. "ok": a backup was made and read back; "none": nothing recorded. where says whether the ZIP is still in the backup folder (not yet moved somewhere safe).

MemberTypeWhat it is
state"none" | "ok""ok" (recorded), or "none".
where?"here" | "moved""here": still in the backup folder; "moved": moved out (where you keep it).
checkLastBackupfunction
function checkLastBackup(lb: LedgerBackup | undefined): Promise<BackupCheck>

The last backup's state (spec 056): recorded or not, and whether its ZIP is still here.

Assessmentinterface
interface Assessment

The vault's state: every secret, what the last backup lacks, and how urgent that is.

MemberTypeWhat it is
items(LiveSecret & { backedUp: boolean; })[]Every secret, with whether the last recorded backup holds it as it is now.
unbacked(LiveSecret & { backedUp: boolean; })[]Not ephemeral, and not in the last backup as it is now.
removedstring[]In the last backup but no longer here (removed since).
lastBackup?LedgerBackupThe last backup recorded.
backupCheckBackupCheckWhether a backup is recorded, and whether its ZIP is still in the backup folder.
severity"amber" | "ok" | "red"Red: something unbacked for more than 7 days, or host identity keys never backed up.
assessfunction
function assess(dir?: string, now?: number): Promise<Assessment>

Compare the secrets folder with the ledger's last backup record (spec 056: the record counts, wherever the ZIP is kept). Amber when anything is unbacked or removed; red when a change is more than 7 days old, or host identity keys have never been backed up.
