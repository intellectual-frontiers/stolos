console

Spec 082: the provider's console (stolos clients console): one Stolos Console for every client, on this PC only (127.0.0.1, a one-time launch link, as spec 066).

  • /clients: the cross-client summary, numbers only, and a switch per client.
  • Switching (a POST to /clients/switch) ends the session and starts a new one, scoped to that client: every other page (the client's own console, its REST API under /v1/) is that client's, served by a console of its own, with its own sessions and caches, built and run in its scope.
  • A session sees one client at a time. Its cookie names a provider session; the provider session maps to one session in one client's console, so reaching another client's pages takes another switch (a new cookie), and the old cookie stops working.
  • /v1/clients: the summary as JSON (numbers only), for any signed-in session.

Source: src/archon/clients/console.ts
