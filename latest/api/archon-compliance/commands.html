commands

Specs 068 and 071: stolos compliance [--framework <id>] [--json]: the fleet's evidence by SCF control and by framework, from what this PC already knows (nothing is asked of a server); stolos compliance catalog downloads the SCF Council's and NIST's catalogs (pinned, SHA-256 checked); stolos compliance export writes the fleet's OSCAL documents. Spec 073: each control shows its evidence's age, and stale evidence fails (MON-02); stolos compliance drift is in drift.ts.

Source: src/archon/compliance/commands.ts

complianceCommandfunction
function complianceCommand(fw?: string | undefined, json?: boolean, ocsf?: boolean, pick?: { tag?: unknown; "any-tag"?: unknown; select?: unknown; }): Promise<number>

Print the fleet's compliance view; exit 1 when a control fails. Spec 108-tags FR-016: with --tag, --any-tag or --select, only the machines those tags choose count (managed, adopted and devices); a cloud account's and the estate's evidence stays.

catalogCommandfunction
function catalogCommand(update?: boolean, o?: { cacheDir?: string | undefined; get?: ((url: string) => Promise<Uint8Array<ArrayBufferLike>>) | undefined; }): Promise<number>

Download, check, read, and cache the catalogs (again with update).

OscalResulttype
type OscalResult =
  | { ok: true; docs: OscalDocuments; fleet: { id: string; title: string }; scf: string }
  | { ok: false; error: string; fix: string };

The fleet's OSCAL documents by file name, or why they cannot be made (and the fix).

oscalDocumentsfunction
function oscalDocuments(now?: Date): Promise<OscalResult>

Build the fleet's four OSCAL documents from what this PC knows (spec 071). stolos compliance export writes them; spec 092's export jobs deliver them.

exportCommandfunction
function exportCommand(out?: string | undefined): Promise<number>

Write the fleet's OSCAL documents (component definition, SSP, assessment results, POA&M).
