drift

Spec 073: compliance drift. stolos compliance drift [--since <date|commit>] [--notify] compares each SCF control's status now with its status at a past commit of the fleet repository, and lists the controls whose status changed, with the evidence that changed under them. With --notify it mails a summary to the fleet's mailbox (fleet.mail.to) through the fleet's notify path: control ids, subjects, checks, and statuses only, never what a check found, so no secret can be in it.

Both sides are computed the same way, from what the repository holds (the observations Stolos commits: adopted machines, devices, connected accounts), each held to the cadences as of its own time (the past side as of its commit's time), so evidence that went stale is drift too. Managed servers' verifies live in this PC's state, not in Git, so they are not compared.

It is made to run on a schedule, by this PC's own scheduler (see the compliance guide, mod.ts).

Source: src/archon/compliance/drift.ts
