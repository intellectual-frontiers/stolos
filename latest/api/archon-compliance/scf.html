scf

Spec 071: the Secure Controls Framework (SCF) controls Stolos gives evidence for, and what it looks at for each. That is all Stolos writes itself: each control's official name, description, and its mappings to SOC 2, HIPAA, PCI DSS, CMMC, NIST SP 800-53 and 800-171, and FedRAMP are the SCF Council's own (its Set Theory Relationship Mapping, STRM), read from the pinned SCF release by catalog.ts. The names here are SCF's, kept for when the catalog is not on this PC yet; a test checks them against the workbook.

Source: src/archon/compliance/scf.ts
