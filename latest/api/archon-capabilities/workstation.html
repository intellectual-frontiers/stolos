workstation

020-workstation: Ubuntu on WSL (or a desktop) as an Archon workstation. Only the user-level parts of a host apply: the tools at their newest releases, the dotfiles (fish, oh-my-posh, tmux, git), .mcp.json for the operator's own MCP client (spec 030), the archon command, and Ubuntu's daily updates. Nothing that belongs to a server: no installer, netplan, firewall, SSH hardening, ops account, converge timers, or backups. The checkout is /srv/archon, owned by the workstation's user.

Source: src/archon/capabilities/workstation.ts

Spec 036: VS Code on a workstation with a graphical desktop, for a user with the developer persona: Microsoft's "code" package from its apt repository (key pinned, Article 12), kept current by apt and unattended-upgrades. WSL and headless machines get nothing: VS Code there runs on the computer in front of you (Remote - SSH, or the WSL extension on Windows).
