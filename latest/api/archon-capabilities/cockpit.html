cockpit

022-cockpit: Ubuntu's web console on every server, with PCP's metric history (cockpit-bridge reads the archives spec 021 keeps). Port 9090 is open to every network (the router decides who reaches the server); logins are the accounts' own passwords (PAM), root excluded by Cockpit. A fleet that allows no password logins (keys only, spec 007) keeps it closed. Installed without apt's recommended extras, so no NetworkManager or PackageKit next to netplan and apt.

Source: src/archon/capabilities/cockpit.ts
