progress

Install and first-boot progress in the boot server's window (spec 004). Ubuntu's installer reports every step to a webhook (autoinstall reporting); most are noise, so a few milestones are shown, plus anything that failed. The first boot reports each Archon phase itself.

Source: src/archon-boot/progress.ts

InstallerEventinterface
interface InstallerEvent

One report posted to the boot server: from Ubuntu's installer (reporting webhook) or from Archon's first boot.

MemberTypeWhat it is
name?stringThe installer's step name, for example "subiquity/Install/install/curthooks".
description?stringThe installer's description of the step.
event_type?string"start" or "finish".
result?stringFor a finish: "SUCCESS", "WARN", or "FAIL".
origin?string"archon" for first-boot events; absent for the installer's.
phase?stringFirst-boot events (origin "archon").
level?stringFirst-boot events: "ok", "warn", or "fail".
summary?stringFirst-boot events: the phase's one-line result.
ProgressEventtype
type ProgressEvent = Pick<ArchonEvent, "name" | "message" | "severity" | "attrs">;

What the window and the log record get from one progress report (spec 049).
