HTTPS on every server

server

archon-boot's HTTP server (spec 004): UEFI HTTP Boot files, GRUB menus per host (by Boot URI, or by MAC when the model has one), the verified installer image, and each host's install config with its secrets filled in at request time (Article 13).

Source: src/archon-boot/server.ts

ServeOptionsinterface
interface ServeOptions

Options for the boot server (bun run stolos boot serve).

MemberTypeWhat it is
portnumberThe HTTP port the boot server listens on (GRUB, the installer and the servers reach it).
proxy?stringProxy the installer and first boot should use (sites behind one; optional).
caPem?stringPEM of a CA that proxy needs trusted (optional).
githubApi?stringGitHub Enterprise or a releases mirror (optional).
hostname?stringThe address to listen on (every IPv4 address by default).
emit(e: ArchonEvent) => voidSpec 049: every event, structured; the window and boot.log render it.
stallWatch?booleanSpec 051, off by default (boot serve --stall-watch): name a machine whose installer took the image and went quiet. It guesses which machine from DHCP leases, which installers change mid-install; it is a hint, not a guarantee.
servefunction
function serve(o: ServeOptions, h: Handler): Promise<Listener>

Serve HTTP with the given handler: the same one TFTP uses, so they share what they saw.

handlerfunction
function handler(assets: Assets, o: ServeOptions): Handler

The request handler, shared by HTTP and TFTP (PXE).
