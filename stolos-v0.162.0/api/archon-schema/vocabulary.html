vocabulary

Spec 089: the vocabularies Stolos names its tables, views, and columns from. No name is Stolos's own: each table or view cites the standard each part of its name comes from, and a test checks the term is in that standard. OCSF's object and class names and MITRE D3FEND's artifact names are generated from their published schemas (bun run ocsf); the others are short lists, each with its source.

Source: src/archon/schema/vocabulary.ts
