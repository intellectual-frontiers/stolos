archon notify

The archon notify commands (spec 025), on hosts, workstations, and the boot machine (bun run stolos boot notify runs the same code), and archon mail credential and mail test (spec 027).

#Modules

commandsThe archon notify commands (spec 025), on hosts, workstations, and the boot machine (bun run stolos boot notify runs the same code), and archon mail credential and mail test (spec 027).
eventsWhich events send a message (spec 025): major actions only, never every routine run.
mimeMail messages for archon notify (spec 025): RFC 5322 with MIME, a plain-text part and a simple HTML part, and small attachments.
notifyarchon notify (spec 025): major events, by email, to the fleet's shared mailbox.
transportHow mail leaves (spec 025, spec 027): Cloudflare Email Service's authenticated SMTP submission, smtp.mx.cloudflare.net:465 with implicit TLS, user "api_token", the password a Cloudflare API token…
watcharchon notify watch (spec 025, user story 2): the events an operator must hear about even when nothing in Archon ran.
