doctor

Spec 100 FR-012: what boot doctor says about remote access: the LAN listener, the certificate's expiry, devices unused for 90 days, and the firewall rule the HTTPS port needs. Each step that is the operator's is ⚡ (an action, never a failure), with its command.

Source: src/archon/access/doctor.ts

AccessFactsinterface
interface AccessFacts

What the doctor reads (on this PC, no network).

MemberTypeWhat it is
configuredbooleanThe fleet names the console (web.domain and stolos.console).
listening?{ address: string; port: number; at: string; }The listener as the running console last recorded it.
notAfter?stringThe certificate's expiry (ISO).
unusednumberDevices with no sign-in for 90 days.
devicesnumberApproved devices.
blocked?{ port: number; code: string; holder?: string | undefined; }TCP 443 cannot be bound on this PC (the error's code), and what holds it where that could be found (spec 103-three-ports).
DoctorLineinterface
interface DoctorLine

One line of the doctor's "Remote access" phase.

MemberTypeWhat it is
level"action" | "hint" | "ok" | "pending"ok (a note), action (⚡), pending (⏳, waiting on time or someone else) or hint (👉, an optional feature that is merely off, spec 105-calm-output FR-008).
msgstringWhat it found.
fix?stringThe next step.
consoleFirewallCommandfunction
function consoleFirewallCommand(os: string, port: number): string

The exact command that allows the console's HTTPS port on Private and Domain networks only (never Public): Windows Defender Firewall, else ufw.

accessDoctorfunction
function accessDoctor(f: AccessFacts, now: number, firewall: readonly string[], os: string): DoctorLine[]

The doctor's lines for remote access. firewall is what the firewall check said for the port.
