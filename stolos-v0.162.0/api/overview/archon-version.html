archon/version

The engine's version (specs 046-engine-instance, 096-bun-runtime, 114-release-record). Every push to main raises it, and the release workflow tags that commit stolos-v<VERSION>, an annotated Git tag, which a fleet repository depends on by its URL. bun run version bump raises the minor number (0.150.0, 0.151.0, ...) here, in package.json and in the work's record release.ts; bun run version check fails when main already has this version or the three differ.

Source: src/archon/version.ts
