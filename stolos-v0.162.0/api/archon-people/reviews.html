reviews

Spec 077: quarterly access reviews, written from the estate graph. Each manager (the people others report to, party_relationship reports_to) gets one Markdown file per quarter, people/reviews/<quarter>/<manager>.md: each report's active accounts (has_account edges) with their admin rights, one line each, unticked. The manager ticks each line they confirm (and removes, in the system itself, any access they do not) and commits it signed: that commit is the approval.

Source: src/archon/people/reviews.ts

const REVIEW_SQL: "SELECT r.to_party_uid AS manager, p.uid, p.email_addr AS email, p.type, p.status,\n  a.connector AS system, a.display_name AS account, a.admin\nFROM party_relationship r\nJOIN user_inventory p ON p.uid = r.from_party_uid\nLEFT JOIN edge e ON e.src_uid = p.uid AND e.verb = 'has_account'\nLEFT JOIN user_account a ON a.user_account_uid = e.dst_uid AND a.active = 1\nWHERE r.party_relationship_type = 'reports_to' AND p.status IN ('active', 'leave')\nORDER BY r.to_party_uid, p.email_addr, a.connector, a.display_name"
