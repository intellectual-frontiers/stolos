HTTPS on every server

http

A small HTTP/1.1 server for archon-boot (spec 004), on raw TCP. A web server's Headers keep names in lowercase, which HTTP allows, but GRUB's HTTP client compares "Content-Length: " case-sensitively and then reads every file as empty. This transport writes canonical header names, keeps connections alive (GRUB sends HEAD then GET on one connection), and streams bodies.

Source: src/archon-boot/http.ts

Handlertype
type Handler = (req: Request, from: string) => Promise<Response>;

Answers one request; from is the client's address.

listenfunction
function listen(port: number, handler: Handler, hostname?: string): Promise<Listener>

Listen on port on hostname (every IPv4 address by default: the machines being installed reach this PC over the LAN) and serve each connection with handler in the background. Returns the listener so the caller can close it.
