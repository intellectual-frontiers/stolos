firewall

Firewall check for boot serve (spec 004): warn, with the exact command, when this machine's firewall would block servers from reaching TFTP (UDP) or HTTP (TCP). Read-only: it never changes a firewall rule. Windows Defender Firewall, ufw, and firewalld; anything else is not checked.

Source: src/archon-boot/firewall.ts

Needinterface
interface Need

A port the boot server needs reachable from the network.

MemberTypeWhat it is
protocol"TCP" | "UDP"TCP (HTTP) or UDP (TFTP).
portnumberThe port number.
whatstringWhat it is for, in words ("HTTP", "TFTP").
WinRuleinterface
interface WinRule

One Windows inbound rule, as the PowerShell probe reports it.

MemberTypeWhat it is
namestringThe rule's display name.
action"Allow" | "Block"Allow or Block.
profilestring"Any", or a comma list of Domain, Private, Public.
protocolstring"Any", TCP, UDP.
portsstring[]Local ports: "Any", or a list such as ["8080"] or ["1000-2000"].
programstringProgram path for an application rule, else "Any".
remote?string[]Remote addresses: "Any", "LocalSubnet", or addresses and ranges.
scoped?booleanLimited to a Windows user, service, app package, or interface: not the boot server's.
WinStateinterface
interface WinState

Windows Defender Firewall's state, as the PowerShell probe reports it.

MemberTypeWhat it is
enabledstring[]Firewall profiles that are on, e.g. ["Domain", "Private", "Public"].
activestring[]Categories of the connected networks, e.g. ["Public"].
rulesWinRule[]The enabled inbound rules.
