commands

Spec 067: stolos host adopt | observe | check | release and stolos fleet query, on the controller PC.

Source: src/archon/adopt/commands.ts

hostAdoptfunction
function hostAdopt(o: { name: string; ssh?: string | undefined; checkIn?: string | undefined; title?: string | undefined; owner?: string | undefined; until?: string | undefined; }): Promise<number>

stolos host adopt <name> --ssh user@address: pin, install the probe, observe.

reportfunction
function report(name: string, rs: PolicyResult[], observe?: string | undefined): void

Print one subject's policy results (spec 117-adopted-in-status FR-006, FR-007): a failure is a warning with its fix; what was not observed yet (never observed, or a policy that could not tell) is one waiting item, never a warning; observe is the command that observes the subject.

hostObservefunction
function hostObserve(name?: string | undefined): Promise<number>

stolos host observe [name]: observe one adopted machine, or all.

hostCheckfunction
function hostCheck(name?: string | undefined, json?: boolean): Promise<number>

stolos host check [name]: the policies, per adopted machine.

hostReleasefunction
function hostRelease(name: string): Promise<number>

stolos host release <name>: remove the probe and its key's line, then the model and the key.

queryAdoptedfunction
function queryAdopted(sql: string, adopted: readonly { machine: AdoptedDef; }[]): Promise<QueryAnswer[]>

One osquery SELECT on each adopted machine, through its probe (the caller checks the SQL first, with queryRefusal). Spec 078's osquery controls ask through this too.

queryTargetsfunction
function queryTargets(sql: string): Promise<AskTarget[]>

Every machine to ask a question: the managed servers (over their MCP servers) and the adopted machines (through their probes, the controller PC's own among them), each as a target askAll can ask within a time limit.

askFleetfunction
function askFleet(sql: string, o?: AskOptions): Promise<QueryAnswer[]>

Ask every machine one SELECT (spec 107-pairing-and-query FR-010): all at once, at most cap at a time, each within timeoutMs; onStart and onAnswer let a page draw the table as the answers come. The caller has checked the SQL (queryRefusal). Spec 108-tags FR-013: with a selection, only the machines whose tags it chooses are asked, and each answer carries its machine's tags.

fleetQueryfunction
function fleetQuery(sql: string, json?: boolean, timeoutS?: number | undefined, pick?: { tag?: unknown; "any-tag"?: unknown; select?: unknown; reported?: unknown; }): Promise<number>

stolos fleet query "<sql>" [--timeout s] [--tag t ...] [--any-tag t ...] [--select expr]: one osquery SELECT on every machine (or the machines the tags choose) at once; one merged table.

discoverfunction
function discover(json?: boolean): Promise<number>

stolos discover: machines seen on this PC's network or in the clouds, not yet in the fleet.

hostAcceptfunction
function hostAccept(name: string, policy: string, reason: string, until: string): Promise<number>

stolos host accept <name> <policy> --reason ... --until YYYY-MM-DD: record an accepted risk in machine.ts.

adoptCheckInfunction
function adoptCheckIn(ci: CheckIn, o: { name: string; ssh?: string | undefined; title?: string | undefined; owner?: string | undefined; until?: string | undefined; spec?: string | undefined; joined?: "integrated" | "paired" | undefined; tags?: readonly string[] | undefined; customTags?: readonly string[] | undefined; }, c?: Phase): Promise<number>

Adopt a machine from its check-in (a stolos1: code, or a paired machine's signed check-in): its host keys are pinned from the check-in, then it is observed over SSH with its probe key.

hostIntegratefunction
function hostIntegrate(o: { name: string; as: string; github?: string | undefined; repo?: string | undefined; }): Promise<number>

stolos host integrate <name> --as discover|adopt|osquery|server|workstation: the line to run on the machine.

discoverImportfunction
function discoverImport(code: string, name?: string | undefined, owner?: string | undefined): Promise<number>

stolos discover --import <code>: record a machine that checked in, to adopt or manage later.
