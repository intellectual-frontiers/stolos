entities

Spec 085: the normalized entities every source contributes to the estate graph: people (from HR systems), accounts (from identity providers, code hosts, clouds, SaaS), devices (managed, adopted, MDM, SNMP), repositories, resources, and findings. Connectors write them into their observations; the fleet's own machines add theirs. Only what a control needs is kept: names, work email, status and dates, roles. Never compensation or personal fields.

Source: src/archon/connect/entities.ts

An account in some system.

MemberTypeWhat it is
