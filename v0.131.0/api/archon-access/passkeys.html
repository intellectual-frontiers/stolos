passkeys

Spec 100: the two pieces of commons the console's remote access stands on, behind one small interface each, so the service and its tests depend on the contract, not on a module:

  • Passkeys: WebAuthn (commons kernel webauthn): the options a browser needs to create or use a passkey, and the verification of what it answers (FR-004, FR-007).
  • the ACME client and the Cloudflare DNS challenge (commons runtime acme), for the console's certificate (FR-002).

Source: src/archon/access/passkeys.ts
