welcome

032-web and 035-welcome-guide: the welcome page every server shows at https://<host>.<domain> (and at any name or address nothing else claims), written for someone new to the server: what it is, whether it's healthy, its apps, what's installed and how to use it, and how changes are made. Rendered per request by archon web serve (loopback only, behind Traefik, local networks only). No secrets: the mailbox address and the admin's username are the most personal things on it. Plain text only (no Nerd Font glyphs).

Source: src/archon/web/welcome.ts

interface WelcomeData

Everything the welcome page shows, gathered per request by archon web serve.

MemberTypeWhat it is
hoststringThe host's name in the model.
fqdn?stringIts full name (for example alpha.lab.example.net); unset without fleet.web.
titlestringThe fleet's title.
osstring"Ubuntu 26.04.1 LTS"
address?stringThe server's address on the local network, if known.
repo{ slug: string; url: string; }The fleet repository: owner/name and its GitHub URL.
lastRun?{ command: string; failures: number; warnings: number; deferred: number; push: boolean; at: string; }Archon's last run on this host (its status file): the command, its counts, whether commits wait to be pushed, and when.
verify?{ at: string; passed: number; total: number; failed: string[]; attention?: { resource: string; level: "fail" | "pending" | "warn"; output: string; fix: string; code?: string | undefined; }[] | undefined; }The last archon verify: when, how many checks passed of how many, and which failed.
installed?{ at?: string | undefined; ok?: boolean | undefined; checks?: { passed: number; total: number; } | undefined; }The install record (spec 048): when, whether it succeeded, and its checks.
certificate?{ issuer: string; notAfter: string; }The certificate Traefik serves on 443: its issuer and expiry, as openssl prints them.
updates?{ pending?: number | undefined; reboot: boolean; rebootPackages: string[]; lastRun?: string | undefined; }Ubuntu's updates: how many wait (unset when unknown), whether a reboot is needed and for which packages, and when they last installed by themselves.
backup?{ last?: string | undefined; ok?: boolean | undefined; }The last backup run, when the host has the backup timer: when it ended and whether it succeeded.
data?{ class: "durable" | "ephemeral"; reasons: string[]; }Article 23 (spec 044): durable or ephemeral, and why.
servicesService[]The apps and pages behind the proxy (none without fleet.web).
unroutednumber[]Ports open to the network with nothing published (internal ones excluded).
guideGuideItem[]What is installed and how to use it, from the host's plan (spec 035).
agent?AgentSetupHow an AI agent reaches this server (spec 035); servers only.
guides{ name: string; title: string; }[]Guides served at /guide/<name>.
adminstringThe fleet admin's username (for the ssh command shown).
mailbox?stringThe fleet's mailbox, where alerts go; unset without mail.
generatedstringWhen the data was gathered: YYYY-MM-DD HH:MM UTC.
