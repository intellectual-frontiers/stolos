prov

Provenance (spec 014, Article 16): every apply is recorded as an activity, kept in this machine's archon.sql (spec 048) and exported as W3C PROV (Turtle) by stolos export.

Source: src/archon/prov/prov.ts

Activityinterface
interface Activity

One apply, recorded as a PROV activity (spec 014).

MemberTypeWhat it is
hoststringThe host it ran on.
startedstringWhen it started (ISO 8601).
endedstringWhen it ended (ISO 8601).
agentstringWho ran it: agentName().
commitstringThe checkout's commit at the time ("unknown" when git cannot say).
changesstring[]What it changed, one line each.
failedbooleanWhether it failed.
log?stringThe path of the run's log, when there is one.
agentNamefunction
function agentName(): string

Who is acting: ARCHON_AGENT, else SUDO_USER, else USER, else "unknown".

headCommitfunction
function headCommit(): Promise<string>

The checkout's HEAD commit, or "unknown".

recordActivityfunction
function recordActivity(host: string, a: { started: Date; ended: Date; changes: string[]; failed: boolean; log?: string | undefined; }): Promise<string | undefined>

Record an apply in this machine's archon.sql (spec 048) as a prov record keyed by its start time, which is returned. An apply that changed nothing and did not fail is not recorded (returns undefined).

loadActivitiesfunction
function loadActivities(host: string, root?: string): Promise<Activity[]>

A host's recorded activities, oldest first.
