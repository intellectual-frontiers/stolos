fleet-init

stolos fleet init (spec 003): the fleet's identity, from your GitHub account as gh reports it. Runs on the boot machine (Windows or Linux). Public data goes into fleets/<fleet>/fleet.ts; the admin password hash goes only into the boot machine's secret store (Article 13).

Source: src/archon/identity/fleet-init.ts

FleetInitOptionsinterface
interface FleetInitOptions

What stolos fleet init is given.

MemberTypeWhat it is
id?stringThe new fleet's id: fleets/<id>/ (spec 046). Without it, the active fleet.
user?stringYour Unix account name on every host.
timezone?stringAn IANA time zone (default: this machine's).
locale?stringA locale (default en_US.UTF-8).
keyboard?stringA keyboard layout (default us).
passwordStdin?booleanRead the admin password from stdin instead of prompting (automation).
rewrite?booleanRewrite fleets/<fleet>/fleet.ts even though it exists (otherwise it is kept).
