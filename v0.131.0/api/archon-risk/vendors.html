vendors

Spec 080: the vendor inventory. Vendors are discovered, not typed in:

  • SSO applications: the apps people sign in to through the identity provider (Okta's app integrations, Entra's enterprise applications), as application nodes in the estate;
  • DNS: CNAME and MX records whose target is a third party's (a mail provider, a help desk, a hosting platform), as dns_record nodes;
  • connected accounts: each tenant a connector reads is itself a vendor;
  • billing: a hook (BillingSource) for a future billing connector.

A small typed table (WELL_KNOWN_VENDORS) maps catalog names and service domains to the organization behind them; anything else is an unknown vendor, named by its domain or app, for triage. The fleet's vendors.ts records each vendor's criticality (FIPS 199: low, moderate, high) and the data it holds (OCSF's data classification categories). A vendor discovered but not in vendors.ts waits for triage.
