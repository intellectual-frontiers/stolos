fleet

Spec 080: the fleet's register and vendors, read from the fleet repository (risks.ts, vendors.ts, controls/accepted.ts, adopted machines) and the estate graph, and run as the risk-register pack. stolos risks, stolos vendors, stolos compliance, and the consoles all read it here.

Source: src/archon/risk/fleet.ts

FleetRiskinterface
interface FleetRisk

The fleet's register, triage file, accepted risks, and vendors, with what did not load.

MemberTypeWhat it is
risks?Risk[]The register (undefined: no risks.ts).
triageVendorDef[]The triage file.
vendorsVendor[]The vendors, discovered and triaged.
runPackRunThe results of the risk-register pack.
problemsstring[]Why a file did not load.
