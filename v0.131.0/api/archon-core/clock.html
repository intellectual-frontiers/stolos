clock

Clock preflight (spec 016): apt rejects signatures that are "not live until" a future time when the host clock is behind, which silently skips trixie-security. Compare with an HTTPS Date header before touching apt.

Source: src/archon/core/clock.ts

ClockCheckinterface
interface ClockCheck

The local clock compared with a web server's Date header.

MemberTypeWhat it is
skewnumberSeconds the local clock is ahead (positive) or behind (negative).
sourcestringThe URL whose Date header was compared.
checkClockfunction
function checkClock(source?: string): Promise<ClockCheck | undefined>

Compare the local clock with source's HTTP Date header (one HEAD request, 5 second timeout). Undefined when the server cannot be reached or sends no Date.

describeSkewfunction
function describeSkew(skew: number): string

A skew in seconds for people, rounded: "3m behind", "2h ahead", "0s ahead".
