secrets

The boot machine's secret store (spec 003, Article 13): a per-user folder outside the repository (%APPDATA%\stolos\secrets on Windows, ~/.config/stolos/secrets elsewhere). Holds the admin password hash, each host's deploy key, and install tokens. Nothing here is ever committed.

Source: src/archon/core/secrets.ts

SECRETSconst
const SECRETS: { readonly dir: string; readonly adminPasswordHash: string; deployKey: (host: string) => string; deployKeyPub: (host: string) => string; acme: (host: string) => string; hostKey: (host: string, type: string) => string; readonly mail: string; exportMail: (name: string) => string; readonly web: string; readonly consoleTls: string; readonly tokens: string; }

Where each secret lives on the boot machine (per fleet; never in Git).

writeSecretfunction
function writeSecret(path: string, content: string): Promise<void>

Write a secret readable only by this user (POSIX 0600; Windows: inheritance removed and full control for this user only, icacls). Every secret write in Archon goes through here (spec 029): it records the change in the ledger, so the vault knows what is newer than the last backup. Unchanged content is not rewritten (and is not a change).

removeSecretfunction
function removeSecret(path: string): Promise<void>

Remove a secret (and record it, so the vault knows).

ownerOnlyfunction
function ownerOnly(path: string): Promise<void>

Windows: this user only (no inherited access), the equivalent of 0600.

readSecretfunction
function readSecret(path: string): Promise<string | undefined>

A secret's content, or undefined.

InstallTokeninterface
interface InstallToken

One armed install (the boot machine's own record).

MemberTypeWhat it is
hoststringThe host.
tokenstringThe random token in its install URLs.
armedstringWhen the token was issued (ISO time).
firstUse?stringFirst time the host fetched its install config; the token then lives 2 hours.
mac?stringThe MAC the host network-booted from, as GRUB reported it.
addresses?string[]Addresses the host was installed from (its old SSH host keys are forgotten for each).
claimUntil?stringboot arm --claim: until then, the next unknown machine to network-boot becomes this host.
done?stringThe installer reported completion; the token is spent.
confirmDestroy?trueSpec 051: a person repeated the host's name with --confirm-destroy: this one install may erase disks that are not blank (otherwise the installer stops).
reinstall?trueboot reinstall reached this host over SSH (its registered keys) and rebooted it into this install: a machine with this MAC holds this host already.
loadTokensfunction
function loadTokens(): Promise<InstallToken[]>

Every armed install.

saveTokensfunction
function saveTokens(tokens: InstallToken[]): Promise<void>

Write them back.

armHostfunction
function armHost(host: string, claimMinutes?: number, knownMac?: string | undefined, o?: { confirmDestroy?: boolean | undefined; reinstall?: boolean | undefined; }): Promise<InstallToken>

Arm a host for one install: any previous token for it is replaced.

liveTokenfunction
function liveToken(tokens: InstallToken[], host: string, now?: number): InstallToken | undefined

The live token for a host: armed, not done, and not expired.
