apply

Spec 060: stolos apply (or stolos push): your changes to the fleet, from this PC to every machine, in one command and at most one passphrase. Each step checks before it changes anything, and stops at the first problem with its fix; running it again with nothing new says so and does nothing.

Source: src/archon/fleet/apply.ts
