#Modules

accounts006-accounts: Archon's groups (sysusers.d), the operator sudo rule, and the ops account's GitHub access through this host's deploy key.
adopted095-proposals: what a host adopted from a proposal.
backup016-backups: the host's own state is archived daily (zstd tar) into Ubuntu's /var/backups by default, kept to a retention count, and restore-tested.
cli012-cli-mcp: the archon launcher on every host.
cockpit022-cockpit: Ubuntu's web console on every server, with PCP's metric history (cockpit-bridge reads the archives spec 021 keeps).
containers040-opt-in: opt-in containers on every server.
data044-durable (Article 23): what this server's data class is, where people see it.
doctor026-doctor: the network tools archon doctor calls.
etckeeper033-etckeeper: /etc's history in a local git repository (Ubuntu's etckeeper package): a commit before and after every apt run, one a day for anything else, and one per archon apply with its specs…
firewall008-firewall: Ubuntu's native firewall, ufw (nftables backend), with incoming traffic denied except the ports the model declares.
guests017-guests: LXD (Ubuntu's native container and VM manager, a snap) with its default bridge (lxdbr0) and a directory storage pool, initialized once from a rendered preseed.
mail027-mail: every server can send mail, the way programs expect to (/usr/sbin/sendmail, or SMTP on localhost:25).
notify025-notify: email the fleet's shared mailbox about major events.
observability021-observability: every server and workstation observes itself with Ubuntu's own components, and OpenTelemetry (OTLP) is the only protocol anything speaks when data leaves where it was made.
ops013-ops: the daily report (deterministic facts only).
osquery042-sql: osquery's daemon on every host, as infrastructure: always installed and running.
passwords037-smb, 039-pg-identity: one PAM hook keeps the copies of a person's Linux password that other protocols need in step with Linux: Samba's NT hash (SMB clients cannot prove a password any other way)…
pg038-pg, 039-pg-identity, 040-opt-in: PostgreSQL instances on a server, from the model (host.pg.instances) and the host's record (the host's own archon.sql (opt-in pg)).
platform001-platform: Ubuntu Server 26.04's own components, verified, never replaced (Article 2).
services039-pg-identity: the fleet's service accounts on every server.
shell011-shell: per-user chezmoi data from personas, so chezmoi apply never prompts.
smb037-smb: file shares over SMB (Samba) on every server, off until an operator turns them on with archon fs smb on; then on, across reboots and reinstalls, until archon fs smb off.
ssh007-ssh: OpenSSH hardening as a drop-in (Ubuntu reads sshd_config.d).
state014-state and 015-reconcile: hosts converge to the repository on a timer (Article 9), and capture their state daily into /var/lib/archon (runtime; spec 048: nothing is recorded in the repository).
tools010-tools: the tool catalog, its apt packages, and the weekly tools sync.
updates009-updates: Ubuntu's unattended-upgrades, as Ubuntu configures it, plus one override (spec 009): the -updates pocket too, so Ubuntu's stable bug-fix updates install daily alongside security updates.
web032-web: every server is HTTPS-ready from its first boot.
workstation020-workstation: Ubuntu on WSL (or a desktop) as an Archon workstation.
modCapabilities: one module per spec.
re-exportsWhat archon capabilities exports from elsewhere, so that its users need import nothing else.
