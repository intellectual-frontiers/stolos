commands

037-smb: archon fs smb on | off | status. SMB is an opt-in service (spec 040): on and off are the shared switch (the host's own archon.sql (opt-in smb)). SMB uses each account's own Linux username and password: PAM keeps Samba's copy in step whenever the password is typed on the server.

Source: src/archon/smb/commands.ts

SmbRecordinterface
interface SmbRecord

The host's SMB switch record (spec 040's opt-in record).

MemberTypeWhat it is
enabledbooleanWhether SMB is on.
bystringWho last turned it on or off.
atstringWhen (ISO 8601).
readRecordfunction
function readRecord(host: string, root?: string): Promise<SmbRecord | undefined>

The host's SMB switch record in archon.sql, or undefined when it was never turned on.

howToConnectfunction
function howToConnect(name: string, user?: string): string[]

How to connect, for the person who just turned it on (or asked).

smbOnconst
const smbOn: (host: string, data: DataClass, confirm?: unknown) => Promise<number>

archon fs smb on: turn SMB on with the forced data choice (spec 044). confirm is the --confirm-destroy value. Resolves to the exit code.

smbOffconst
const smbOff: (host: string) => Promise<number>

archon fs smb off: turn SMB off (its data is kept). Resolves to the exit code.

smbStatusfunction
function smbStatus(hostName: string): Promise<number>

archon fs smb status: the switch, smbd and port 445, the shares, and who has an SMB password (as root). Returns 1 when a check failed, else 0.
