define

Spec 078: a control, written in TypeScript. A control is a query plus an assertion, tagged with the Secure Controls Framework (SCF) controls it gives evidence for. Its subject says what it asks:

  • estate: SQL over the estate graph (spec 090), one SELECT per query, read-only (through estateQuery); one result across systems.
  • osquery: one osquery SELECT on every adopted machine, through its probe (as stolos fleet query); one result per machine.
  • observation: a typed observation Stolos already holds (an adopted machine's, a device's, a connected account's); one result per subject.

Its assertion turns the answer into a Verdict (pass, fail, warn, or unknown, with what was found), or undefined when the control does not apply. Controls are grouped into a pack (defineControlPack), which a fleet keeps in fleets/<fleet>/controls/<pack>/pack.ts.
