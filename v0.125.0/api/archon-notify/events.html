events

Which events send a message (spec 025): major actions only, never every routine run. Each helper queues (never throws, never waits for the relay) and starts the sender.

Healthinterface
interface Health

What HEALTH holds: the last known state of each thing that sends on a change.

MemberTypeWhat it is
apply?{ state: "failing" | "ok"; since: string; notified?: string | undefined; }The last full apply: ok or failing, since when (ISO 8601), and when a "failing" message was last sent (for the daily reminder).
verifyFailing?string[]The verify checks (resources) failing at the last run; unset before the first.
rebootNotified?stringThe boot id the "needs a reboot" message was sent for (one per boot).
backupSummaryAt?stringWhen the last weekly backup summary was sent (ISO 8601).
applyTransitionfunction
function applyTransition(prev: { state: "failing" | "ok"; since: string; notified?: string | undefined; } | undefined, ok: boolean, now?: Date): { next: { state: "failing" | "ok"; since: string; notified?: string | undefined; }; send?: "failing" | "recovered" | "still failing" | undefined; }

What to send about an apply, given the last known state: ok -> failing, failing -> ok, and a reminder once a day while it keeps failing. Nothing for an apply that stays ok.

applyOutcomefunction
function applyOutcome(hostName: string, ok: boolean, failing: string[], log: string | null, timezone: string): Promise<void>

After every full apply (reconcile, update, apply): message on state changes only.

rebootCheckfunction
function rebootCheck(hostName: string): Promise<void>

Updates that need a reboot: one message per boot.

verifyOutcomefunction
function verifyOutcome(hostName: string, checks: { resource: string; ok: boolean; output: string; level?: string | undefined; }[]): Promise<void>

archon verify as root: a check that passed before and fails now.

backupOutcomefunction
function backupOutcome(hostName: string, ok: boolean, detail: string, log: string | null): Promise<void>

Backups: every failure, and a summary once a week.
