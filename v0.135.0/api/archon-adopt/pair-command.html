pair-command

Spec 098: stolos pair, on the controller PC. Shows the short line to run on a machine for each door that is up and a code, keeps the pairing's record in a short-lived file (spec 103-three-ports), and asks the person to approve the machine before anything is written to the fleet repository. The doors answer the machine from that file: the boot server's HTTP on TCP 8080 (when boot serve runs; otherwise this command serves just the /device/pair routes there, no TFTP and no downloads), and the console's TLS on TCP 443 (when stolos console --lan serves and its name resolves to this PC). The person still approves here, in the terminal.

Source: src/archon/adopt/pair-command.ts

runPairingfunction
function runPairing(r: PairRun): Promise<"no-door" | PairEnd>

The terminal's part of a pairing: write the record, bring the doors up, then watch the record: when a machine's check-in is waiting, ask the person (approve) and write the decision; end on a decision, on too many wrong tries, on expiry, on a record another stolos pair replaced, or on Ctrl+C. Whatever ends it, the record is removed in finally.
