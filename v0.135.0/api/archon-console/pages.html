pages

Spec 065: the Archon Console's pages, as typed functions of their data: sign-in, Overview, Actions, Activity, and Guide. Written for developers who have not run servers before: each page says what it is for, and the diagrams (Mermaid, drawn from this server's real state) show how the pieces connect: the fleet repository, signing, the 15-minute convergence, and what happens when you press Run.

Source: src/archon/console/pages.ts

interface RepoFacts

What the server's checkout of the fleet repository says about itself.

MemberTypeWhat it is
commit?{ sha: string; subject: string; author: string; at: string; }The commit applied now: short hash, subject, author.
signer?stringWho signed it (a name from signers.ts), when the signature is good.
engine?stringThe engine release the fleet is pinned to ("v0.66.0").
signers{ name: string; role: string; }[]The fleet's signers: name and role.
