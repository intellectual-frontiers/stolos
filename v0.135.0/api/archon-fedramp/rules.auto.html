ClassCadenceinterface
interface ClassCadence

What the rules ask of each class's package, and how often.

MemberTypeWhat it is
automationClassRule & { minMethods: number; }FRC-CSX-VVK: automated validation of each KSI, with the minimum number of methods.
machineValidationClassRuleVDR-TFR-MVX: how often machine-based resources are verified and validated.
packageMaintenanceClassRuleCPO-CSX-CPM: how often the certification package is brought up to date.
metricsClassRuleSDR-CSX-KMT: historical metrics in the Security Decision Record.
documentationClassRuleSDR-CSX-KSI: what the Security Decision Record says for each KSI.
