interface OcsfNetworkEndpoint

Network Endpoint: The Network Endpoint object describes characteristics of a network endpoint. These can be a source or destination of a network connection.

Container: The information describing an instance of a container. A container is a prepackaged, portable system image that runs isolated on an existing system using a container runtime like containerd. (recommended)

Intermediate IP Addresses: The intermediate IP Addresses. For example, the IP addresses in the HTTP X-Forwarded-For header. (optional)

optional

For example, Comcast Corporation would be the ISP org for Xfinity internet service. This attribute helps identify the ultimate provider when ISPs operate under different brand names. (optional)

Name: The short name of the endpoint. (recommended)

Namespace PID: If running under a process namespace (such as in a container), the process identifier within that process namespace. (recommended)

optional
network_scope: string

Network Scope: Indicates whether the endpoint resides inside the customer’s network, outside on the Internet, or if its location relative to the customer’s network cannot be determined. The value is normalized to the caption of the network_scope_id. (optional)

optional
network_scope_id: 0 | 1 | 2 | 99

Network Scope ID: The normalized identifier of the endpoint’s network scope. The normalized network scope identifier indicates whether the endpoint resides inside the customer’s network, outside on the Internet, or if its location relative to the customer’s network cannot be determined. Values: 0 Unknown, 1 Internal, 2 External, 99 Other. (optional)

os: OcsfOs

optional

Owner: The identity of the service or user account that owns the endpoint or was last logged into it. (recommended)

optional
pool: OcsfGroup

Pool: The pool of desktops or virtual machines to which the endpoint belongs. (optional)

optional
port: number

Port: The port used for communication within the network connection. (recommended)

optional
proxy_endpoint: OcsfNetworkProxy

Proxy Endpoint: The network proxy information pertaining to a specific endpoint. This can be used to describe information pertaining to network address translation (NAT). (optional)

optional
subnet_uid: string

Subnet UID: The unique identifier of a virtual subnet. (optional)

optional

Service Name: The service name in service-to-service connections. For example, AWS VPC logs the pkt-src-aws-service and pkt-dst-aws-service fields identify the connection is coming from or going to an AWS service. (recommended)
