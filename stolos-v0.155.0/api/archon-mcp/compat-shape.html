compat-shape

The shape of the MCP tool surface a machine serves (spec 115-compatibility FR-003): each tool listed at the tier mutate (what an operator's agent reaches), with its tier, whether it is read-only with a flag, and its arguments (name, type, whether required), sorted. Descriptions are not part of the shape: rewording a tool does not change what a reader may rely on. bun run compat:digest and tests/compat115.test.ts digest this text for the seam mcp.

Source: src/archon/mcp/compat-shape.ts

mcpShapefunction
function mcpShape(): string

The tools a machine serves at mutate, one line each: name, tier, read-only flag, and each argument as name:type (! where required).

    Titles, headings, exports, tables, columns and requirements. Esc closes.
