compat-command

stolos compat (spec 115-compatibility FR-016): the contract between this PC and its machines, in one report: the seams with this PC's current and minimum, this PC's engine, each machine with its engine, status and fix, and each hold at an engine tag with its check. It asks nobody (it reads what the machines last reported, kept by stolos fleet status and stolos host observe), except git ls-remote of the engine's repository for a hold's tag, with a time limit.

Source: src/archon/observe/compat-command.ts
