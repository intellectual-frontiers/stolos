fleet-machines

Spec 117-adopted-in-status: every machine of the fleet in stolos fleet status, after the managed servers: the adopted machines (paired, integrated), the SNMP devices and the network assets adopted through an integration. Each is one line (name, kind, how it joined, operating system, last observation, policy result, tags; a network asset also the account it came through and its state) and detail lines only for what is wrong (a failing policy, a warning with its fix) or waiting (what was not observed yet, once, with the command that observes it). The lines are a function over data (machineLine, lineText); showOtherMachines loads and prints them.

Source: src/archon/observe/fleet-machines.ts

MachineLineinterface
interface MachineLine

One machine of the fleet that is not a managed host, as its line and its detail lines need it.

MemberTypeWhat it is
namestringIts name in the fleet.
kindstringWhat it is, in words: workstation, server, machine, device (router), network asset (switch).
joinedWayOfJoining | undefinedHow it joined (spec 107-pairing-and-query FR-007).
osstringIts operating system, or a device's model; empty where nothing was read.
observedAt?stringWhen it was last observed (ISO time), where it was.
resultsreadonly PolicyResult[]Its policy results.
observestringThe command that observes it.
via?{ connector: string; account: string; state: string; }A network asset: the connector, the account and the state at the controller.
quiet?readonly string[]The ids of results said elsewhere (the Network phase says a network asset's presence and state), not repeated as warnings.
adoptedKindfunction
function adoptedKind(o: Observed | undefined): string

Whether an adopted machine is a workstation or a server, from what its probe read: Windows, macOS and a Linux flavor of a desktop distribution (Omarchy) are workstations, any other Linux is a server, and one never observed is only a machine.

resultTextfunction
function resultText(rs: readonly PolicyResult[]): string

The policy result in short form: 8 passing, 1 failing, 2 not observed yet (the zero ones left out, except the passing).

lineTextfunction
function lineText(l: MachineLine, tags: string): string

The one line of a machine: name, kind, how it joined, operating system, last observation, policy result, tags.

showMachinefunction
function showMachine(l: MachineLine, tags: string): void

Print one machine: its failing policies and what is not observed yet as detail lines, then its line.

otherMachinesfunction
function otherMachines(now?: number): Promise<MachineLine[]>

Every machine the fleet knows beyond its managed hosts and the controller, in the order of spec 117-adopted-in-status FR-001: the adopted machines, the SNMP devices, the network assets. A source that cannot be read gives none (a courtesy: the hosts are still shown).

showOtherMachinesfunction
function showOtherMachines(tagsOf: (name: string) => string): Promise<number>

Print the other machines of the fleet, each with its tags (tagsOf: the text of spec 108-tags FR-015, or empty).
