commands

Spec 080: stolos risks list | check | review and stolos vendors list | triage, on the controller PC, over the fleet repository and the estate graph built from Git. The reading ones change nothing; risks review and vendors triage --write open a pull request (a branch, one signed commit, gh pr create), which a signer approves by merging it with a signed merge commit.

Source: src/archon/risk/commands.ts

risksListfunction
function risksList(json?: boolean): Promise<number>

stolos risks list: the register, highest level first.

risksCheckfunction
function risksCheck(json?: boolean): Promise<number>

stolos risks check: the risk-register pack's results, and who approved the files.

risksReviewfunction
function risksReview(id: string, o?: { next?: string | undefined; note?: string | undefined; check?: boolean | undefined; }): Promise<number>

stolos risks review <id>: move a risk's next review on, in a signed pull request.

vendorsListfunction
function vendorsList(json?: boolean): Promise<number>

stolos vendors list: every vendor, discovered or triaged, and what revealed it.

vendorsTriagefunction
function vendorsTriage(o?: { write?: boolean | undefined; json?: boolean | undefined; }): Promise<number>

stolos vendors triage [--write]: vendors not triaged yet; with --write, a pull request adding them.
