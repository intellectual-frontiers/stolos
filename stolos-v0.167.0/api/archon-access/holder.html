holder

Spec 103-three-ports FR-009: why the console cannot listen on TCP 443, in plain words. There is no fallback to another port (Article 29): when 443 is in use or not allowed, the LAN listener is refused, and the message names what holds the port where that is cheap to find (Windows: Get-NetTCPConnection and the owning process; Linux: ss -ltnp; macOS: lsof), and the fix. The lookup never fails a command: where it cannot tell, the message says only that the port is taken. stolos console --lan --lan-port <n> is the explicit choice, which prints its own firewall rule.

Source: src/archon/access/holder.ts
