site

Spec 081: the Trust Center's page. One self-contained HTML file: its stylesheet and its one small script are inline (and pinned by SHA-256 in its Content-Security-Policy, which also forbids every request to anywhere else); it uses the system's fonts; it follows the reader's light or dark setting; it reads at phone width; and every status is written in words, not only in color. The script only turns "N before this page was built" into "N ago" by the reader's clock, and shows the stale-bundle banner when the page has aged past it; the page says the same without it.

Source: src/archon/trust/site.ts
