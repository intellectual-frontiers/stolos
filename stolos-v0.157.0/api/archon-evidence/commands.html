Spec 072: stolos evidence export --from <date> --to <date> gathers a period's evidence from the fleet repository and this PC, and signs it with your daily key (ssh-keygen asks its passphrase in this terminal; Stolos never sees it). stolos evidence verify <bundle> checks one, offline.

Source: src/archon/evidence/commands.ts
