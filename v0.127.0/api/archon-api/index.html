archon api

Spec 094: the REST API's request handler, mounted under /v1/ in the Stolos Console (../console/stolos-server.ts), on this PC only. The console has already checked the Host (127.0.0.1 or localhost) and the signed-in session before a request reaches it; it opens no listener of its own.

  • GET /v1/: what it serves; GET /v1/openapi.json: the OpenAPI 3.1 document.
  • GET /v1/<table or view>: a page of rows (limit, offset, equality filters).
  • GET /v1/finding?format=ocsf (or Accept: application/vnd.ocsf+json): the findings as OCSF Compliance Findings.
  • GET /v1/oscal/<document>: an OSCAL document.
  • GET /v1/evidence/, GET /v1/evidence/<bundle>: the evidence bundles.

Only GET and HEAD: anything else is 405.
