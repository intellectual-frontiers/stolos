observe

bun run stolos boot observe (spec 023): recent installs from the boot server's own telemetry (the OTLP JSON files on this PC): when, how long, which step took the time, and what failed.

Source: src/archon-boot/observe.ts

Installinterface
interface Install

One install, from its root span archon.boot.install.

MemberTypeWhat it is
namestringThe host's name.
startDateWhen it started.
secondsnumberHow long it took, in seconds.
okbooleanWhether the root span ended without an error.
result?stringIts archon.result attribute (for example "Ready"), if any.
steps{ name: string; seconds: number; ok: boolean; problem?: string | undefined; }[]Its steps (the root's children), in order, with their durations and any problem.
installsFromfunction
function installsFrom(lines: string[]): Install[]

Installs (archon.boot.install spans) with their steps (archon.boot.step), newest first.

bootObservefunction
function bootObserve(o: { count: number; }): Promise<number>

bun run stolos boot observe: the newest count installs, each with its slowest and failed steps.
