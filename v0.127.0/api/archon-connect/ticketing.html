ticketing

Spec 087: what the ticketing connectors (Jira, Linear) share: how a ticket is classed (change, incident, or other), how commit SHAs and pull request URLs are found in the links a ticket carries, the tickets' posture, and the policies on it. Evidence for change control (SCF CHG-03): a change that shipped links the commit or pull request it shipped in.

Source: src/archon/connect/ticketing.ts

TICKET_DAYSconst
const TICKET_DAYS: 90

How far back tickets are read (days).

TICKET_MAXconst
const TICKET_MAX: 1000

At most this many tickets are read per observation.

ticketTypefunction
function ticketType(...words: (string | undefined)[]): "change" | "incident" | "other"

A ticket's type from its issue type, project, or labels (the source's own words).

devLinksfunction
function devLinks(urls: (string | undefined)[]): string[]

The commit SHAs and pull (or merge) request URLs among a ticket's links, deduplicated, in order.

ticketPosturefunction
function ticketPosture(records: ObservedRecord[]): Record<string, string | number | boolean>

The tickets' posture: changes, how many link their development work, incidents.

ticketPoliciesfunction
function ticketPolicies(o: Observation, prefix: string, fix: { changes: string; link: string; admins: string; }): PolicyResult[]

The ticketing policies, in the vendor's words (ids prefixed with prefix).

daysBeforefunction
function daysBefore(now: Date, days: number): string

An ISO time days before now.
