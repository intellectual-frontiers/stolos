engagement

Spec 083: an audit engagement, as a file in the fleet repository: fleets/<fleet>/audits/<id>/engagement.ts. It says who audits (the firm and its people), the period, the frameworks and the controls in scope (each tested on one population), the evidence bundle the populations are drawn from (pinned by its SHA-256), and the day the auditor's access ends. stolos audit open writes it and stolos audit close closes it, each in a signed commit; Stolos reads it as a TypeScript literal (never runs it), so a past version from Git reads the same way.

Source: src/archon/audit/engagement.ts

Engagementinterface
interface Engagement

An audit engagement: fleets/<fleet>/audits/<id>/engagement.ts.

MemberTypeWhat it is
idstringIts id: the folder's name (lowercase letters, digits, dashes).
titlestringIts name for people ("SOC 2 Type 2, 2026").
firmstringThe audit firm.
auditorsAuditor[]The firm's people who may see it.
period{ from: string; to: string; }The period audited (YYYY-MM-DD, both days included).
frameworksstring[]The frameworks in scope (soc2, iso27001, hipaa, pci, ...).
controlsScopedControl[]The controls in scope.
access{ expires: string; }The portal's time box: it refuses every request after this day (YYYY-MM-DD, UTC, the day included).
bundle?PinnedBundleThe evidence bundle, once pinned.
opened{ on: string; by: string; }When it was opened (YYYY-MM-DD), and by which fleet signer.
closed?{ on: string; by: string; }When it was closed (YYYY-MM-DD), and by whom; the portal refuses a closed engagement.
PinnedBundleinterface
interface PinnedBundle

The evidence bundle (spec 072) an engagement's populations are drawn from.

MemberTypeWhat it is
filestringIts file name in this PC's evidence directory.
sha256stringIts SHA-256: a different file with that name is refused.
headstringIts manifest's head (the end of its hash chain).
ScopedControlinterface
interface ScopedControl

One control in scope, and the population it is tested on.

MemberTypeWhat it is
idstringThe control's id as the auditor names it (a criterion such as "CC6.2", or the company's own id).
titlestringWhat it is, in words.
framework?stringThe framework it is from (soc2, iso27001, ...), when it is one framework's.
scf?string[]The SCF controls it maps to, when known.
populationPopulationIdThe population it is tested on (a typed query over the bundle's items).
