commands

Spec 083: stolos audit .... The writing commands (open, bundle, access, request, respond, sample, close) each make one commit, signed with Git's signing key (your daily key: ssh-keygen asks its passphrase in this terminal), of the engagement's files only; nothing is pushed. The reading ones (list, show, export, verify, portal) change nothing.

The work is in functions that take an AuditCtx (the repository, the fleet, a committer), so the tests drive them with a real repository and a real key; the commands build the context from this PC.

Source: src/archon/audit/commands.ts
