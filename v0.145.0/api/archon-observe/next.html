next

"What now?" for a freshly installed server or workstation (specs 021, 022): how to reach it, its web console, and how to observe it. One list, shown by the boot server when a host is ready, at the end of the first boot, by boot reinstall, by stolos fleet status, and (servers) at SSH login.

Source: src/archon/observe/next.ts

interface NextOptions

What nextSteps needs to know about a host.

MemberTypeWhat it is
hostHostDefThe host the steps are for.
fleetFleetDefIts fleet (admin account, web domain, local networks).
address?stringAn address it is known by besides its name.
nextStepsfunction
function nextSteps(o: NextOptions): string[]

The "what now?" lines for a host, one per step, each a short label then the command or address: connect, Cockpit, observe, live, health, HTTPS, agent.
