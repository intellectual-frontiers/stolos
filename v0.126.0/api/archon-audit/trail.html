trail

Spec 083: the audit trail. Every request the auditor makes, every response the company gives, and every sample drawn is one file in fleets/<fleet>/audits/<id>/trail/, numbered in order (0001-request.md, 0002-response.md, 0003-sample.md), added in a commit of its own signed with a fleet signer's key. The commit names the file and its SHA-256 in a trailer, so the signature covers the entry's exact text and an auditor checks it with the commit alone:

engagement.ts carries the same trailer in each commit that writes it. An entry is a Markdown file with front matter, each value one line of JSON:

Source: src/archon/audit/trail.ts
