notify

archon notify (spec 025): major events, by email, to the fleet's shared mailbox. Reporting never fails or slows the action it reports: a message is queued on disk and sent by archon notify flush (a service started at once and a timer every 5 minutes) through Cloudflare's SMTP relay (spec 027), with backoff when it cannot be reached, duplicates dropped by key within an hour, and one summary after a long outage. Nothing secret is ever sent (IFC TypeScript's one redaction, otel.redactText).

Source: src/archon/notify/notify.ts

Siteinterface
interface Site

Where this machine keeps its credential, queue, and status.

MemberTypeWhat it is
role"boot" | "server" | "workstation"What this machine is: a server, a workstation, or the boot machine.
namestringIts short name, as it appears in subjects and in the From display name.
credentialstringPath of the credential file (Postfix's sasl_passwd on hosts, JSON on the boot machine).
spoolstringFolder of queued messages, one JSON file each.
statusstringPath of the status file (archon notify status reads it).
to?stringThe fleet's mailbox (fleet.mail.to); unset when the fleet has no mail.
from?stringThe sender address (spec 027); unset when the fleet has no mail.
relaystringhost:port of the SMTP relay (Cloudflare Email Service).
ipv4booleanReach the relay over IPv4 only (the network has no IPv6).
timezonestringThe fleet's IANA time zone, for local times in messages.
HOST_NOTIFYconst
const HOST_NOTIFY: { credential: string; spool: string; status: string; flushUnit: string; }

Where a host (server or workstation) keeps its notify files, and its flush unit.

hostSitefunction
function hostSite(fleet: FleetDef, name: string, kind: "server" | "workstation", ipv6: boolean): Site

A host as a notify site: the fixed host paths, the fleet's mailbox, and root+<host>.<tag>@<domain> as sender (spec 027). ipv6 is whether the host's network has IPv6 (without it, the relay is reached over IPv4).

bootUserfunction
function bootUser(): string

The boot machine's user, as a mail local part (Windows USERNAME, else USER).

bootSitefunction
function bootSite(fleet: FleetDef): Site

The boot machine as a notify site: its queue next to the boot cache, the credential in its secrets folder, and <user>+<pc>.<tag>@<domain> as sender.

loadCredentialfunction
function loadCredential(site: Site): Promise<Credential | undefined>

The relay credential: parsed from sasl_passwd on hosts, JSON on the boot machine; undefined when missing or unreadable.

Eventinterface
interface Event

Something to report: what notify and enqueue take.

MemberTypeWhat it is
eventstringWhat happened, short: "✗ apply failing since 14:04".
level?LevelHow serious it is; "info" by default.
whatstringThe details: a few lines.
todo?stringWhat a person or assistant should do, if anything.
log?stringPath of the full log, named in the message (not attached by itself).
attach?string[]Files to attach (redacted, trimmed, about 1 MB in all).
key?stringMessages with the same key within an hour are sent once.
subject?stringarchon notify send: this exact subject (for example "Lab Network Runbook Change Log ..."), and what as the whole body.

attachmentsfunction
function attachments(files: string[], exact: string[]): Promise<{ name: string; type: string; b64: string; }[]>

Files to attach: text redacted and trimmed to its end, gzipped when large; about 1 MB in all.

composefunction
function compose(site: Site, ev: Event, exact?: string[]): Promise<Queued>

Build the message for an event: subject, plain text and HTML, all redacted (known secret shapes and the exact strings). With ev.subject the body is ev.what as given; otherwise a report with host, time, Archon commit, what happened and what to do.

BACKOFF_MINconst
const BACKOFF_MIN: number[]

Backoff between attempts: 1 min, 5 min, 15 min, 1 h, then every 3 h.

enqueuefunction

Queue a message. Returns why it was not queued, if it was not. Never throws.

queuedfunction
function queued(site: Site): Promise<{ path: string; q: Queued; }[]>

The messages in the spool, oldest first, with their file paths.
