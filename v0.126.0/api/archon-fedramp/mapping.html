mapping

Spec 076: which Stolos evidence gives evidence for each FedRAMP 20x Key Security Indicator (KSI), and which KSIs Stolos cannot observe, each with its reason in plain words. This is the only mapping here that is Stolos's own: "these checks give evidence for this KSI". The KSIs themselves, their NIST SP 800-53 controls, and which classes they apply to are FedRAMP's (rules.auto.ts); the path from a check's SCF control to SP 800-53 is the SCF Council's (its STRM, in the catalog), and strmLinks shows it where it exists, so a reviewer can see each claim's footing.

Every KSI appears exactly once: the type is a record over FedRAMP's KSI ids, so a KSI FedRAMP adds fails to compile until it is mapped.

Source: src/archon/fedramp/mapping.ts

KsiCoveredinterface
interface KsiCovered

A KSI that Stolos's checks give evidence for.

MemberTypeWhat it is
scfstring[]The SCF controls whose evidence counts (Evidence.scf).
sources?("adopted" | "cloud" | "control pack" | "device" | "estate" | "managed" | "repository")[]Only evidence from these sources (default: any).
reasonstringWhat the checks show for this KSI, and what they do not, in plain words.

type NotObservableKind = "process" | "document" | "contract" | "not read";

Why Stolos cannot observe a KSI.

MemberTypeWhat it is
notObservableNotObservableKindWhat it rests on: a person's process, a document, a contract, or something Stolos does not read.

strmLinksfunction

Where the SCF Council's STRM reaches the KSI's own SP 800-53 controls: for each SCF control the mapping cites, the KSI's controls it shares. Empty without the catalog, or where the claim rests on the reason alone.
