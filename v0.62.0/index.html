Stolos v0.62.0

The fleet engine (its command is archon), documented from its TypeScript.

Start here: the overview, with how the pieces fit, in diagrams. Then the model: types.ts. Every symbol: all symbols (searchable).

archon/

  • build.ts stolos validate and stolos build (spec 002): validate the fleet and every host plan (TypeScript, Article 10), then render each host's files into out/hosts/<host>/rootfs/.
  • main.ts The command line, for both commands (spec 059): archon on each machine (servers, workstations) and stolos on your PC (src/stolos/main.ts), over one registry where every command says where it runs.
  • version.ts The engine's version (spec 046-engine-instance).

  • state.ts 014-state and 015-reconcile: hosts converge to the repository on a timer (Article 9), and capture their state daily into /var/lib/archon (runtime; spec 048: nothing is recorded in the repository).
  • tools.ts 010-tools: the tool catalog, its apt packages, and the weekly tools sync.
  • updates.ts 009-updates: Ubuntu's unattended-upgrades, as Ubuntu configures it, plus one override (spec 009): the -updates pocket too, so Ubuntu's stable bug-fix updates install daily alongside security updates.
  • web.ts 032-web: every server is HTTPS-ready from its first boot.
  • workstation.ts 020-workstation: Ubuntu on WSL (or a desktop) as an Archon workstation.
