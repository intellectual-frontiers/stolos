proposal

Spec 095-proposals: the stolos-proposal/1 format. A proposal is proposal.json (the host, the model commit it ran, who proposed it and why, the change sessions, each item with its action and the structured edits that adopt it, and the observations as evidence) and proposal.json.sig, an SSH signature made with the host's own host key (ssh-keygen -Y sign -n stolos-proposal). The PC already has that public key in Git (registration.ts), so a forged or altered proposal is refused.

Everything in it has passed through notify's redaction before it is signed, so the mail cannot change a byte of it (Article 13).

Source: src/archon/proposal/proposal.ts
