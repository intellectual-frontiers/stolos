compat-shapes

The shape of a seam, as a digest (spec 115-compatibility FR-003): a stable SHA-256 of text derived from the code itself, so that a golden test and bun run compat:digest can tell that a seam changed without anyone listing its fields by hand. The model's shape is the text of its types with comments and layout removed; the query interface's is its views and their columns, sorted; the MCP tool surface's (src/archon/mcp/compat-shape.ts, one rung up) is each tool with its arguments and tier. tests/compat.digest.txt holds each digest with the version it belongs to, and reconcileDigests is the one rule: a changed digest under an unchanged version is refused.

Comments and layout do not move a digest

Source: src/archon/observe/compat-shapes.ts

DIGESTED_SEAMSconst
const DIGESTED_SEAMS: readonly ["model", "query", "mcp"]

The seams whose shape is a digest of the code (the other two are versioned by hand, FR-003).

type DigestedSeam = (typeof DIGESTED_SEAMS)[number];

One of DIGESTED_SEAMS.

shapeTextfunction
function shapeText(source: string): string

TypeScript text with its comments removed and every run of whitespace made one space: what a type says, not how it is laid out or documented. Strings and template literals are kept whole (a // inside one is not a comment).

sha256const
const sha256: (text: string) => string

The SHA-256 of a text, in hex.

modelShapefunction
function modelShape(src?: string): Promise<string>

The model's shape: the types of the fleet and its hosts, and the site's, as text (spec 115-compatibility FR-003).

queryShapefunction
function queryShape(views?: Readonly<Record<string, readonly string[]>>): string

The query interface's shape: every view of the machine's state database with its columns, sorted.

DigestOutcomeinterface
interface DigestOutcome

What reconcileDigests decided.

MemberTypeWhat it is
problemsstring[]What is wrong, in words: a changed shape under an unchanged version.
nextDigestEntry[]The entries the file should hold (what is there, with what may be recorded).
changedbooleanWhether next differs from what was recorded.
reconcileDigestsfunction
function reconcileDigests(recorded: readonly DigestEntry[], now: Readonly<Record<"mcp" | "model" | "query", string>>, current?: Readonly<Record<Seam, { current: string; }>>): DigestOutcome

The one rule (spec 115-compatibility FR-003): for each digested seam, a digest that differs from the recorded one is accepted only where the seam's version is higher than the recorded version; a version raised without a change of shape is accepted too; a seam with no record is recorded. current is the version of SEAMS, now the digests of the code.
