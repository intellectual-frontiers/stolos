sdk

Spec 089: the connector SDK. A connector is declared once, in typed TypeScript: its credential's fields, the resources it reads (each an async generator over the vendor's public API, mapped to a label in the estate graph and an OCSF class), and its posture policies. defineConnector turns it into a Connector the rest of Stolos already runs.

What every connector gets, so none re-implements it (the transport, the read-only guard, backoff and paging are IFC TypeScript's runtime http):

  • a read-only guard: only safe methods, plus the token endpoints it declares and the POSTs it declares as reads (readPost);
  • paging: Link: rel="next", cursors in the body, page tokens;
  • backoff on 429 and 503, honoring Retry-After;
  • a denied call becomes a gap in the observation, not a failure;
  • the vendor's record kept beside the mapped one (OCSF's unmapped).

Nothing else: no vendor SDK, no third-party binary. Only the runtime and the vendor's published API.

Source: src/archon/connect/sdk.ts
