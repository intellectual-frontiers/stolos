bitbucket

Spec 091: Bitbucket Cloud, read-only, for one workspace: its members (who are owners) and its repositories (private or public, whether the main branch is protected by branch restrictions, and how many approvals a pull request needs to merge). Evidence for change management (SCF CHG-03) and least privilege (IAC-30).

Bitbucket's API does not show members' two-step verification or whether the workspace requires it, and secret scanning has no per-repository setting to read: those policies stay unknown.

Credential: an Atlassian API token with Bitbucket scopes, read only (read:workspace:bitbucket, read:user:bitbucket, read:repository:bitbucket), sent with the account's email (HTTP Basic).

Source: src/archon/connect/bitbucket.ts
