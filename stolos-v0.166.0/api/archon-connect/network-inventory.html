network-inventory

Spec 111-network-posture FR-016: the network inventory (NIST SP 800-53 Rev 5 CM-8, system component inventory): every network device the integration reports or the fleet adopted (class, model, firmware, address, state, tags, how it joined, when it was observed), the Wi-Fi networks and the networks, and the gaps, as Markdown or JSON. It is deterministic: it holds no time of its own (the time of a device is its observation's) and a stable order, so the same observation and records give the same bytes, and a commit of the file is a record of the inventory.

Source: src/archon/connect/network-inventory.ts

The inventory.

MemberTypeWhat it is
