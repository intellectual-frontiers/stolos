signers-commands

stolos signers (spec 047-intent-and-identity): list, add, and remove the fleet's signers (fleets/<id>/signers.ts, in its fixed form), and, on a host in an emergency, trust a key a person types there.

Source: src/archon/identity/signers-commands.ts

signersTrustfunction
function signersTrust(keyArg: string, name: string): Promise<number>

Emergency (spec 047): every signing key is lost. A person on the host itself (never an agent, never over MCP) trusts a new public key here; the next apply keeps it until the fleet's signers.ts lists it, signed by it.
