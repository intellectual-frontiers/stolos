mime

Mail messages for archon notify (spec 025): RFC 5322 with MIME, a plain-text part and a simple HTML part, and small attachments. Built here (TypeScript, Article 4) so the boot machine on Windows and the hosts send the same thing.

Source: src/archon/notify/mime.ts

Attachmentinterface
interface Attachment

A file attached to a message.

MemberTypeWhat it is
namestringThe file name the recipient sees (for example apply.log).
typestringIts MIME type (for example text/plain or application/gzip).
dataUint8Array<ArrayBufferLike>Its contents, raw bytes (base64-encoded when the message is built).
Mailinterface
interface Mail

One mail message, before it is encoded (buildMime).

MemberTypeWhat it is
fromstringThe sender's address (for example root+alpha.lab@example.com).
fromName?stringDisplay name for From ("alpha (Archon)").
tostringThe recipient's address.
subjectstringThe subject line, any text (RFC 2047-encoded when not plain ASCII).
textstringThe plain-text part.
htmlstringThe HTML part (the same content, simply styled).
attachments?Attachment[]Files to attach; none by default.
headers?Record<string, string>Extra headers (for example Reply-To), values encoded like the subject.
headerValuefunction
function headerValue(s: string): string

A header value, RFC 2047-encoded when it is not plain ASCII.

displayNamefunction
function displayName(s: string): string

A display name: quoted when plain ASCII (RFC 5322), RFC 2047-encoded otherwise.

escapeHtmlfunction
function escapeHtml(s: string): string

Escape &, < and > for HTML text (not for attribute values: quotes are kept).

mimeEntityfunction
function mimeEntity(m: Pick<Mail, "attachments" | "html" | "text">, boundarySeed?: string): string

The body as one MIME entity (CRLF line ends): its Content-Type header, a blank line, then a multipart/mixed body (plain text and HTML as multipart/alternative, base64), then each attachment. buildMime puts the message headers in front; spec 092 encrypts it whole (S/MIME).

buildMimefunction
function buildMime(m: Mail, boundarySeed?: `${string}-${string}-${string}-${string}-${string}`): string

The whole message as RFC 5322 text with CRLF line ends: headers, a multipart/alternative body (plain text and HTML, base64), then each attachment. boundarySeed names the MIME boundaries (random by default; fixed in tests). Date and Message-ID are set here.
