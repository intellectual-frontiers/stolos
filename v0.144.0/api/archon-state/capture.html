capture

archon capture (spec 014, 048): read this host's actual state and compare it with the plan (drift). Nothing is written: the machine answers for itself (archon query).

Source: src/archon/state/capture.ts

Snapshotinterface
interface Snapshot

What a host is now, read from it (archon capture): packages, units, ports, users, tools.

MemberTypeWhat it is
hoststringThe host.
capturedstringWhen it was read (ISO time).
ubuntustringIts Ubuntu release.
kernelstringIts running kernel.
manualPackagesstring[]Packages installed by hand (apt-mark showmanual).
snapsstring[]Snaps installed.
enabledUnitsstring[]Enabled systemd units.
listeningstring[]Listening sockets.
usersstring[]Accounts with a login shell.
toolsRecord<string, string | null>Each tool's version (null: not installed).
Driftinterface
interface Drift

How a host differs from its plan.

MemberTypeWhat it is
missingPackagesstring[]Packages the plan has that the host does not.
unitsNotInDesiredStatestring[]Units not in the state the plan says.
unmodeledListeningPortsstring[]Ports listening that the plan does not open.
