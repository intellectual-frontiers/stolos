types

Spec 095-proposals: the types shared by the server side (archon drift, archon propose, archon record) and the PC side (stolos proposal ...): observations, drift items, change sessions, structured model edits, and the signed stolos-proposal/1 format.

Source: src/archon/proposal/types.ts

Observationinterface
interface Observation

One thing a collector saw: what changed, who changed it, when, and the source it came from.

MemberTypeWhat it is
idstringA stable id (the same evidence collected twice is one observation).
sourceSourceThe collector that saw it.
atstringWhen it happened (ISO time; when it was first seen, if the source has no time).
who?stringWho did it (a Unix account), when the source says.
kindSubjectKindWhat it is about.
namestringIts name: a package, a unit, an absolute path, tcp/443, an account.
changestringWhat happened to it: installed, removed, enabled, edited, added, ...
whatstringOne line for people.
evidencestringThe evidence as the source recorded it (redacted; never a secret).

interface DriftItem

What a drift item is: something the host has that neither the plan nor Ubuntu's own install explains.

MemberTypeWhat it is

kindSubjectKindWhat it is about.
namestringIts name.
changestringHow it differs: added, removed, enabled, disabled, masked, changed.
managedbooleanThe plan manages it, so archon converges it back (a hand edit is held, spec 095).
spec?stringThe spec that manages it, when managed.
who?stringWho changed it, when known.
atstringWhen it was first seen.
evidencestring[]The observations that show it (ids).
flag?stringA constitution flag (Article 5: something no package owns).

manual?stringWhy there is no structured edit, and what a person does instead.
proposal?stringThe proposal it is in, if any.
localUntil?stringAccepted local drift: kept until this date (ISO day).
rejected?booleanRejected on the PC: managed items revert; anything else stays flagged.
heldUntil?stringHeld from the reconcile timer until this time (ISO).

Edittype

type Edit =
  | {
      /** Install a package (apt, or a snap). */
      op: "packages.add";
      /** The package. */
      name: string;
      /** "snap" for a snap; apt otherwise. */
      source?: "snap";
    }
  | {
      /** Enable, disable, or mask a unit Ubuntu ships. */
      op: "units.enable" | "units.disable" | "units.mask";
      /** The unit. */
      unit: string;
    }
  | {
      /** Open a port in the firewall. */
      op: "ports.open";
      /** The port. */
      port: number;
      /** tcp or udp. */
      protocol: "tcp" | "udp";
    }
  | {
      /** Write a file with this content (small, non-secret text only). */
      op: "files.override";
      /** Its absolute path. */
      path: string;
      /** Its content. */
      content: string;
      /** Its mode ("0644"). */
      mode: string;
      /** Its owner. */
      owner: string;
      /** Its group. */
      group?: string;
    };

type ProposalDecision = {
  /** accepted or rejected. */
  decision: "accepted" | "rejected";
  /** Who decided. */
  by: string;
  /** When (ISO). */
  at: string;
  /** The reason given (rejections). */
  reason?: string;
  /** The draft spec an acceptance wrote. */
  spec?: string;
  /** Items adopted into the model (keys). */
  adopted?: string[];
  /** Items kept as accepted local drift, each until a day. */
  local?: Array<{ key: string; until: string }>;
  /** Items skipped at acceptance (named conflicts), left flagged. */
  skipped?: string[];
};

What operators decided about one proposal, in Git (fleets/<fleet>/hosts/<host>/proposals.ts).
