discover

Spec 067: discovered machines: seen, not yet managed or adopted. Stolos looks where it already can, without scanning anything: this PC's neighbor table (machines it has talked to on the local network) and the cloud observations in Git (servers and instances no fleet machine owns). It prints them with the command that would adopt each; it records nothing.

Source: src/archon/adopt/discover.ts
