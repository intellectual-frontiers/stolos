operator

Spec 058: archon update on your PC (the boot machine, or any checkout of the fleet repository that is not an installed host). One command instead of git pull, and everything that should follow it, every step idempotent:

  1. Pull: fetch, then fast-forward a clean checkout (never a merge, never a rewrite); local commits or changes are named, with what to do.
  2. Approval: what arrived is signed by a key the fleet trusted before it (the check servers make), so a push that servers will refuse is seen here.
  3. Engine: is the pinned Stolos release the newest? If not, fleet upgrade moves the pin (one signed commit; you push it). --no-upgrade only reports. Then bun install --frozen-lockfile: the engine bun.lock holds is the one installed here.
  4. Keys: the parts of keys setup that need no passphrase (Git's allowed signers, the pre-push check).
  5. Doctor: boot doctor on a boot machine (keys included), else stolos keys.

On an installed host, archon update is spec 015's (pull, apply, verify).

Source: src/archon/update/operator.ts
