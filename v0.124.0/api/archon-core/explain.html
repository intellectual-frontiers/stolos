explain

Spec 052: every problem archon knows how to explain, by a stable code. A problem shown with a code says "explain: archon explain <code>"; the code stays the same across versions, so it can be searched for and written down. Raw errors from other tools (ssh, apt, git, Bun) that people meet often are recognized here too, and given their plain cause and fix.

Codes: E<spec>-<WORD> for a problem, P<spec>-<WORD> for something not set up yet (pending).

Source: src/archon/core/explain.ts

Explanationinterface
interface Explanation

One problem's explanation: what, why, the fix, and the guide.

MemberTypeWhat it is
titlestringIts title, in one line.
whatstringWhat happened, in plain words.
whystringThe likely cause.
fixstringThe fix: what to do, with the exact command where there is one.
docstringThe guide that explains more (its name: bun run stolos docs <name>).
