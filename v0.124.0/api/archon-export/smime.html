smime

S/MIME for spec 092's emailed exports (RFC 8551): the message around IFC TypeScript's CMS encryption (kernel cms.authEnveloped). Each message is encrypted to each recipient's PUBLIC key, taken from their X.509 certificate: there is no shared secret, and Stolos holds no private key for this. Only the recipient's mail program (or openssl cms -decrypt) can open it.

The kernel writes CMS (RFC 5652) AuthEnvelopedData (RFC 5083): the content (a whole MIME entity: the text and the attached files) encrypted once with a fresh AES-256-GCM key, that key encrypted to each recipient with RSAES-OAEP SHA-256. This module wraps the DER as application/pkcs7-mime; smime-type=authEnveloped-data, base64, in a whole RFC 5322 message.

Only RSA certificates are supported (by far the most common for S/MIME); an EC certificate is refused with a clear message.

Source: src/archon/export/smime.ts
