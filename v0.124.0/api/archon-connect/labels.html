labels

Spec 091: the labels connectors fill, declared once (spec 089). Each is a term from MITRE D3FEND or OCSF, and each record a connector reads carries one: user_account, code_repository, person (an HR roster), and hardware_device become the estate's accounts, repositories, people, and devices; the others become nodes of the estate graph as they are.

Source: src/archon/connect/labels.ts

USER_ACCOUNTconst
const USER_ACCOUNT: LabelView

An account in some system (D3FEND user account).

CODE_REPOSITORYconst
const CODE_REPOSITORY: LabelView

A code repository (D3FEND code repository).

PERSONconst
const PERSON: LabelView

A person on an HR system's roster (UDM person): the source of truth for people.

HARDWARE_DEVICEconst
const HARDWARE_DEVICE: LabelView

A device a connector knows (D3FEND hardware device): an MDM's or directory's machines.

DNS_RECORDconst
const DNS_RECORD: LabelView

A DNS record (D3FEND DNS record).

DOMAIN_NAMEconst
const DOMAIN_NAME: LabelView

A DNS zone (D3FEND domain name).

SERVERconst
const SERVER: LabelView

A server in a cloud (D3FEND server).

CLOUD_STORAGEconst
const CLOUD_STORAGE: LabelView

Object storage (D3FEND cloud storage).

VOLUMEconst
const VOLUME: LabelView

A disk volume (D3FEND volume).

FIREWALLconst
const FIREWALL: LabelView

A firewall (D3FEND firewall).

LOAD_BALANCERconst
const LOAD_BALANCER: LabelView

A load balancer (OCSF load balancer).

IP_ADDRESSconst
const IP_ADDRESS: LabelView

A public IP address (D3FEND IP address).

SOFTWAREconst
const SOFTWARE: LabelView

Software a provider runs for the fleet (D3FEND software): serverless functions, sites, tunnels.

ACCOUNTconst
const ACCOUNT: LabelView

A cloud or SaaS account itself (OCSF account): an AWS account, a Cloudflare account.

CLOUD_USER_ACCOUNTconst
const CLOUD_USER_ACCOUNT: LabelView

A cloud's own identity (D3FEND cloud user account): an AWS IAM user. Kept as a record, not an estate account: it signs in to the cloud's API, not as a person on the roster.

ORGANIZATIONconst
const ORGANIZATION: LabelView

An organization a connector reads (OCSF organization): a tenant, a code host's organization.

ACCESS_CONTROL_GROUPconst
const ACCESS_CONTROL_GROUP: LabelView

A role or group that grants access (D3FEND access control group), and who holds it.

ASSESSMENTconst
const ASSESSMENT: LabelView

An assessment a source reports (OCSF assessment): who has registered a second factor.

POLICYconst
const POLICY: LabelView

A security policy (OCSF policy): security defaults, a Conditional Access policy.

PRODUCTconst
const PRODUCT: LabelView

A product an account holds (OCSF product): a license.

RESOURCEconst
const RESOURCE: LabelView

A cloud resource (D3FEND resource): an Azure subscription or anything in one.

TICKETconst
const TICKET: LabelView

A ticket in an IT service management or work-tracking system (OCSF ticket): a change, an incident, or other work, and the commits or pull requests it links (spec 087).

PASSWORD_STOREconst
const PASSWORD_STORE: LabelView

A shared vault or collection in a password manager (D3FEND password store), and who can open it.

APPLICATIONconst
const APPLICATION: LabelView

An application people sign in to through an identity provider (OCSF application): an Okta app integration, an Entra enterprise application. Spec 080 reads them to discover the fleet's vendors.

VULNERABILITYconst
const VULNERABILITY: LabelView

A vulnerability a scanner reports on one asset (OCSF vulnerability; emitted as OCSF Vulnerability Finding, 2002): spec 088. Open ones go in the OSCAL POA&M with their CVE, severity, and asset.

EVENT_LOGconst
const EVENT_LOG: LabelView

An audit log a cloud keeps (D3FEND event log): a CloudTrail trail, an exported activity log, a log sink.

INTRUSION_DETECTION_SYSTEMconst
const INTRUSION_DETECTION_SYSTEM: LabelView

A cloud's threat detection (D3FEND intrusion detection system): GuardDuty, a Defender for Cloud plan.

CONFIGURATION_MANAGEMENT_DATABASEconst
const CONFIGURATION_MANAGEMENT_DATABASE: LabelView

A cloud's record of its resources' configuration history (D3FEND configuration management database): AWS Config.

CONNECTOR_LABELSconst
const CONNECTOR_LABELS: readonly LabelView[]

Every connector label.
