exec

Spec 065: how the Archon Console runs a command for the person signed in.

The console's web server runs as the archon-console account, in a sandbox that cannot change the system. For each command it runs sudo -n archon console exec --as <person> --argv '<command as JSON>' (that account is in archon-ops, which may run archon as root). console exec, as root:

  1. accepts only the console's account (SUDO_USER is archon-console);
  2. checks again that the person may run it (their groups, the command's tier as its arguments make it): the web server is never trusted alone;
  3. asks systemd to run archon <command...> as a transient service, outside the console's sandbox, with SUDO_USER set to the person, so every record the command writes names them (as sudo archon ... from their own shell would), and ARCHON_VIA=web;
  4. after a command that changes the server, mails the fleet's mailbox.

Source: src/archon/console/exec.ts
