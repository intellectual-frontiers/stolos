forms

Specs 065 and 066: every command a console offers is a form, generated from the command registry (the source of archon help, the man pages, and the MCP tools), so the web and the CLI cannot drift. A form's values become an argument list for that command alone: each value is one argument (never a shell), checked against the command's own definition.

Source: src/archon/console/forms.ts

NOT_IN_CONSOLEconst
const NOT_IN_CONSOLE: Set<string>

Commands a console never offers, though their place matches: interactive ones (a terminal UI, psql), the services themselves, and the internals.

function consoleCommands(place: "machine" | "pc"): Command[]

The commands a console offers where place runs ("machine": archon; "pc": stolos).

function shellWords(argv: string[]): string

An argument list as a person would type it in a shell (quoted where needed).

A tier in plain words, for people.

function tierPill(t: CommandTier): Html

A tier as a pill.

FormResulttype
type FormResult = { argv: string[]; args: Parsed; tier: Tier } | { error: string };

The result of reading a command's form: its argument list and tier, or why not.

argvForfunction
function argvFor(cmd: Command, form: Record<string, string | undefined>): FormResult

A form's values as cmd's argument list. Positional arguments first, in order, then the options; a flag is present when its box is ticked. Values may not start with "-" (they would read as options). Required ones must be there. Unknown fields are ignored.

FormOptionsinterface
interface FormOptions

How a console's forms differ (the Stolos Console: the person at the PC may run everything).

MemberTypeWhat it is
may?((t: CommandTier) => boolean)Whether the person may run a tier (default: the Archon Console's roles).
password?booleanAsk for the password again before destroying data (default: yes).
footnote?stringThe line beside the Run button.
commandFormfunction
function commandForm(cmd: Command, role: Role, post: string, values?: Record<string, string>, o?: FormOptions): Html

A command's form: what it does, its fields, and the run button. People who may not run it see why; destroying data asks for the password again. Datastar posts it and streams the output into #output.
