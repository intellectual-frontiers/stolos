drift

Spec 095-proposals: drift is what the host has, minus the plan, minus the birth snapshot (what Ubuntu itself put on the host at install), so Ubuntu's own changes (unattended upgrades, a package's own presets) are never drift (Article 2). Each item carries who changed it and when (from the observations), and the model change that would adopt it.

Source: src/archon/proposal/drift.ts
