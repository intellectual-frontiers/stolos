host-add

stolos host add (spec 004): write the host's model, give it its own GitHub deploy key (read-only access to this repository (spec 048); the private half stays in the boot machine's secret store), and arm it for one install.

Source: src/archon/install/host-add.ts

HostAddOptionsinterface
interface HostAddOptions

What stolos host add is given.

MemberTypeWhat it is
namestringThe host's name.
claim?booleanSpec 051: exactly one of claim and macAddress (see recognize.ts).
macAddress?stringIts network card (instead of --claim).
confirmDestroy?stringThe host's name again: its install may erase disks that are not blank.
disk?"largest" | `/dev/${string}`The install disk.
layout?"direct" | "lvm"Ubuntu's guided layout.
noDeployKey?booleanSkip the GitHub deploy key (tests, or a host that should not push).
force?booleanRewrite an existing host.ts.
push?booleanBuild, commit, and push the new model (default true; --no-push leaves it).
