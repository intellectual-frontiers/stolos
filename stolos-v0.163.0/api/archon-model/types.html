types

The Archon model (spec 002): a fleet with one shared identity and one file per host. Capabilities contribute packages, files, units, and the rest to a host's plan. TypeScript types plus validate.ts are the whole validation story (Article 10); RDF is only an export.

Source: src/archon/model/types.ts

ExportJobDefinterface
interface ExportJobDef

One export job (spec 092): which documents, for which tenants, to whom, and when. Delivery: to the fleet's OpenTelemetry collector (OTLP/HTTP, telemetry.collector) when one is configured, otherwise to a file in this PC's state directory; with email, the files are also mailed, encrypted to each recipient's certificate. Nothing secret is in a job: the sending credential stays in this PC's secrets folder.

MemberTypeWhat it is
idstringIts id, a DNS label: names the scheduled job and its folder (stolos export run <id>).
title?stringWhat it is for, in one line.
kindsExportKind[]The documents to export.
tenants?string[]The tenants it covers, by uid (<connector>:<account>, as in the estate graph: fleet:<fleet>, aws:123456789012); a trailing * matches a prefix (aws:*). Default: every tenant.
otlp?booleanSend to the fleet's OpenTelemetry collector when one is configured (default true).
email?ExportEmailDefAlso email the files (send-only, each copy encrypted to its recipient).
schedule?ExportScheduleDefWhen it runs by itself (stolos export schedule <id> creates the OS's own job).

An auditor's monthly OSCAL, and a cloud tenant's daily inventory

verifystringThe command that checks it (exit 0: fine).

onCalendar?stringFor a timer: when it fires (systemd OnCalendar syntax).
