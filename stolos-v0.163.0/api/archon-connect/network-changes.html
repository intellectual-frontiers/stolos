network-changes

Spec 111-network-posture FR-018, FR-019: the network's change events. A router's observation is a generated TypeScript file committed in Git (fleets/<fleet>/estate/<id>.ts), so a difference between two of its versions is a recorded change (NIST SP 800-53 Rev 5 CM-3 configuration change control, CM-6 configuration settings). diffObservations says what differs between two observations (a device added, gone, renamed or with new firmware; a Wi-Fi network added, removed or with another security; a network added, removed or changed; a firewall rule added, removed or changed), and networkChanges walks the commits of the file since a point of history, comparing each with the one before, with the reader and the date resolution compliance drift uses.

Source: src/archon/connect/network-changes.ts

networkChangesfunction
function networkChanges(o: { repo: string; fleet: string; connectors: readonly string[]; since: string; now?: number | undefined; }): Promise<NetworkHistory | { error: string; }>

The change events of the routers' observation files between a point of the history of the fleet repository and now. Each commit that changed fleets/<fleet>/estate/<id>.ts is compared with the version before it; the first version of a file is the baseline and gives no event; an observation in the working tree that is not committed is compared with the last one and its events are uncommitted.
