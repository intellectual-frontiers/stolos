network-class

Spec 110-network-assets FR-001: what a network device is, whatever its vendor. A device has a class (stolos:DeviceClass: gateway, switch, access point, camera, recorder, door controller, phone, other) and facets (stolos:DeviceFacet: routing, switching, wireless, surveillance, access control), both typed from the ontology's code lists, so that a feature asks for a facet and gets the devices of any vendor that have it.

UniFi's devices are classified from what the official API gives (10.3.58): the features of an adopted device (gateway, switching, accessPoint) first, which is authoritative; and where it gives none, the model code against a typed table of model families. A model that matches nothing is other: a class is never guessed.

Source: src/archon/connect/network-class.ts
