network-check

Spec 111-network-posture FR-013, FR-016, FR-018: stolos network check | inventory | changes. The check runs the posture pack (evaluateNetworkPosture) over the last observation, the fleet's assets, its tags, its network.ts and its accepted risks, and prints a report; the inventory writes the CM-8 listing; changes lists what the history of the observation files recorded. All three read Git and this PC's files and ask the controller nothing.

Source: src/archon/connect/network-check.ts
