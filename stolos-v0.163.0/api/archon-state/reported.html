reported

Spec 112-machine-reported-tags FR-005, FR-010: what a machine says about itself, on both sides of the wire. On the machine: its /etc/machine-info is read as data (never sourced). On the PC: what a machine reported is kept in the PC's own observation cache (its archon.sql, the kind reported), so no observation makes a commit, and is read again with the fleet's current tags.ts.

Source: src/archon/state/reported.ts

readMachineInfofunction
function readMachineInfo(file: string): Promise<Record<string, string> | undefined>

The machine's own /etc/machine-info (DEPLOYMENT, LOCATION, CHASSIS, TAGS) as bounded text, or none where it has no such file.

keepReportfunction
function keepReport(host: string, report: unknown, dir?: string): Promise<boolean>

Keep what a machine reported in the PC's observation cache (replacing the last), bounded. Returns whether it kept anything.

lastReportfunction
function lastReport(host: string, dir?: string): Promise<MachineReport | undefined>

What the PC last read from a machine (bounded again on the way out: the cache is a file a person can edit), or none.

lastReportsfunction
function lastReports(dir?: string): Promise<Record<string, MachineReport>>

What the PC last read from every machine, by name (one read of the cache).
