autoinstall

Ubuntu autoinstall config for one host (spec 004) and the first-boot step inside it (spec 005). Rendered from the model; the two secrets (admin password hash, deploy key) are passed in only by archon-boot at request time and never reach out/ or git (Article 13). JSON is valid YAML, so the config is written as JSON after the #cloud-config marker.

Source: src/archon/render/autoinstall.ts

InstallSecretsinterface
interface InstallSecrets

What an install hands the machine that must not be in Git.

MemberTypeWhat it is
passwordHashstringThe admin password's hash.
deployKey?stringIts read-only deploy key.
hostKeys?{ type: string; private: string; public: string; }[]The host's SSH host keys, kept on the boot machine: its identity across re-installs.
mailCredential?stringThe mail relay's credential JSON (spec 027).
webCredential?stringThe Cloudflare DNS token (spec 032).
acme?stringTraefik's ACME store carried from the previous install (spec 032).

interface InstallContext

Everything the install config is made from.

MemberTypeWhat it is
fleetFleetDefThe fleet.
hostHostDefThe host.
basestringBase URL of this host's install directory on archon-boot (ends with /).

caPem?stringExtra CA certificate (PEM) the site's proxy needs (optional).

traceparent?stringSpec 049: the boot server's install trace, which the first boot continues.

Spec 049: the first boot reports its spans to the boot server (the one collector sure to be there), in the install's trace: /etc/archon/first-boot.env.
