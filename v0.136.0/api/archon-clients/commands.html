commands

Spec 082: the stolos clients commands (add, list, remove, use, summary, report, console) and --client <id>, which runs any command in one client's scope.

Source: src/archon/clients/commands.ts

resolveClientScopefunction
function resolveClientScope(flag: string | undefined, command: string): Promise<{ client?: Client | undefined; error?: string | undefined; }>

Which client this run is for: --client <id>, else the chosen one (clients use), else none. The clients commands themselves are the provider's and run in no client's scope. Enters the scope; returns an error to print when the client is unknown.

clientsAddfunction
function clientsAdd(o: { path: string; fleet?: string | undefined; id?: string | undefined; title?: string | undefined; }): Promise<number>

stolos clients add <path>: register a client's checkout.

scopedFoldersfunction
function scopedFolders(c: Client): Promise<string[]>

The per-user folders a client's scope uses on this PC.

clientsListfunction
function clientsList(json: boolean): Promise<number>

stolos clients list.

clientsRemovefunction
function clientsRemove(id: string): Promise<number>

stolos clients remove <id>: forget a client (its checkout, state, and secrets stay).

clientsUsefunction
function clientsUse(id: string | undefined, clear: boolean): Promise<number>

stolos clients use <id> (or --clear): the client every command is for, until changed.

clientsSummaryfunction
function clientsSummary(o: { since?: string | undefined; json: boolean; }): Promise<number>

stolos clients summary: every client's numbers, each read on its own.

clientsReportfunction
function clientsReport(o: { out: string; since?: string | undefined; }): Promise<number>

stolos clients report --out <folder>: one report per client, and the summary.

clientsConsolefunction
function clientsConsole(o: { port?: number | undefined; open?: boolean | undefined; }): Promise<number>

stolos clients console: every client in one console, on this PC.
