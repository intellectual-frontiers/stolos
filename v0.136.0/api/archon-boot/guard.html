guard

Spec 051: the blank-disk guard. Before Ubuntu's installer touches a disk, it reports the machine's own facts (from its firmware tables, /proc, and its disks) to this boot server, which answers "ok" or "stop: why". The install goes on by itself only when every disk is blank, when a person confirmed with --confirm-destroy <host>, or when the machine is this host already (it installed as this host, or boot reinstall reached it over SSH). Anything else stops before a byte is written, and the boot window says what the machine holds and the one command that lets it go on.

Source: src/archon-boot/guard.ts

const GUARD_SCRIPT: "#!/bin/sh\n# archon-boot (spec 051): before any disk is touched, report this machine's\n# facts to … (2017 characters)
const GUARD_SCRIPT: "#!/bin/sh\n# archon-boot (spec 051): before any disk is touched, report this machine's\n# facts to the boot server and do what it answers. Nothing here writes a disk.\nB=\"$1\"\nF=/tmp/archon-facts\n{\n  for k in sys_vendor product_name product_serial board_vendor board_name; do\n    echo \"$k=$(cat /sys/class/dmi/id/$k 2>/dev/null)\"\n  done\n  echo \"mem_kib=$(awk '/^MemTotal:/ { print $2 }' /proc/meminfo)\"\n  echo \"cpus=$(nproc 2>/dev/null)\"\n  # Disks (not RAM disks, loops, or optical drives, by their fixed majors; zram by\n  # name: its major, like virtio's and NVMe's, is assigned at boot).\n  lsblk -dnbro NAME,SIZE,TYPE,TRAN -e 1,7,11 2>/dev/null |\n    awk '$3 == \"disk\" && $1 !~ /^zram/ { print \"disk=\" $1 \" \" $2 \" \" $4 }'\n  # What is on them, probed on the disks themselves (wipefs): udev's database,\n  # which lsblk reads, is not filled in yet this early. Any partition the kernel\n  # sees counts too. A disk that cannot be probed counts as not blank.\n  for d in $(lsblk -dnro NAME,TYPE -e 1,7,11 2>/dev/null | awk '$2 == \"disk\" && $1 !~ /^zram/ { print \"/dev/\" $1 }'); do\n    command -v wipefs >/dev/null || { echo \"signature=$d unchecked (no wipefs)\"; continue; }\n    for x in $d $(lsblk -nrpo NAME,TYPE \"$d\" 2>/dev/null | awk '$2 == \"part\" { print $1 }'); do\n      [ \"$x\" = \"$d\" ] || echo \"signature=$x partition\"\n      wipefs -n --noheadings -O DEVICE,TYPE \"$x\" 2>/dev/null | awk 'NF > 1 { print \"signature=\" $1 \" \" $2 }' ||\n        echo \"signature=$x unchecked\"\n    done\n  done\n} >\"$F\"\nA=$(curl -fsS --noproxy \"*\" -m 30 -X POST -H 'content-type: text/plain' --data-binary @\"$F\" \"${B}facts\") ||\n  A=\"stop: the boot server did not answer, so nothing was erased (is bun run stolos boot serve running?)\"\ncase \"$A\" in\n  ok*) exit 0 ;;\nesac\necho \"archon: $A\" | tee /dev/console\necho \"archon: nothing was written to any disk; this machine powers off in 30 seconds.\" | tee /dev/console\nsleep 30\npoweroff -f\n"

Run by the installer (early-commands) with the host's install URL. Facts only, as key=value lines; the decision is the boot server's. It fails closed: no answer, no install.

MachineFactsinterface
interface MachineFacts

What a machine says about itself, before its install (from its firmware tables, /proc, and its disks).

MemberTypeWhat it is
vendor?stringIts maker (firmware filler such as "To Be Filled By O.E.M." is dropped).
model?stringIts model.
serial?stringIts serial number.
memKiB?numberIts memory, in KiB.
cpus?numberIts CPUs.
disks{ name: string; bytes: number; transport?: string | undefined; }[]Its disks: name, size in bytes, and how attached (nvme, sata, usb, virtio).
signaturesstring[]Partition tables and filesystems found: "/dev/sda gpt", "/dev/sda2 ext4".
