commands

038-pg: archon pg list | status | ensure | start | stop | restart | reload | upgrade | remove | backup | restore | maintain | publish | unpublish | connect.

Every command names an instance (default prime). Failures exit non-zero with one plain sentence (the app contract, spec 038 FR-019); --json prints a stable document and nothing else on stdout.

Source: src/archon/pg/commands.ts

InstanceViewinterface
interface InstanceView

One instance as archon pg list and archon pg status show it (stable JSON).

MemberTypeWhat it is
namestringThe instance's name.
versionnumberIts major version.
portnumber | nullThe port it listens on (null until allocated).
statusstringpg_lsclusters' status, "not created", or "missing" (recorded but no cluster).
unitstringIts systemd unit, postgresql@<version>-<name>.service.
environmentstringShown in the psql prompt.
protectedbooleanpsql turns AUTOCOMMIT off and warns.
inModelbooleanWhether the host's model names it.
ownedbooleanWhether Archon created it (the host's record has it).
publishedstring | nullThe name it is published at (the host's name when the fleet has no web domain), or null when private.
datastring | nullIts data directory, when the cluster exists.
pgListfunction
function pgList(hostName: string, json: boolean): Promise<number>

archon pg list: every instance on the host, and the clusters that are not Archon's.

pgStatusfunction
function pgStatus(hostName: string, name: string, json: boolean): Promise<number>

archon pg status NAME: exit code 0 only when the instance is online and accepting connections.

interface EnsureResult

The ensure document (stable; apps read it).

MemberTypeWhat it is

versionnumberIts major version.
portnumberThe port it listens on.
statusstringpg_lsclusters' status ("online" when ready), or "unknown".
unitstringIts systemd unit.

pgEnsureReadyfunction
function pgEnsureReady(hostName: string, name: string, version: string | undefined, json: boolean): Promise<number | undefined>

Unprivileged first look (an app's path): when the instance exists, is Archon's, and is online, there is nothing to do and nothing to elevate for.

pgEnsurefunction
function pgEnsure(hostName: string, name: string, version: string | undefined, json: boolean): Promise<number>

archon pg ensure NAME: create the instance if needed and converge it to the model. PostgreSQL must be on for the host. Exit code 0 when it is online.

pgControlfunction
function pgControl(hostName: string, name: string, action: "reload" | "restart" | "start" | "stop"): Promise<number>

archon pg start|stop|restart|reload NAME, through pg_ctlcluster; journaled.

guardDestructivefunction
function guardDestructive(op: string, name: string, confirm: string | undefined): Promise<void>

Destructive operations: the owner's approve marker in spec 038 and --confirm-destroy NAME.

dumpInstancefunction
function dumpInstance(i: Instance & { record: PgRecord; }): Promise<string>

Dump an instance (pg_dumpall, zstd) into /var/backups/archon/pg/<name>/; keep the last 7. Gives the dump's path as the host names it.

pgBackupfunction
function pgBackup(hostName: string, name: string, allInstances: boolean, json: boolean): Promise<number>

archon pg backup NAME (or every instance Archon created): dump each with dumpInstance.

pgRestorefunction
function pgRestore(hostName: string, name: string, from: string | undefined, confirm: string | undefined): Promise<number>

archon pg restore NAME (destructive): load a dump (the newest, or --from) after dumping what is there now, then converge again so Archon's passwords are set anew.

pgUpgradefunction
function pgUpgrade(hostName: string, name: string, to: string | undefined, confirm: string | undefined): Promise<number>

archon pg upgrade NAME --to V (destructive): dump first, install the new version, run pg_upgradecluster, and keep the old cluster stopped (retired).

pgRemovefunction
function pgRemove(hostName: string, name: string, version: string | undefined, confirm: string | undefined): Promise<number>

archon pg remove NAME (destructive): drop the instance (dumped first) and its record and passwords, or with --version only a retired cluster. An instance still in the model is refused.

MAINTAIN_SQLconst
const MAINTAIN_SQL: { connections: string; max: string; sizes: string; bloat: string; }

The queries archon pg maintain reports: connections, max_connections, database sizes, and dead rows.

pgMaintainfunction
function pgMaintain(hostName: string, name: string, json: boolean): Promise<number>

archon pg maintain NAME (root): VACUUM ANALYZE every database, then report connections, sizes, and the tables with the most dead rows.

pgPublishfunction
function pgPublish(hostName: string, name: string, on: boolean): Promise<number>

archon pg publish|unpublish NAME: record the change, then apply the files and databases phases now (firewall, listen_addresses, pg_hba.conf, TLS).

pgConnectfunction
function pgConnect(hostName: string, name: string, write: boolean, remote: boolean, json: boolean): Promise<number>

Your libpq service (spec 039): on the server, your own role over the socket, no password (peer). --remote: the published name with TLS; a person types their Linux password (libpq asks), a service gets its generated one in its own ~/.pgpass.

RoleViewinterface
interface RoleView

One role as archon pg who shows it.

MemberTypeWhat it is
rolestringThe role's name.
kindstring"superuser" (postgres), the kind Archon's comment names (human, service, group), or "unmanaged".
linuxAccountbooleanWhether a Linux account of the same name exists.
loginbooleanWhether the role may log in.
superuserbooleanWhether the role is a superuser.
passwordboolean | nullnull when not root (only the superuser may see whether a password is set).
memberOfstring[]The roles it is a member of, sorted.
pgWhofunction
function pgWho(hostName: string, name: string, json: boolean): Promise<number>

Roles and their Linux identities; exit 1 when one breaks spec 039's rules.

whoProblemsfunction
function whoProblems(views: RoleView[], published: boolean): string[]

Spec 039's rules, as sentences: every login is a Linux account; postgres is the only superuser.

pgPasswdSyncfunction
function pgPasswdSync(hostName: string, user: string): Promise<number>

Run by the PAM hook (spec 039) with a person's password on stdin, after Linux accepted or changed it: each instance where they have a role gets a SCRAM verifier of that same password, so a published instance takes their Linux password. Nothing is printed or stored but the verifier.
