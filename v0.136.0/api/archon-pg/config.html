038-pg: PostgreSQL instances as data. Pure functions only (tested without a server): which instances a host keeps, their ports, configuration, client authentication, roles, the libpq service block, and the SCRAM verifier that sets a password without the password ever reaching PostgreSQL or its logs.

Source: src/archon/pg/config.ts

hbaConffunction
function hbaConf(published: boolean, from: string[]): string

pg_hba.conf (spec 039): every login is a Linux account. On the socket, peer: the kernel says who is connecting, and that is the role (no password). On loopback, scram-sha-256. When published, TLS with scram-sha-256 from from (every address: the router decides who reaches the server). postgres never over a network. Nothing weaker anywhere.
