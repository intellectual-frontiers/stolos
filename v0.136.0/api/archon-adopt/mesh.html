mesh

Spec 098 (FR-010): stolos mesh, guidance only. Stolos does not install, configure, or depend on any network product. Constitution Article 28 says where the fleet's own plain-HTTP exchanges (PXE, HTTP Boot, pairing) may run: the site's LAN, or a zero trust mesh network for a device that is not on it. This command says what that means in practice: the choices, how to tell which of this PC's addresses are on a mesh, and what to type next.

A zero trust mesh network (an overlay) connects each device directly to the others it may reach, encrypted end to end (usually WireGuard), with each device known by an identity rather than by where it is plugged in, and access decided by policy. Nothing listens on the internet.

Source: src/archon/adopt/mesh.ts
