commands

Spec 090: the estate graph's commands.

  • stolos estate query "<select>": one SELECT across every source.
  • stolos estate build: write the canonical estate.sql (the schema and every row), estate.auto.sqlite.db made from it, and estate.osquery.json, in this PC's state directory. The SQL loads into other databases; the SQLite file is what osquery reads (spec 093).
  • stolos estate osquery [--print]: write (or print) the osquery configuration alone, and say how to load it.
  • stolos estate diff "<select>" --since <date|commit>: the rows a query gains and loses between then and now, from Git.
  • stolos estate schema [--docs]: the schema's SQL, or its docs.

#osquery (spec 093)

Every estate table and view is also an osquery table, stolos_<name> (stolos_device, stolos_user_account, stolos_person, ...), through osquery's Automatic Table Construction: estate.osquery.json tells osquery to read estate.auto.sqlite.db itself, so no extension runs. The configuration is generated from the schema's declarations (osquery.ts). The SQLite file is written to a temporary file and renamed over the old one, so osquery, which reads it without locks, sees the old file or the new one, never half of either.

Source: src/archon/estate/commands.ts
