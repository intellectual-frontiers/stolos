backup

Backups (spec 016, Article 14): zstd tar archives of the host's own state and its durable data (spec 044), kept to a retention count, with a restore test. Never restores in place: a restore extracts into a directory for you to inspect.

Source: src/archon/backup/backup.ts

GuestExportinterface
interface GuestExport

One durable guest's export (spec 044): its file, or why it failed.

MemberTypeWhat it is
gueststringThe LXD instance's name.
file?stringThe lxc export file written next to the archives, when it worked.
error?stringlxc's error output, when the export failed.

What a backup run wrote.

MemberTypeWhat it is

VerifyResultinterface
interface VerifyResult

The outcome of a restore test of the newest archive.

MemberTypeWhat it is
okbooleanTrue when the archive lists and its host marker restores to this host's name.
reasonstringWhy the test failed; empty when it passed.
archivestringPath of the archive tested; empty when there is none yet.
entries?numberHow many lines the archive's listing has (set only when the test passed).
RestoreResultinterface
interface RestoreResult

Where a restore put an archive.

MemberTypeWhat it is
archivestringPath of the archive extracted.
dirstringThe directory it was extracted into (<to>/<archive name>).
backupRunfunction
function backupRun(host: HostDef): Promise<BackupResult>

Write a zstd tar archive of the host's backup paths (those that exist), prune old archives to the policy's keep, journal it, then export each durable guest (spec 044). Throws when tar fails (exit code above 1).

backupVerifyfunction
function backupVerify(host: HostDef): Promise<VerifyResult>

Restore-test the newest archive (Article 14): list it, then extract etc/archon/host into a temporary directory and check it names this host. Changes nothing on the live system.

backupRestorefunction
function backupRestore(host: HostDef, name: string | undefined, to: string): Promise<RestoreResult>

Extract an archive (name, or the newest) into <to>/<archive name> to inspect. Never restores in place. Throws when there is no archive or tar fails.
