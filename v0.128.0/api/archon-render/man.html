man

Man pages and fish completions generated from the command registry and from the constitution and personas (Article 6). Installed into /usr/local/share/man and fish's vendor completions directory by spec 012.

Source: src/archon/render/man.ts

MAN_DATEconst
const MAN_DATE: "2026-11-09"

A fixed date keeps rendered pages stable across builds; bump with releases.

function pageName(cmd: Command): string

A command's man page name, for example archon-vault-backup.

function commandPage(cmd: Command): string

One command's man page, in roff, from its registry entry.

function mainPage(commands: Command[]): string
