registry-types

Types for the command registry (Article VI). One definition per capability generates the CLI, MCP tools, man pages, fish completions, and the agent's permission rules.

Source: src/archon/core/registry-types.ts

Tiertype
type Tier = "read" | "repo" | "mutate" | "destructive";

What a command may do, from least to most: read, change the repository, change a machine, or destroy something (the agent's permission rules follow it).

ArgSpecinterface
interface ArgSpec

One argument of a command: an option (--name) or a positional value.

MemberTypeWhat it is
namestringIts name (the option is --name).
type"boolean" | "string"A value, or a flag.
descriptionstringWhat it does, in one line (help, man page, MCP).
positional?booleanGiven without --name, in order.
short?stringA one-letter form (-m for --message).
required?booleanThe command refuses to run without it.
default?string | booleanIts value when it is not given.
repeatable?booleanMay be given more than once; the values are joined with newlines.
human?booleanOnly a person types it (--confirm-destroy, Article 23; --show for a secret): never offered over MCP, and refused when an agent runs the command (ARCHON_AGENT is set).
choices?string[]The only values it takes (a console shows a choice).
Parsedtype
type Parsed = Record<string, string | boolean | undefined>;

A command's arguments, parsed: name to value.

RunContextinterface
interface RunContext

What every command is given besides its arguments.

MemberTypeWhat it is
hostNamestringThe host this invocation operates on.
jsonboolean--json: machine-readable output, nothing drawn.
verbose?boolean-v: every item, as it happens.
Commandinterface
interface Command

One archon command: its name, help, tier, arguments, and what it runs. The man pages, the MCP tools, and archon help all come from these.

MemberTypeWhat it is
namestringSpace-separated words, for example "tools sync".
summarystringOne line, for archon help.
descriptionstringParagraphs separated by blank lines.
tierTierWhat it may do: read, write the repository, change the host, or destroy (spec 030: MCP serves up to the fleet's tier).
readOnlyWith?stringTier when this flag is set (for example apply --check is read-only).
mutateWith?stringThe reverse: read-only, except with this flag, which changes the host (fs s3 key --rotate). It then elevates, and counts as mutate over MCP.
asOwner?booleanAlways runs elevated, even when read-only, because it works through the checkout's owner (ops and the host's deploy key): push. Operators and the admin are in archon-ops, so sudo does not prompt (spec 006).
argsArgSpec[]Its arguments.
examples?{ cmd: string; text: string; }[]Examples, for its man page.
seeAlso?string[]Related man pages.
noMcp?booleanHide from MCP (for example mcp itself).
operation?booleanAn operation (Article XXII): runs in phases with a header, a run log, and a closing summary instead of printing a result.
unlocked?booleanTouches only its own files (archon notify's spool): no host lock, so it never waits for or blocks an apply, and it leaves the prompt's last-run segment alone.
precheck?((args: Parsed, ctx: RunContext) => Promise<number | undefined>)A look before elevating (spec 038): when it returns a code, the command is already satisfied and finishes unprivileged, so an idempotent mutate command (archon pg ensure) works unattended for a normal user once its work is done.
place?PlaceWhere it runs: "pc" (stolos, in the fleet repository on your PC), "machine" (archon, on each server or workstation), or "both".
aliases?string[]Other names for it (spec 060: stolos push is stolos apply).
run(args: Parsed, ctx: RunContext) => Promise<number>Runs it; returns the exit code.
Placetype
type Place = "pc" | "machine" | "both";

Where a command runs: your PC (stolos), each machine (archon), or both.

effectiveTierfunction
function effectiveTier(cmd: Command, args: Parsed): Tier

The tier this run needs (a command's tier can depend on its arguments, for example --check).

parseArgsfunction
function parseArgs(cmd: Command, argv: string[]): Parsed

Parse argv for this command, or throw a message naming the problem (a person-only option from an agent is refused).

GLOBAL_ARGSconst
const GLOBAL_ARGS: ArgSpec[]

Arguments shared by every command.
