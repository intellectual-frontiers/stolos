markdown

035-welcome-guide: the engine's guides (each module's @module JSDoc, src/archon/core/guides.ts) as HTML on the welcome page, so one text serves the repository, the man pages, and the server. Handles what those guides use: headings, paragraphs, lists, tables, code blocks, blockquotes, inline code, bold, italics, and links. Everything is escaped first; links to other guides stay on the page, the rest go to GitHub.

Source: src/archon/web/markdown.ts
