server

archon mcp: a Model Context Protocol server over stdio (JSON-RPC 2.0, newline-delimited), implemented natively without an SDK (Article II). Every registry command within the tier limit is a tool; docs, specs, runbooks, and reports are resources. Workstations reach it on a server as ops over SSH, forced to archon mcp --max-tier <tier> (spec 030): the limit is enforced here, on the server, whatever the client is configured to do.

Source: src/archon/mcp/server.ts

annotations{ readOnlyHint: boolean; destructiveHint: boolean; idempotentHint: boolean; }MCP hints for clients.

Msgtype
type Msg = {
  /** Always "2.0". */
  jsonrpc: "2.0";
  /** The request ID to answer with; absent on notifications. */
  id?: number | string;
  /** The method, such as "tools/call". */
  method?: string;
  /** The method's parameters. */
  params?: Record<string, unknown>;
};

One JSON-RPC 2.0 message from the client: a request (with id) or a notification.

handlefunction
function handle(msg: Msg, limit?: McpTier): Promise<unknown>

Answer one JSON-RPC message, serving tools up to limit: the JSON-RPC response, or undefined for notifications (nothing to send).

serveMcpfunction
function serveMcp(maxTier?: string | undefined): Promise<void>

archon mcp: read newline-delimited JSON-RPC from stdin and write each response to stdout until stdin closes. maxTier is the --max-tier value (default mutate); an invalid one throws.
