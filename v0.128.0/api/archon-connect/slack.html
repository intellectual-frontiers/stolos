slack

Spec 087: Slack, read-only, for one workspace: its people (active, owner or admin, guest, whether they have two-factor authentication on), and its channels shared with other organizations (Slack Connect). Evidence for MFA (SCF IAC-37), least privilege (IAC-30), account management (IAC-08), and data protection (DCH-02).

Every Slack Web API method used here accepts GET; Slack answers a denied call with HTTP 200 and ok: false, so that is turned into a gap here. Slack shows a member's two-factor status only to an admin's or owner's token, and has no API for the workspace's "require two-factor" setting outside Enterprise Grid: the policy is that every member has it on.

Source: src/archon/connect/slack.ts
