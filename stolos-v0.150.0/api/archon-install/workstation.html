workstation

stolos workstation add (spec 020): run inside Ubuntu on WSL (or on an Ubuntu desktop), from the checkout in /srv/archon, as your own user. It writes fleets/<fleet>/hosts/<name>/host.ts (kind "workstation") and then, through sudo, converges the user-level parts: tools, dotfiles, the archon command, Ubuntu's daily updates (archon update --no-pull).

Source: src/archon/install/workstation.ts

workstationAddfunction
function workstationAdd(o: { name?: string | undefined; user?: string | undefined; force?: boolean | undefined; }): Promise<number>

stolos workstation add: checks this machine (Linux, not root, the fleet's Ubuntu release, systemd, the /srv/archon checkout), writes the host model (kept unless force), then runs archon update through sudo. Returns the exit code: 1 when a check fails, else update's.
