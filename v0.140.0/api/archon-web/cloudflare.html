cloudflare

032-web: the few Cloudflare API calls a server needs to keep its own DNS records (its name and wildcard, both to its private address, not proxied). The token needs Zone: Read and DNS: Edit on the zone (the same token Traefik uses for Let's Encrypt's DNS challenge).

Source: src/archon/web/cloudflare.ts

CfCredentialinterface
interface CfCredential

The server's Cloudflare credential: an API token with Zone: Read and DNS: Edit on the zone.

MemberTypeWhat it is
tokenstringThe API token. A secret: never logged or sent anywhere but Cloudflare's API.
created?stringWhen it was made (ISO 8601), if known.
ARecordinterface
interface ARecord

A DNS A record to keep (always TTL 60, not proxied).

MemberTypeWhat it is
type"A"The record type: only A records are kept.
namestringIts full name (for example alpha.lab.example.net, or *.alpha.lab.example.net).
contentstringThe IPv4 address it points to.
TxtRecordinterface
interface TxtRecord

Spec 100: a DNS TXT record to keep (TTL 60): the Stolos Console's heartbeat.

MemberTypeWhat it is
type"TXT"The record type.
namestringIts full name (for example _stolos-console.stolos.lab.example.net).
contentstringIts text, unquoted.

The fetch function the calls use: the global fetch, or a fake in tests.
