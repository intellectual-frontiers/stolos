commands

The archon notify commands (spec 025), on hosts, workstations, and the boot machine (bun run stolos boot notify runs the same code), and archon mail credential and mail test (spec 027).

Source: src/archon/notify/commands.ts

installCredentialfunction
function installCredential(json: string): Promise<void>

Install the relay credential on this host (spec 027): Postfix's /etc/postfix/sasl_passwd, root only, then Postfix reloads (it reads the file once, texthash). archon's own sends read the same file.

SendArgsinterface
interface SendArgs

The options of archon notify send.

MemberTypeWhat it is
subjectstringThe subject. One that starts with [ or Lab is sent as given, with the body as the whole message; a short one becomes [Archon] <host>: <subject>.
body?stringThe body text (with a short subject, the subject itself when empty).
bodyFile?stringRead the body from this file instead (it wins over body).
attach?string[]Files to attach.
level?LevelHow serious it is; "info" by default.
key?stringDeduplication key: the same key within an hour is sent once.
notifySendfunction
function notifySend(a: SendArgs, o: { wait: boolean; }): Promise<number>

archon notify send: queue a message from this machine. With wait, send it now and report whether it went; otherwise start the sender and return. Exit code 0 when queued (or sent, with wait) or a duplicate, else 1.

notifyTestfunction
function notifyTest(): Promise<number>

archon notify test: send a test message now and wait for the relay (exit code 0 when sent).

notifyStatusfunction
function notifyStatus(o: { check: boolean; }): Promise<number>

archon notify status: mailbox, sender, relay, credential, last send and queue. With check (archon verify), one line instead, and exit code 1 when mail is not configured, the last send failed, or a message has waited more than 6 hours.

notifyFlushfunction
function notifyFlush(): Promise<number>

archon notify flush (the flush service): send what is due. Prints counts only when something was tried. Always exit code 0.

mailCredentialfunction
function mailCredential(): Promise<number>

archon mail credential: the credential JSON on stdin (bun run stolos boot mail-push). Then the doctor's email checks, mailed to the shared mailbox through archon and Postfix, so the new token is proven where it matters.

mailTestfunction
function mailTest(hostName: string): Promise<number>

archon mail test: one message through Postfix (/usr/sbin/sendmail), the path every app and cron job uses; addressed to root, which this host's Postfix sends on to the fleet's mailbox.
