passphrase

One passphrase per command (spec 106-one-passphrase-speed): the daily key's passphrase, asked once and kept only in the memory of the command that signs, so that a run which signs twice (a record, then an engine upgrade) or starts a child run does not ask twice.

The passphrase is bytes in this process's memory from the first time it is asked until the command ends, then zeroed. It reaches OpenSSH only through a per-run askpass helper (SSH_ASKPASS, a .cmd on Windows) that asks this process over 127.0.0.1 with a token made for this run: never through an environment variable, a file, a log, an argument, telemetry or MCP. A child process (a nested run that needs a new engine) inherits the helper's address and token, not the passphrase, and asks the same process. A passphrase is kept only after it unlocked the key.

Source: src/archon/core/passphrase.ts

collectSecretfunction
function collectSecret(next: () => Promise<number | null>): Promise<Uint8Array<ArrayBufferLike> | undefined>

Read a secret byte by byte, as a terminal in raw mode gives it (no echo): Enter ends it, Backspace takes one character back, Ctrl+U everything, Ctrl+C and Ctrl+D (on an empty line) cancel. next gives each byte, or null at the end of the input. The bytes are never made into a string.

askThePersonfunction
function askThePerson(prompt: string, limitMs?: number): Promise<Uint8Array<ArrayBufferLike> | undefined>

Where the person is asked, once (spec 106-one-passphrase-speed FR-004): at the terminal, by this program, with no echo; else through the askpass the environment names (SSH_ASKPASS, when it is forced or there is no terminal); else nowhere.

PerSigningSessionclass
class PerSigningSession implements Passphrases

What a command holds where there is no broker (Windows, until the broker has had a real Windows test, spec 106-one-passphrase-speed FR-002): nothing. Each signing is OpenSSH's own, as in spec 105-calm-output (the person's SSH_ASKPASS, or the terminal), so a command that signs twice asks twice. No server, no helper script, no child process of ours is involved in signing.
