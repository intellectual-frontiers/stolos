html

Spec 065: the console's HTML, as typed TypeScript. html is a tagged template that escapes every value it is given, except another Html (a piece already built this way) or raw() (markup the engine wrote itself). So a username, a command's output, or a value from a form can never become markup.

Source: src/archon/console/html.ts

Htmlclass
class Html

A piece of HTML that is safe to put in a page as it is.

MemberTypeWhat it is
sstringThe markup.
toString() => stringThe markup.
textfunction
function text(v: unknown): string

Any value as text: strings as they are, numbers and booleans written out, objects as JSON, nothing as "".

formTextfunction
function formText(v: FormDataEntryValue | null): string

A form field's value as text ("" for a missing one or an uploaded file).

escfunction
function esc(v: unknown): string

Text made safe for HTML content and double- or single-quoted attributes.

rawfunction
function raw(s: string): Html

Markup the engine itself wrote (never a value from outside).

htmlfunction
function html(strings: TemplateStringsArray, ...values: unknown[]): Html

Build HTML: every interpolated value is escaped unless it is Html (arrays are joined).
