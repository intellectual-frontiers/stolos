askpass

Spec 099 (FR-005): a passphrase typed in the browser, not the terminal, while the Stolos Console runs a command that signs (stolos update, stolos apply). OpenSSH asks for a key's passphrase through a helper program when SSH_ASKPASS names one and SSH_ASKPASS_REQUIRE=force; the console's runs name this file's helper, which asks the console (on 127.0.0.1, with a token made for this console only), and the console shows the question on the page that started the run. The answer goes back to OpenSSH and nowhere else: it is not logged, not stored, and not sent to the page again.

Source: src/archon/console/askpass.ts
