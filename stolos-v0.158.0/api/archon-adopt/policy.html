policy

Spec 067: the policy pack for adopted machines. Each policy reads an observation and says pass, fail, or unknown, with the fix in plain words for that operating system, and names the Secure Controls Framework (SCF) controls it gives evidence for (specs 068 and 071 reach each framework from those through the SCF Council's own mappings). Spec 078: the pack is written on the control SDK (ADOPTED_CONTROLS), as a fleet's own controls are.

Source: src/archon/adopt/policy.ts

PolicyResultinterface
interface PolicyResult

One policy's result for one machine.

MemberTypeWhat it is
idstringThe policy's id.
titlestringWhat it requires, for people.
scfstring[]The SCF controls it gives evidence for.
status"accepted" | "fail" | "pass" | "unknown" | "warn"pass, fail, unknown (cannot tell), warn (not required, but worth doing), or accepted (fails, by a recorded decision).
detailstringWhat was found.
fix?stringHow to make it pass, on this machine's OS.
supportedOsfunction
function supportedOs(o: Observed): boolean | undefined

Whether this OS version is still supported by its maker (a starter table).

acceptfunction
function accept(m: AdoptedDef, rs: PolicyResult[], now?: number): PolicyResult[]

Failing policies the owner accepted (until a date) become "accepted", with who, why, and until when.

ADOPTED_CONTROLSconst
const ADOPTED_CONTROLS: ObservationControl<"adopted">[]

The adopted-machine policy pack, as controls (spec 078), in the order results are shown.

policiesfunction
function policies(m: AdoptedDef, o: Observed | undefined, now?: number): PolicyResult[]

Every policy, for one machine: the controls above, then accepted risks.

ResultReadingtype
type ResultReading = "pass" | "fail" | "not-observed" | "other";

How a result reads for a person (spec 117-adopted-in-status FR-002, FR-004): a pass, a failure, nothing observed yet, or the rest (a warning, an accepted risk).

isNeverObservedfunction
function isNeverObserved(r: PolicyResult): boolean

The result of a machine that was never observed (the one policies gives when there is no observation).

readResultfunction
function readResult(r: PolicyResult): ResultReading

Read one result: the never-observed result and unknown are "not observed yet", never a failure.

notObservedItemfunction
function notObservedItem(rs: readonly PolicyResult[], observe: string): { message: string; fix: string; code: string; } | undefined

Spec 117-adopted-in-status FR-004, FR-006, FR-008: what is not observed yet of a machine's results, as ONE waiting item (its words, its one fix, its code), or undefined where all of it was observed. observe is the command that observes the machine.
