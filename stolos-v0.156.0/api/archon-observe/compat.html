compat

The PC's side of the contract (spec 115-compatibility FR-006 to FR-010, FR-014): what each machine last reported of its engine and its seams is in the PC's observation cache (the reported record of its own archon.sql, with what a machine says about its tags: no commit per run), and is judged here against this PC's contract, once, for every place that shows it: stolos fleet status, host check, boot doctor, the Stolos Console, stolos compat and the compliance evidence.

Source: src/archon/observe/compat.ts

CompatMachineinterface
interface CompatMachine

One machine, judged against this PC's contract, with the words that say it.

MemberTypeWhat it is
namestringIts name.
kindContractKindHow it is reached, which says which seams it has.
judgementMachineJudgementThe judgement: status, engine and each seam.
wordsCompatWordsThe statement in plain words, with its fix and code.
reportedAt?stringWhen the machine last reported (ISO), when it did.
hold?ResolvedHoldThe hold that applies to it (its own enginePin, or a group's), when there is one.
holdWords?stringThe hold in plain words (held at stolos-v0.150.0 (fleet pin stolos-v0.152.0) ...).
contractOffunction
function contractOf(report: MachineReport | undefined): ContractReport | undefined

What a machine reported, as the contract the judge reads.

contractOfProbeVersionfunction
function contractOfProbeVersion(probe: string | undefined): ContractReport | undefined

What an adopted machine's committed observation says of its probe (3 is the probe-facts seam at 3.0.0), for a cache that predates @compat.

compatOffunction
function compatOf(name: string, kind: ContractKind, report: MachineReport | undefined, o?: { fallback?: ContractReport | undefined; hold?: ResolvedHold | undefined; fleetPin?: string | undefined; answered?: boolean | undefined; pcEngine?: string | undefined; }): CompatMachine

One machine judged (spec 115-compatibility FR-007, FR-008). answered: it was just asked and answered, so "not reported" means its engine predates this check.

interface AdoptedForCompat

The adopted machines the PC judges: each with its model and its last observation (the committed one is the fallback of an old cache).

MemberTypeWhat it is
machine{ name: string; }The machine (name, role).
observed?{ probe: string; }Its last observation, when there is one.
fleetPinTagfunction
function fleetPinTag(repo?: string): Promise<string | undefined>

The tag the fleet pins the engine at, from the fleet repository's package.json, or undefined.

fleetCompatfunction
function fleetCompat(src: { fleet?: HoldFleet | undefined; hosts: readonly HoldHost[]; adopted?: readonly AdoptedForCompat[] | undefined; dir?: string | undefined; now?: Date | undefined; tagIds?: ((name: string) => ReadonlySet<string>) | undefined; answered?: ReadonlySet<string> | undefined; pcEngine?: string | undefined; fleetPin?: string | undefined; }): Promise<CompatMachine[]>

Every machine of the fleet judged: the managed servers (not the workstations, which stolos fleet status does not ask) from what each reported over SSH, and the adopted machines and the controller from their probe. Reads the cache; asks nobody.

isIncompatibleconst
const isIncompatible: (m: Pick<CompatMachine, "judgement">) => boolean

Whether a machine's status is a problem the PC reports (too old or newer); unknown is a thing to do, compatible is nothing.

interface ApplyWarning

A machine that cannot read what this PC is about to send (spec 115-compatibility FR-011).

MemberTypeWhat it is
machinestringThe machine.
messagestringWhy, in words.
fix?stringThe command that fixes it.
code?stringThe code stolos explain knows.
applyWarningsfunction
function applyWarnings(src: { fleet?: HoldFleet | undefined; hosts: readonly HoldHost[]; adopted?: readonly AdoptedForCompat[] | undefined; dir?: string | undefined; now?: Date | undefined; tagIds?: ((name: string) => ReadonlySet<string>) | undefined; answered?: ReadonlySet<string> | undefined; pcEngine?: string | undefined; fleetPin?: string | undefined; }): Promise<ApplyWarning[]>

Before stolos apply signs a change: the managed servers that cannot read what it sends, from what each last reported (the cache; nobody is asked): a model or signed-records seam that is too old or newer, or any seam too old. It only says; it never blocks (FR-011).
