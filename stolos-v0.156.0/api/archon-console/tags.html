tags

Spec 108-tags FR-014: the Stolos Console's tags. A chip for each tag a machine holds (a defined tag in its own colour, a free-form one always apart: a dashed outline and the word "custom"), the fleet's tags with how many machines hold each (they filter the machines table), the machines grouped by a dimension, and the picker above "Ask every machine". The console holds no logic: the tags are resolved by the fleet's tags (fleet/tags.ts), and this only draws them.

Source: src/archon/console/tags.ts

tagChipfunction
function tagChip(t: ResolvedTag): Html

One tag as a chip: its label in its colour; a free-form tag says "custom"; one that is not defined says so.

tagChipsfunction
function tagChips(tags: readonly ResolvedTag[] | undefined): Html

A machine's tags as chips (nothing where it has none).

tagIdsconst
const tagIds: (tags: readonly ResolvedTag[] | undefined) => string

The tag ids of a machine, spaced, for a row's filter (' env:prod role:nas pilot ').

groupByDimensionfunction
function groupByDimension<M extends { tags?: readonly ResolvedTag[] | undefined; }>(machines: readonly M[], view: TaggingView | undefined, dimension: string): { key: string; label: string; machines: M[]; }[] | undefined

The machines grouped by one dimension: a group per value (a many-of machine is in each of its values), and one for none.

groupLinksfunction
function groupLinks(view: TaggingView | undefined, current: string): Html

The links that group the machines table by a dimension (and ungroup it).

tagFacetsfunction
function tagFacets(view: TaggingView | undefined): Html

The fleet's tags with how many machines hold each, as buttons that filter the machines table (the page's $tag signal), the free-form ones in a row of their own, marked custom.

tagPickerfunction
function tagPicker(view: TaggingView | undefined, select: string): Html

The tag picker above the Ask page: chips that add a tag to the expression field ($select), a field for the expression itself, and a line that says what it chooses. The expression is read by the same typed parser the command line uses.

claimsPanelfunction
function claimsPanel(machine: string, says: readonly ClaimView[], disagreements: readonly string[], o: { gaps?: number | undefined; canAccept: boolean; }): Html

Spec 112-machine-reported-tags FR-014: the Machines say panel of a machine's page: what it says about itself, where it was read, what the fleet did with it, and Accept (a form that runs tag accept, a command of the one registry) and Ignore (hides the claim for the session: a signal of the page, nothing is kept). A claim that tags.ts does not define, or that is ignored by its dimension, offers no Accept. Everything a machine said is escaped where it is drawn.
