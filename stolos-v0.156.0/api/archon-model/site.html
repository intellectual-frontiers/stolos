site

The site (spec 028, constitution Article 21): the UniFi network as typed data. Archon checks hosts against it and renders the network reference from it, but never changes the router: the owner (or the network assistant) changes the router, then this model is updated to match. The data is fleets/<fleet>/site.ts; this file is the ontology and its rules.

Addresses, prefixes, VLANs, and ports are branded types: a plain string or number does not type-check where an IPv4 is expected, and the constructors (ipv4(), cidr(), vlan(), port()) reject a malformed literal when the model loads, before anything is rendered (Article 10).

Source: src/archon/model/site.ts

BRANDconst
const BRAND: typeof BRAND

The brand's key (type-level only: no such value exists at run time).

Brandtype
type Brand<T, B extends string> = T & { readonly [BRAND]: B };

A value checked once, at the model's load, and marked so: a plain string or number is not accepted where a branded one is expected.

IPv4type
type IPv4 = Brand<string, "IPv4">;

An IPv4 address, checked: made with ipv4.

Cidrtype
type Cidr = Brand<string, "Cidr">;

An IPv4 prefix (a.b.c.d/n), checked: made with cidr.

VlanIdtype
type VlanId = Brand<number, "VlanId">;

A VLAN id (1 to 4094), checked: made with vlan.

Porttype
type Port = Brand<number, "Port">;

A TCP or UDP port (1 to 65535), checked: made with port.

ipv4function
function ipv4(s: string): IPv4

An IPv4 address, or an error naming the malformed literal.

cidrfunction
function cidr(s: string): Cidr

An IPv4 prefix (a.b.c.d/n), or an error naming the malformed literal.

vlanfunction
function vlan(n: number): VlanId

A VLAN id, or an error when it is not 1 to 4094.

portfunction
function port(n: number): Port

A port, or an error when it is not 1 to 65535.

Is the address inside the prefix?

type Zone =
  "Internal" | "IoT" | "Servers" | "DMZ" | "Hotspot" | "VPN" | "External" | "Gateway";

UniFi's firewall zones as this site uses them (a closed set; Gateway is UniFi's own).

The site's network as data (spec 028, Article 21): fleets/<fleet>/site.ts. Archon checks hosts against it and renders the network reference from it; it never changes the router.

MemberTypeWhat it is
