secret-inventory

The secret inventory (spec 028, constitution Article 13): every secret the fleet depends on, by name, where it lives, and how to make it again. Values never. The boot machine's secrets are what bun run stolos vault backs up and restores (spec 029); the owner's are listed so a lost one is not a surprise. A test checks that every path the code writes is listed here.

Source: src/archon/model/secret-inventory.ts

SecretRefinterface
interface SecretRef

One secret the fleet depends on: where it lives and how to make it again (never its value).

MemberTypeWhat it is
idstringStable identifier ("deploy-key").
labelstringShort name for tables and the backup panel; <host> and <type> are filled in.
pathstringBoot machine: the path inside its secrets folder (%APPDATA%\stolos\secrets), with <host>, <type>, and <name> placeholders. Owner: where it is kept.
purposestringWhat it is for, in a sentence.
holder"boot-machine" | "owner"Who keeps it: the boot machine (backed up by the vault) or the owner.
recreatestringHow to make it again when it is lost (vault status --lost prints this).
ephemeral?trueShort-lived; never backed up (install tokens).
identity?trueIdentity that cannot be re-made the same: losing it changes what others trust.
specstringThe spec that introduced it (NNN-short-name).
