network-commands

Spec 110-network-assets: stolos network discover | adopt | status, and what stolos estate observe and stolos host release do for network assets. A device a router's controller manages is discovered (read from the last observation, no SSH, no probe), adopted (a record in the fleet, one signed commit through stolos apply as stolos tag add sends its change), refreshed at every observation, and released only when a person says so; a device that disappears from the controller is a warning, never a deletion.

Source: src/archon/connect/network-commands.ts

networkAdoptfunction
function networkAdopt(o: NetworkAdoptOptions, deps?: NetworkAdoptDeps): Promise<number>

stolos network adopt <device...> | --all [--class c]: adopt devices the controller manages as assets of the fleet: one record each, written to adopted/<name>/network.ts, and one signed commit through stolos apply (--no-apply leaves it written). No SSH, no probe.

afterObservefunction
function afterObserve(): Promise<string[]>

What stolos estate observe does for assets after it read the router connectors (spec 110-network-assets FR-004, FR-005): writes the records the fleet's autoAdopt rules choose (a signed commit through stolos apply sends them: nothing is hidden), and warns of each asset that is gone from the integration, with its fix. Returns the names it adopted.

releaseNetworkAssetfunction
function releaseNetworkAsset(name: string): Promise<number | undefined>

Release a network asset (stolos host release <name> where the name is one): its record goes, remembered in network-released.ts so that a rule does not take it again; nothing at the controller changes. Undefined where name is not an asset.

showNetworkGroupfunction
function showNetworkGroup(): Promise<void>

The Network group of stolos fleet status and stolos network status: assets by class, discovered, gone (warnings with their fix).

networkStatusfunction
function networkStatus(json?: boolean): Promise<number>

stolos network status [--json]: the Network group, and the unmanaged clients with the guidance of stolos pair.
